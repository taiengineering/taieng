자주 묻는 질문

TAI 서비스에 대해 가장 많이 묻는 질문들을 정리했습니다

무료 법령 진단은 정말 무료인가요?+
네, 시설 정보 기준 1차 분석은 완전 무료입니다. 로그인 없이도 이용 가능하며, 적용 법령·선임 의무·점검 항목·리스크 수준을 확인하실 수 있습니다.
진단 결과는 얼마나 정확한가요?+
입력하신 시설 정보를 기반으로 적용 가능성이 높은 법령 의무를 자동 도출합니다. 특허 출원된 조건코드 기반 자동 판정 시스템(출원번호: 10-2026-0056330)을 활용합니다.
TAI Safe SaaS를 사용하면 안전관리자가 없어도 되나요?+
아닙니다. TAI Safe는 안전관리자의 업무를 자동화하는 도구이지, 안전관리자를 대체하는 시스템이 아닙니다. 법령상 선임 의무가 있는 경우 반드시 안전관리자를 선임하셔야 합니다.
기존 안전 관리 시스템과 연동이 가능한가요?+
현재는 독립 SaaS로 운영됩니다. Enterprise 플랜의 경우 API 연동을 지원하며, 기존 ERP·HR 시스템과의 연동은 별도 협의가 필요합니다.
선임 의무가 있는지 어떻게 확인하나요?+
무료 법령 진단을 통해 3분 안에 확인하실 수 있습니다. 사업장 유형, 근로자 수, 설비 종류를 입력하면 선임 의무 여부와 해당 법령 근거를 자동 도출해드립니다.
수선 전문업체는 어떻게 검증하나요?+
사업자등록증, 해당 분야 면허·인증, 시공 실적 등을 기준으로 검토 후 등록합니다. 등록 완료된 업체만 플랫폼에 노출됩니다.
서비스 취소는 어떻게 하나요?+
서비스 종류에 따라 취소 방법이 다릅니다.
  • SaaS 구독: 마이페이지 → 구독 관리 → 구독 취소에서 직접 취소 가능합니다. 취소 후에는 다음 결제일부터 청구되지 않으며, 위약금은 없습니다.
  • 법령진단 단건: 결과를 열람하지 않은 상태에서 결제일로부터 7일 이내라면 고객센터(tai@taieng.co.kr)로 취소 요청 가능합니다.
  • 기타 서비스: 고객센터(tai@taieng.co.kr 또는 070-8080-1858)로 문의해 주세요.

청약철회(계약철회)가 가능한가요?+
네, 전자상거래 등에서의 소비자보호에 관한 법률 제17조에 따라 청약철회 권리가 보장됩니다.
⚠️ 법령진단 서비스 주의사항: 법령진단 결과는 디지털 콘텐츠로 제공됩니다. 결과 화면을 열람하는 즉시 서비스가 개시된 것으로 간주되며, 이후에는 전자상거래법 제17조 제2항에 따라 청약철회가 제한됩니다. 결제 시 이 사항에 대한 사전 동의를 받습니다.
  • 철회 가능: 결제일로부터 7일 이내, 법령진단 결과 미열람 상태
  • 철회 불가: 법령진단 결과 열람 후 / SaaS 서비스 실제 사용 후
  • 철회 방법: 고객센터(tai@taieng.co.kr)로 서면 또는 이메일로 의사 표시
구독을 언제든지 취소할 수 있나요?+
네, 언제든지 취소 가능합니다. 월 단위 구독이며, 취소 시 다음 결제일부터 청구되지 않습니다. 위약금은 없습니다.
세금계산서 발행이 가능한가요?+
네, 일반과세자로 등록되어 있어 B2B 세금계산서 발행이 가능합니다. 결제 시 사업자 정보를 입력해 주시면 자동 발행됩니다.
