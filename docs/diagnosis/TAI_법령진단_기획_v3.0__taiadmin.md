# TAI Safe 법령진단 기획 v3.0

> 작성일: 2026-03-29  
> 수정일: 2026-03-31 (건설 가격 상향 조정)  
> 분류: 산업(INDUSTRY) / 건설(CONSTRUCTION) / 건물(FACILITY)

---

## 핵심 원칙

```
법령진단 = 1회성 유료 서비스
  → 구독 아님
  → 한 번 사면 끝
  → SaaS 구독과 완전 분리

SaaS 구독 = 법령엔진이 백그라운드 자동 작동
  → 사용자가 진단 버튼을 누르는 게 아님
  → 구독 기간 내내 시스템이 알아서 작동
  → 의무 변경 감지·알림·할당·이력 자동 처리

관계:
  법령진단 → "우리 의무가 뭔지" 1회 확인
  SaaS 구독 → 그 의무들을 매일 자동 관리
```

## 분류 1 — 산업 (INDUSTRY)

### 대상
```
제조업·물류·창고·위험물 취급 사업장
KSIC 기반 업종 분류
설비 보유 (보일러·압력용기·크레인·전기설비 등)
안전관리자 선임 의무 대상
```

### 법령진단 단계별 요금

| 단계 | 입력 | 출력 | 가격 |
|------|------|------|------|
| 기초 | KSIC + 근로자수 | 적용법령 수(숫자만) + 선임의무 O/X | **무료** |
| 표준 | + 시설유형 + 위험물 여부 | 법령명·조문·과태료 전체 (401건) | **99,000원** |
| 설비 | + 보유 설비 선택 | 설비별 점검항목·주기·담당자 지정 | **199,000원** |
| 종합 | 표준 + 설비 통합 | 전체 의무 + 설비 + 신고서식 목록 | **249,000원** |

### 단계별 입출력 상세

| 단계 | 입력 | 출력 | 데이터 활용 |
|------|------|------|-------------|
| 무료 | 업종(KSIC) + 근로자수 | 적용법령 목록(산안법·고압가스·전기안전 등) + 안전관리자 선임 필요 여부 | diagnosis_stage=1 / APPOINT 30건 |
| 표준 | + 시설유형(공장/창고/판매점) + 위험물 보유 여부 | 전체 의무 목록(선임·신고·점검·조치) + 과태료 금액 | stage=1 전체 401건 |
| 설비 | + 보유 설비 선택(보일러·압력용기·전기설비 등) | 설비별 점검항목 + 점검주기 + 담당자 지정 | stage=2 설비점검 매핑 |
| 종합 | 기준일 입력 | 점검 일정 자동 생성 + 신고서식 자동작성 + 알림 설정 | stage=3 + work_schedules |

## 분류 2 — 건설 (CONSTRUCTION)

### 대상
```
현장마다 공사 내용이 다름
공사 기간 존재 (착공~준공)
하도급 구조
인원 수시 변동
KCSC 161개 공정·243개 위험작업
```

### 법령진단 단계별 요금

| 단계 | 입력 | 출력 | 가격 | 특이사항 |
|------|------|------|------|----------|
| 기초 | 공사유형(건축/토목) + 공사금액 | 안전관리자 선임의무 O/X + 안전관리비 계상 기준 | **무료** | 건축 150억/토목 120억 기준 |
| 표준 | + 공사규모 + 하도급 수 + 근로자수 | 전체 의무 목록 + 벌칙·과태료 | **99,000원** | stage=1 CONSTRUCTION 173건 |
| 공정 | + 공정 선택(KCSC 161개 공정) | 공정별 위험작업 + 특별교육 대상 + 안전점검 항목 | **199,000원** | KCSC 데이터 161공정·243작업 |
| 종합 | + 착공일·준공 예정일 | 공정별 점검 일정 자동 생성 + TBM 자동 발령 + 신고서식 | **299,000원** | 건설 특화 알고리즘 |

### 건설 가격이 산업보다 높은 이유

```
1. 데이터 복잡도
   산업 설비: 보유 설비 목록에서 선택 (정적)
   건설 공정: 161개 공정 × 243개 위험작업
              × 착공일~준공일 전체 기간 (시간축 포함)
              → 훨씬 많은 데이터 처리

2. 시간적 범위
   산업: 현재 시점 스냅샷 진단
   건설: 공사 기간 전체 (착공~준공) 일정 자동 생성
         → 시간축이 있는 복잡한 구조

3. 법적 리스크
   건설 중대재해 발생 시:
   → 발주처·원청·하도급 모두 연루
   → 처벌 수위 산업 대비 높음
   → 고객이 느끼는 필요성·긴박감 높음

4. TBM·일정 자동생성 가치
   건설 종합: TBM 자동발령 + 공정별 일정 자동생성
   → 현장소장이 매일 사용하는 핵심 기능
   → 산업 설비 점검보다 실무 가치 높음

5. 고객 예산
   건설 안전관리비 법정 계상 의무
   100억 공사 기준 약 200만원 안전관리비 확보
   → 가격 저항 거의 없음
```

### 단계별 입출력 상세

| 단계 | 입력 | 출력 | 특이사항 |
|------|------|------|----------|
| 무료 | 공사유형(건축/토목) + 공사금액 | 안전관리자 선임의무 여부 + 안전관리비 계상 기준 | 건축 150억/토목 120억 기준 |
| 표준 | + 공사규모 + 하도급 업체수 + 근로자수 | 전체 의무 목록 + 벌칙·과태료 | stage=1 CONSTRUCTION 173건 |
| 공정 | + 공정 선택(KCSC 161개 공정) | 공정별 위험작업 + 특별교육 대상 + 안전점검 항목 | KCSC 데이터 161공정·243작업 |
| 종합 | + 착공일·준공 예정일 | 공정별 점검 일정 자동 생성 + TBM 자동 발령 + 신고서식 | 건설 특화 알고리즘 |

### 건설 공정 선택 UX 주의사항
```
161개 공정을 한 번에 보여주면 안 됨
→ 공사유형(건축/토목/공통) 먼저 필터
→ 20~30개만 표시
→ KOSHA 추천 공정 배지 우선 표시
→ 검색 기능 필수
```

## 분류 3 — 건물 (FACILITY)

### 대상
```
일반건물·복지시설·판매시설·의료기관
건물 자체가 대상 (업종보다 건물 용도·규모 중심)
소방·전기·승강기·시설물 안전 중심
건물주 or 관리사무소가 고객
```

### 법령진단 단계별 요금

| 단계 | 입력 | 출력 | 가격 |
|------|------|------|------|
| 기초 | 주소 입력 → 건축물대장 자동 채움 | 적용법령 수(숫자만) + 선임의무 O/X | **무료** |
| 표준 | + 건물용도 + 수전용량 + 승강기 수 | 법령명·조문·과태료 전체 | **79,000원** |
| 설비 | + 보유 설비(소방·전기·승강기 등) | 설비별 정기검사 주기·담당자 지정 | **129,000원** |
| 종합 | 표준 + 설비 통합 | 전체 의무 + 점검 일정 기준 | **179,000원** |

### 건물형 특이사항
```
건축물대장 API 자동 채움:
  주소 입력 → bdMgtSn 자동 수집
  → 연면적·층수·준공연도·건물용도 자동 채움
  → 사용자가 추가로 입력할 것이 거의 없음
  → 진입 장벽 최소화

건물형 가격이 산업형보다 낮은 이유:
  복잡도가 낮음 (설비 종류 적음)
  의무 수가 상대적으로 적음
  소규모 건물주·관리소 타깃
```

## 법령진단 → SaaS 전환 퍼널

```
[1회성 법령진단 구매]
  "우리 회사 의무가 이렇구나"
  → PDF 저장 → 끝 (구독 아님)

[BUT 실제 실행은?]
  → 시스템 없으면 안전관리자 혼자 다 해야 함
  → "이 의무들을 자동으로 관리해줬으면..."

[전환 유도]
  법령진단 결과를 TAI Safe에 연동하면
  이 의무들이 자동으로 관리됩니다.
  → 법령진단 구매자 첫 달 50% 할인

→ 법령진단이 SaaS 구독의 퍼널 역할
```

## 무료 단계 설계 원칙

```
무료에서 주는 것:
  법령 수 (숫자만) — 예: "14개 법령 해당"
  선임의무 여부 (O/X만) — 예: "안전관리자 선임 필요"

무료에서 주지 않는 것:
  법령명 (유료)
  조문 번호 (유료)
  과태료 금액 (유료) ← 핵심 전환 트리거
  점검 항목 (유료)

이유:
  과태료 금액을 보여줘야 구매 결정이 생김
  무료에서 너무 많이 주면 유료 전환 이유 없어짐
```
