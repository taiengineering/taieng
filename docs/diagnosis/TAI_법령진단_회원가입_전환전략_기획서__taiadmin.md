# TAI Safe 법령진단 — 회원가입 필수 전환 전략 기획서

> 작성일: 2026-03-31  
> 목적: 무료 체험 후 이탈 방지 + 유료 전환율 극대화

---

## 1. 핵심 원칙

```
회원가입을 해야만 무료 서비스 이용이 가능하다.

이유:
  무료 체험 후 나중에 결제하려는 사람은 거의 돌아오지 않음
  → 회원가입 = 이메일 확보 = 언제든 리마인드 가능
  → 입력 데이터 저장 = 이탈 후 복귀 시 이어서 진행
  → CRM 자동화 기반 구축
```

---

## 2. 전체 사용자 흐름

```
[홈페이지 진입]
  "우리 회사 안전관리 의무 무료로 확인하기"
  → [시작하기] 버튼
        ↓
[회원가입]
  이메일 + 비밀번호 (2개만)
  또는 카카오 / 구글 1클릭 로그인
        ↓
[무료 진단]
  KSIC(업종) + 근로자수 입력 (30초)
        ↓
[무료 결과 화면]
  적용 법령: 14개
  안전관리자 선임: 필요
  과태료 리스크: 최대 [블러 처리] ← 핵심 전환 트리거
        ↓
  [전체 내용 보기 — 99,000원]
        ↓
[결제 완료]
  이미 입력한 KSIC·근로자수 유지
  → 시설유형·위험물 추가 입력 안내
        ↓
[전체 결과 수령]
        ↓
[SaaS 구독 전환 유도]
  "이 의무들을 시스템이 자동으로 관리해드립니다"
  → 첫 달 50% 할인
```

## 3. 회원가입 화면 설계

### 3.1 마찰 최소화 원칙

```
나쁜 예 (마찰 높음 → 이탈률 80% 이상):
  이름 / 생년월일 / 전화번호 / 회사명
  / 사업자번호 / 업종 / 근로자수 / 주소
  → 처음부터 너무 많이 요구

좋은 예 (마찰 최소):
  이메일 + 비밀번호 (2개만)
  → 가입 완료
  → 이후 진단 과정에서 자연스럽게 추가 수집

최선 (마찰 없음):
  카카오 / 구글 소셜 로그인 1클릭
  → 즉시 진단 시작
  (B2B 특성상 카카오보다 구글 선호)
```

### 3.2 회원가입 화면 상단 문구

```
"무료로 우리 회사 안전관리 의무를 확인하세요.
 회원가입 후 결과가 저장되어
 언제든 이어서 볼 수 있습니다."

→ "왜 가입해야 하나"에 대한 답을 먼저 제시
→ 저항감 최소화
```

## 4. 무료 결과 화면 설계 — 전환 트리거

```
┌─────────────────────────────────────────────┐
│  📋 진단 결과 (무료)                        │
│                                             │
│  적용 법령:       14개                      │
│  안전관리자 선임: 필요 ✅                    │
│                                             │
│  과태료 리스크:   최대 ██,███만원  ← 블러   │
│  주요 법령명:     ████ / ████ / ████ ← 블러 │
│  점검 항목:       ██개 항목 미이행 ← 블러   │
│                                             │
│  ┌─────────────────────────────────────┐   │
│  │  전체 내용 보기                     │   │
│  │  법령명·조문·과태료 금액 전체 공개  │   │
│  │  → 99,000원                         │   │
│  └─────────────────────────────────────┘   │
│                                             │
│  결과를 이메일로 받아두기 →               │
└─────────────────────────────────────────────┘

핵심:
  과태료 금액이 블러 처리된 채로 보임
  "저 숫자가 얼마지?" → 결제 충동 유발
  법령명도 블러 → "어떤 법령이지?" → 궁금증 유발
```

## 5. 이탈 사용자 재유입 전략 (CRM 자동화)

### 5.1 이탈 시점별 대응

| 이탈 시점 | 상황 | 대응 |
|---------|------|------|
| 회원가입 후 진단 미완료 | KSIC 입력 안 함 | 1일 후 이메일: "진단을 완료해보세요" |
| 무료 결과 확인 후 미결제 | 과태료 블러 봄 | 당일 이메일: 결과 요약 + 결제 링크 |
| 결제 페이지 이탈 | 장바구니 이탈 | 1시간 후 이메일: "결제를 완료해보세요" |
| 결제 완료 후 입력 미완료 | 추가 입력 안 함 | 1일 후 이메일: "결과를 완성해보세요" |

### 5.2 이메일 시퀀스 (무료 결과 확인 후 미결제)

```
[즉시] 결과 요약 이메일
  제목: "귀사 안전관리 의무 진단 결과가 저장되었습니다"
  내용: 법령 14개 해당 / 안전관리자 선임 필요
        과태료 전체 금액 확인하기 → [링크]

[1일 후] 리마인드
  제목: "과태료 최대 ?,???만원 — 확인하셨나요?"
  내용: 어제 확인하신 진단 결과를 저장해뒀습니다
        지금 바로 확인 → [링크]

[3일 후] 사례 제시
  제목: "비슷한 업종 A사, 점검 누락으로 과태료 2,000만원"
  내용: TAI Safe로 예방하세요 → [링크]

[7일 후] 할인 유도
  제목: "이번 주 한정 10% 할인"
  내용: 지금 결제하면 89,100원 → [결제 링크]
```

### 5.3 링크 복귀 시 처리

```
이메일 링크 클릭 → 사이트 재방문:

  ✅ 기존 입력 데이터 유지
     (KSIC·근로자수 회원 데이터로 저장)

  ✅ 바로 결제 화면으로 이동
     (다시 입력할 필요 없음)

  ✅ 결제 완료 → 추가 입력만 하면 결과 완성
```

## 6. 회원가입 필수 구조의 장단점

### 장점

```
✅ 이탈 사용자 재유입 가능 (CRM 자동화)
✅ 입력 데이터 저장 → 이어서 진행 가능
✅ 결제 전환율 추적 및 개선 가능
✅ SaaS 구독 전환 자동화 기반 확보
✅ 고객 DB 구축 (혁신장터·조달청 영업 활용)
✅ 법령 변경 시 기존 회원에게 즉시 알림 가능
✅ 무료 체험 후 "나중에" 하려는 사람도 데이터 보존
```

### 단점 및 해결책

```
⚠️ 회원가입 자체가 이탈 포인트
   해결: 소셜 로그인 (카카오·구글) 1클릭

⚠️ "왜 가입해야 하나" 저항감
   해결: "결과 저장·이어보기를 위해 필요" 명시

⚠️ 스팸 이메일로 가입 후 진단만 하고 이탈
   해결: 이메일 인증 필수 (가입 즉시 인증 링크 발송)
```

## 7. 선결제 방식과의 비교

```
방법 A — 선결제 후 데이터 입력:
  장점: 이탈 방지 (매몰비용 효과)
  단점: 신뢰도 부족한 초기에 저항 큼
        "뭘 받는지도 모르고 결제?" 불안감
        공공기관·중견기업 결재 프로세스와 충돌
  → 레퍼런스 100개 이상 확보 후 도입 권장

방법 B — 회원가입 필수 + 부분입력 → 블러 → 결제 (채택):
  장점: 이탈 방지 효과 동일
        신뢰도 문제 없음
        "충격 → 결제 → 완료" 자연스러운 흐름
        CRM 자동화 기반까지 확보
  → 현재 단계에서 최적
```

## 8. 기술 구현 요건

| 항목 | 내용 | 우선순위 |
|------|------|--------|
| 회원가입 | 이메일+비밀번호 / 구글·카카오 소셜로그인 | 🔴 필수 |
| 세션 데이터 저장 | 무료 진단 입력값 회원 DB에 저장 | 🔴 필수 |
| 과태료 블러 처리 | 무료 결과 화면에서 금액·법령명 블러 | 🔴 필수 |
| 이메일 자동 발송 | 이탈 후 시퀀스 이메일 자동화 | 🟡 중요 |
| 링크 복귀 처리 | 이메일 링크 클릭 시 저장된 데이터 로드 | 🟡 중요 |
| 전환율 추적 | 무료→결제 전환율 대시보드 | 🟢 권장 |

## 9. 기대 효과

```
이탈 방지:
  회원가입 없는 구조: 무료 체험 후 재방문율 ~5%
  회원가입 필수 구조: CRM 이메일로 재방문율 ~25%

전환율 예측:
  무료 체험 → 유료 결제: 15~20%
  이메일 시퀀스 포함 시: 25~30%

LTV 향상:
  회원 DB 확보 → SaaS 구독 전환 자동화
  → 법령진단 1회성 고객이 구독 고객으로 전환
  → 객단가 99,000원 → 월 49,000원 × 12개월
```
