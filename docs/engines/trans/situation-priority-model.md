# Situation Priority Model

## 목적

운영자에게 "무엇을 먼저 봐야 하는가"를 결정하는 우선순위 모델.

## 우선순위 등급

| 등급 | 운영 표현 | 의미 |
|------|----------|------|
| P1 | 즉시 확인 필요 | 고객 영향 발생 중이거나 임박 |
| P2 | 주의 필요 | 위험 증가 추세, 곧 영향 가능 |
| P3 | 관찰 필요 | 이상 감지, 현재 영향 제한적 |
| P4 | 정보 수준 | 참고용 정보 |

## 판단 기준

| 요소 | 가중치 | 설명 |
|------|--------|------|
| 고객 영향 (customer_impact) | 40% | 사용자에게 직접 영향이 있는가 |
| 반복성 (repetition) | 20% | 같은 문제가 반복 발생하는가 |
| escalation 발생 | 15% | 심각도가 상승했는가 |
| degradation 수준 | 15% | 성능 저하 정도 |
| tenant 확산 (spread) | 10% | 여러 조직/사용자에 걸쳐 발생하는가 |

## 점수 → 등급 매핑

| 점수 범위 | 등급 |
|-----------|------|
| 0.75 이상 | P1 (즉시 확인 필요) |
| 0.50~0.74 | P2 (주의 필요) |
| 0.25~0.49 | P3 (관찰 필요) |
| 0.25 미만 | P4 (정보 수준) |

## 예시

| 상황 | customer_impact | repetition | escalation | degradation | spread | 점수 | 등급 |
|------|----------------|------------|------------|-------------|--------|------|------|
| 결제 반복 실패 | 1.0 | 1.0 | 0.5 | 0.5 | 0.3 | 0.76 | P1 |
| 문서 생성 지연 | 0.3 | 0.0 | 0.0 | 0.7 | 0.2 | 0.27 | P3 |
| 내부 배치 경고 | 0.0 | 0.0 | 0.0 | 0.3 | 0.0 | 0.09 | P4 |
