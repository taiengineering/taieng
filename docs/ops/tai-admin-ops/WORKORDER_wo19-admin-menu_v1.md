## 1. 현황 (실측)

- 운영자 어드민(admin.taieng.co.kr, role '001')의 메뉴는 `menu-nav.js`의 `MENU` 배열 하나로 관리(12그룹).
- **tadmin(safe SaaS 사용자)·site(마케팅)는 별개 — 손대지 않음.**
- 서비스 범위: 법령진단 + SaaS 2종 + 교육(매출 1순위). 미서비스: 수선·매칭·선임·견적·크몽·건설·컨설팅.

## 2. 재구성 원칙 (b: 미서비스 삭제 + 엔진 강등)

**유지(그대로):** 상황감시 / 고객 / 마케팅 / 교육 / SaaS / 법령진단 / 시스템
- 마케팅 그룹은 mkt 서빙 연계 — **보존**(사용자 지시).

**정리:**
- **결제**: 견적관리·견적설정 → 주석(미서비스). 결제내역·구독/계약·가격설정 유지.
- **매칭** 그룹 전체 → 주석(수선·수선설정·선임연결·크몽계약·크몽편집). 상담리스트(fix-chat)는 문의성이라 유지 판단 → 시스템/고객 쪽 검토(우선 주석 보류).
- **위험** 그룹: 산업 섹션(공정·설비·시설설비·점검) 유지. **건설 섹션 전체 주석**(건설현장~건설TBM). todo(미개발) 항목 주석.
- **엔진 + 관제엔진** → 하단 "개발자도구" 단일 그룹으로 강등(격리 엔진 관측 경로는 보존하되 맨 아래로).

**방식:** 미서비스=JS 주석(`// ...`)으로 오픈 대비. 엔진=배열 하단 재배치. 실제 서비스/운영 메뉴가 위에 오도록.
