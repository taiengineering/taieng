# tai-admin 파일정합성 작업지시서

> 작성: 2026-05-18
> 작업도구: Cursor (파일 수 100+ → MCP 부적합)
> 순서: 이동 → 삭제 → 검증

## 작업 전 주의사항
- 반드시 `git stash` 또는 브랜치 생성 후 작업
- 삭제는 `git rm -r`로 수행 (git 추적에서 제거)
- 커밋 메시지: `cleanup: 파일정합성 정리 - Phase N`

---

## Phase 1: 파일 이동

### 1-1. inspection-request.html → request/
```bash

```

### 1-2. payment/ → site/full-version/html/payment/

## Phase 3: 잡파일 정리

```bash
# macOS 메타 파일 전체 삭제 (.gitignore에 추가됨)
find . -name '.DS_Store' -type f -exec git rm -f {} \;

# 임시 파일
git rm -f temp_find.txt

# npm 캐시
git rm -rf .npm-cache/

# Cursor 설정 (이미 .gitignore에 포함되지만 추적 해제)
git rm -rf .cursor/cache/ 2>/dev/null || true
```
