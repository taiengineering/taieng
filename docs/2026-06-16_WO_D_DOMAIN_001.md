## ⚠️ 이 WO의 목적

```
목적 = 오염 제거가 아니다
목적 = 오염 알굴리즈가 조합 기준으로 얼마나 줄어드는지 측정하는 것

성공 기준:
  "CONSTRUCTOR 의무를 제거했다" → 아님
  "CONSTRUCTOR 의무임을 식별하고 제조업에서의 감소량을 측정했다" → 맞음

DROP 여부는 이 WO에서 저장하지 않는다.
actor + sector 조합으로 domain_verdict만 생성한다.
```

## 배경 — 실측으로 확인된 취거

### Track A 오염 구조 (실측 거본)

**K-05 글읽기 결론**: BUSINESS actor 34건 중 Domain 오염 ~25건

| 법령 | actor_code | law_sector_mapping | 오염 이유 |
|---|---|---|---|
| 소방시설공사업법 | ACTOR:CONSTRUCTOR | BUILDING, CONSTRUCTION | pass-through 오염 |
| 건설산업기본법 | ACTOR:CONSTRUCTOR | CONSTRUCTION | pass-through 오염 |
| 공동주택관리법 | ACTOR:MANAGER | BUILDING, CONSTRUCTION | pass-through 오염 |
| 건축물관리법 | ACTOR:MANAGER | BUILDING | pass-through 오염 |
| 정보통신공사업법 | ACTOR:CONSTRUCTOR | BUILDING, CONSTRUCTION | pass-through 오염 |
| 화재예방법 (제24조 소방안전관리) | ACTOR:MANAGER | **BUILDING+INDUSTRIAL+CONSTRUCTION** | INDUSTRIAL 매핑 존재 |

**핵심 발견**: law_sector_mapping은 이미 정상 (건설산업기본법에 INDUSTRIAL 없음). 
문제는 Track A가 이 매핑을 무시하고 실행하는 것 — **pass-through 오염**.

## WO-D-DOMAIN-001 설계

### 입력
```
Track A 결과 (facility_applicability rows)
semantic_clause_actor_resolution
law_sector_mapping
facility.sector (= INDUSTRIAL / BUILDING / CONSTRUCTION)
```

### 출력 테이블: `domain_filter_result`

```sql
CREATE TABLE domain_filter_result (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    facility_id UUID NOT NULL,
    draft_id UUID NOT NULL,
    law_id UUID,
    law_name TEXT,
    facility_sector TEXT,
    actor_group TEXT,
    actor_code TEXT,
    law_sectors TEXT[],           -- law_sector_mapping.sectors
    domain_verdict TEXT,          -- DOMAIN_KEEP / DOMAIN_MISMATCH / DOMAIN_REVIEW
    mismatch_reason TEXT,         -- 판정 근거
    created_at TIMESTAMPTZ DEFAULT now()
);
```

### domain_verdict 정의

```
DOMAIN_KEEP:
  facility_sector=INDUSTRIAL + actor_group=BUSINESS
  + law_sectors contains INDUSTRIAL
  → 업종 일치

DOMAIN_MISMATCH (강한 제외 신호):
  facility_sector=INDUSTRIAL
  + actor_code = ACTOR:CONSTRUCTOR
  → MISMATCH (law_sectors 무관하게)

  facility_sector=INDUSTRIAL
  + actor_group = AUTHORITY
  → MISMATCH

DOMAIN_REVIEW (쫐토 필요):
  facility_sector=INDUSTRIAL
  + actor_code = ACTOR:MANAGER
  + law_sectors NOT contains INDUSTRIAL
  → REVIEW

  facility_sector=INDUSTRIAL
  + actor_group = ASSOCIATION
  → REVIEW

  actor_group = UNKNOWN
  → REVIEW (분류 불가)
```

### 1차 규칙 (화성 제2공장 기준)

```
facility_sector = INDUSTRIAL

+ actor_group = AUTHORITY → MISMATCH
+ actor_code = ACTOR:CONSTRUCTOR → MISMATCH
+ actor_code = ACTOR:MANAGER + law ∈ {BUILDING only} → MISMATCH
+ actor_code = ACTOR:MANAGER + law ∈ {INDUSTRIAL} → KEEP
+ actor_group = ASSOCIATION → REVIEW
+ actor_group = FRAGMENT → MISMATCH
+ actor_group = UNKNOWN → REVIEW
+ actor_group = BUSINESS + law_sectors ∈ {INDUSTRIAL} → KEEP
+ actor_group = BUSINESS + law_sectors NOT ∈ {INDUSTRIAL} → REVIEW
```
