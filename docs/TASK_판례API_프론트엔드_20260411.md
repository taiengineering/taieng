## 작업 1. nexas/index-5.html — 안전정보 페이지 신규

### URL
`new.taieng.co.kr/nexas/index-5.html`

### 페이지 구조

```
[GNB]

[Hero 섹션]
  태그: "안전정보"
  타이틀: "안전관리자가 꼸어야 할 정보"
  서브: "법령 개정·재해사례·판례를 매주 업데이트합니다"

[탭]
  [엔산안전 판례] [산재판례] [개정뉴스]

[판례 목록 섹션] ← API 로드
  검색바 (query 입력)
  카드 형식:
    사건명 / 법원명 / 선고일자
    판결유형 (보조/파기/인용)
    [판례 보기] 버튼 → 판례상세링크 새새 열기

[Footer]
```

### API 호출

```javascript
const API = 'https://api.taieng.co.kr';

// 산업안전 전체 판례
async function loadSafetyPrecedents(query = '산업안전보건', page = 1) {
  const res = await fetch(
    `${API}/precedents/search?query=${encodeURIComponent(query)}&page=${page}&size=10`
  );
  return (await res.json()).data;
}

// 산재 전문 판례
async function loadSanjae(query = '산재', page = 1) {
  const res = await fetch(
    `${API}/precedents/search?query=${encodeURIComponent(query)}&source=sanjae&page=${page}&size=10`
  );
  return (await res.json()).data;
}
```

### 렌더링 규칙

```
카드 1개 구성:
  상단: 데이터출처 백지 (산재=주황 / 안전=네이비)
  주말: 사건명
  하단: 법원명 · 선고일자 · 판결유형
  리크: 판례상세링크 (새새 열기)

판결유형 표시:
  기각 → 빨간 보라
  인용 → 초록 보라
  파기 → 회색 보라

룡드 중 스피너 표시
API 실패 시 오류메시지 표시 (하드코딩 fallback 금지)
```

### 디자인 요구사항
- `tai-main.css` 기존 스타일 사용
- 을떡 배경 (var(--navy)) + 다크 헤더
- 판례 카드는 흰 배경 / 취수 아코디언 스타일
- 페이지네이션 (이전/다음 버튼)

## 작업 2. safe.taieng.co.kr — 안전정보 판례 섹션 추가

**파일:** `site/full-version/html/front-pages/safety-news.html`

현재 페이지 엔에 판례 섹션 추가:

```html
<!-- 기존 안전뉴스 섹션 아래에 추가 -->
<section class="sec" id="precedents">
  <div class="sec-inner">
    <div class="text-center mb-4">
      <span class="sec-tag">판례</span>
      <h2 class="sec-h2">산업안전 관련 판례</h2>
    </div>

    <!-- 탭: 안전전체 | 산재전문 -->
    <div class="d-flex gap-2 mb-4">
      <button onclick="loadPrecedents('all')">... </button>
      <button onclick="loadPrecedents('sanjae')">...</button>
    </div>

    <!-- 판례 목록 -->
    <div id="prec-list">...</div>
  </div>
</section>
```

**API 호출:**
```javascript
async function loadPrecedents(source) {
  const params = source === 'sanjae'
    ? '?query=산재&source=sanjae&size=5'
    : '?query=산업안전&size=5';
  const res = await fetch('https://api.taieng.co.kr/precedents/search' + params);
  const data = (await res.json()).data || [];
  renderPrecedents(data);
}
```
