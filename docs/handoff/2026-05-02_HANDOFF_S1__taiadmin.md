## 2. α 검증 기준 (확정)

### 2.1 의무 동사 사전 (한국어, obligation_type별)
| obligation_type | 의무 동사 |
|---|---|
| `ACTION` | 조치, 이행, 실시, 시행 |
| `NOTIFY` | 통보, 통지, 알림 |
| `REPORT` | 보고, 신고, 제출 |
| `INSPECT` | 점검, 검사, 진단, 측정, 평가 |
| `APPOINT` | 선임, 지정, 임명, 위촉 |
| `BEFORE_WORK` | 작업전, 시작 전, 착공 전 |
| `DOCUMENT` | 작성, 비치, 보존, 기록, 게시 |

### 2.2 판정 기준 (결정론적)
- **필수**: obligation_type 매핑 의무 동사 ≥1개가 `law_article.article_text`에 존재
- **추가**: `obligation_summary`에서 길이 3+ 한글 토큰 중 ≥2개가 `article_text`에 존재
- **합산 ≥3개 일치 시 A_PASS**
