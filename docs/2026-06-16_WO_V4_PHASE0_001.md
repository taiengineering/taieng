## Phase 0A — 확정 (이 WO 범위)

### 1. TriValue / TriList ✅ 승인

```
TriValue<T> = {
  state: PRESENT | ABSENT | UNKNOWN
  value: T | null
}

원칙: 결측 = UNKNOWN. 0으로 채우지 않는다.

배경:
  미입력 → 0 저장 → N 이하 → 자동 통과
  이 문제는 어떤 엔진을 만들든 다시 나타난다.
  PRESENT / ABSENT / UNKNOWN 3치는 설계 원칙으로 고정.

TriList<T> = {
  confirmed: [T]      -- 있다고 확인된 것
  denied: [T]         -- 없다고 확인된 것
  unknown_rest: bool  -- 나머지가 모름 상태인가
}
```

### 3. FacilityProfile v1.0 골격 ✅ 승인

```
FacilityProfile {
  profile_id: UUID
  sector: INDUSTRIAL | BUILDING | CONSTRUCTION
  ksic_code: str

  building: {
    use_code:    TriValue<BLDG:USE_CODE>
    floor_area:  TriValue<float>           -- ㎡
    floor_count: TriValue<int>
  }

  workforce: {
    regular_workers:     TriValue<int>
    subcontract_workers: TriValue<int>
  }

  processes:  TriList<PROC:*>             -- Phase 0B
  equipment:  TriList<EQUIP:*>            -- Phase 0B
  materials:  TriList<MAT:*>              -- Phase 0B
  activities: TriList<ACT:*>              -- Phase 0B

  metrics: {
    construction_amount: TriValue<float>
    electrical_kw:       TriValue<float>
    gas_capacity:        TriValue<float>
  }

  provenance: {
    입력값:  [field, ...]   -- 사용자가 직접 입력한 것
    확장값:  [field, ...]   -- KSIC 추론으로 채운 것
    기본값:  [field, ...]   -- 기본값 적용한 것
  }
}

원칙:
  결측 컬럼 → UNKNOWN (0 채우기 금지)
  입력하지 않은 항목 → unknown_rest: true
  provenance는 Phase 0부터 필수
  (사용자 입력 vs KSIC 추론 vs 공정 추론 구분 없으면 디버깅 불가)
```

### 4. ApplicabilityCondition v1.0 골격 ✅ 강력 승인

```
ApplicabilityCondition {
  condition_id: UUID

  source: {
    law_id:        UUID
    article_id:    UUID
    part_ref:      str     -- 항·호·목
    raw_text_span: str     -- 원문 텍스트
  }

  actor: {
    code: ACTOR:OWNER | ACTOR:GOV | ...
    raw:  str
  }

  quantifiers: [{
    metric:       METRIC:*
    subject_raw:  str      -- "상시근로자" 등 원문 주어 (필수)
    operator:     >= | > | <= | < | ==
    value:        float
    unit:         str
  }]

  obligation: {
    action_type:   APPOINTMENT | INSTALLATION | REPORT | ...
    action_text:   str
    deadline:      str
    frequency:     str
    penalty_ref:   UUID
  }

  completeness: {
    actor_coded:            bool
    quantifiers_subject_ok: bool   -- subject_raw 있는가
  }

  status: ACTIVE | QUARANTINED
  quarantine_reason: str
}

원칙:
  subject_raw = 필수 (선택 아님)
  배경: "50명"만 남고 "누구 50명인가"가 사라진 것이
        이전 엔진 수차례 붕괴 원인 중 하나
  subject_raw 없으면 completeness 실패 → QUARANTINED
  actor UNKNOWN이어도 보존 (버리지 않음)
  탈락 = 보류, 소멸 금지
```
