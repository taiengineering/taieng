## Phase 0A — 즉시 확정 가능 (이 WO 범위)

### 1. TriValue / TriList

```
TriValue<T> = {
  state: PRESENT | ABSENT | UNKNOWN
  value: T | null
}

원칙: 결측 = UNKNOWN. 0으로 채우지 않는다.

TriList<T> = {
  confirmed: [T]      -- 있다고 확인된 것
  denied: [T]         -- 없다고 확인된 것
  unknown_rest: bool  -- 나머지가 모름 상태인가
}
```

### 2. Registry Namespace v1.0

```
즉시 확정:
  ACTOR:OWNER         사업주, 사업자
  ACTOR:CONSTRUCTOR   건축주, 시공자, 도급인
  ACTOR:MANUFACTURER  제조자, 수입자, 판매자
  ACTOR:MANAGER       관리주체, 소유자, 점유자
  ACTOR:GOV           장관, 대통령, 청장

  ACTOR:ASSOCIATION   협회, 조합
```

### 3. FacilityProfile v1.0 골격

```
FacilityProfile {
  profile_id: UUID
  sector: INDUSTRIAL | BUILDING | CONSTRUCTION
  ksic_code: str                           -- 업종 코드

  building: {
    use_code:    TriValue<BLDG:USE_CODE>
    floor_area:  TriValue<float>           -- ㎡
    floor_count: TriValue<int>
  }

  workforce: {
    regular_workers:     TriValue<int>     -- 상시근로자
    subcontract_workers: TriValue<int>     -- 수급인 근로자
  }

  processes:  TriList<PROC:*>             -- Phase 0B
  equipment:  TriList<EQUIP:*>            -- Phase 0B
  materials:  TriList<MAT:*>              -- Phase 0B
  activities: TriList<ACT:*>              -- Phase 0B

  metrics: {
    construction_amount: TriValue<float>  -- 억원
    electrical_kw:       TriValue<float>
    gas_capacity:        TriValue<float>
  }

  provenance: {
    입력값:  [field, ...]
    확장값:  [field, ...]   -- KSIC 추론으로 채운 것
    기본값:  [field, ...]   -- 기본값 적용한 것
  }
}

원칙:
  결측 컬럼 → UNKNOWN (0 채우기 금지)
  입력하지 않은 항목 → unknown_rest: true
```

### 4. ApplicabilityCondition v1.0 골격

```
ApplicabilityCondition {
  condition_id: UUID

  source: {
    law_id:        UUID
    article_id:    UUID
    part_ref:      str     -- 항·호·목
    raw_text_span: str     -- 원문 텍스트
  }

  actor: {
    code: ACTOR:OWNER | ACTOR:GOV | ...
    raw:  str
  }

  quantifiers: [{
    metric:       METRIC:*
    subject_raw:  str      -- "상시근로자" 등 원문 주어 (필수)
    operator:     >= | > | <= | < | ==
    value:        float
    unit:         str
  }]

  obligation: {
    action_type:   APPOINTMENT | INSTALLATION | REPORT | ...
    action_text:   str
    deadline:      str
    frequency:     str
    penalty_ref:   UUID
  }

  completeness: {
    actor_coded:            bool
    quantifiers_subject_ok: bool   -- subject_raw 있는가
  }

  status: ACTIVE | QUARANTINED
  quarantine_reason: str
}

원칙:
  subject_raw 없으면 completeness 실패 → QUARANTINED
  actor UNKNOWN이어도 보존 (버리지 않음)
  탈락 = 보류, 소멸 금지
```
