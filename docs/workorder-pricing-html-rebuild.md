## 배경

현재 pricing.html은 확정된 가격체계와 완전히 다릅니다.
SMS/카카오/서류/TBM 노출은 삭제 완료했으나, 가격과 구조 자체가 불일치합니다.

## TAI 역할 (반드시 준수)

- TAI는 대행이 아닙니다
- SaaS = 안전관리를 직접 하게 해주는 도구
- 법령진단 = 미리 알고 대비하게 하는 1회성 리포트 서비스
- 선임/수선/진단 = 연결하고 수수료를 받는 역할
- 대행기관은 경쟁자가 아니라 연결 서비스의 공급자(파트너)
- 금지 용어: 소개비, 소개수수료, 인력소개, 소개료, 크레딧

### 법령진단 (1회성 리포트)

| 단계 | 내용 | 가격 |

## API 연동 (어드민 가격수정 → 사이트 자동 반영)

```javascript
// 페이지 로드 시 API에서 가격 가져오기
async function loadPricing() {
  try {
    const [saas, diag] = await Promise.all([
      fetch('https://api.taieng.co.kr/public/pricing/saas-plans').then(r => r.json()),
      fetch('https://api.taieng.co.kr/public/pricing/diagnosis-reports').then(r => r.json())
    ]);
    renderSaasPlans(saas);  // sector_code별로 그룹핑하여 렌더링
    renderDiagnosis(diag);  // facility_type_code별로 렌더링
  } catch(e) {
    renderFallback();  // API 실패 시 하드코딩 가격 표시
  }
}

// API 응답 구조 (public_pricing.py)
// GET /public/pricing/saas-plans → is_active=true만
//   각 레코드: { plan_code, display_name, sector_code, monthly_base_fee, ... }
//   sector_code: BUILDING / INDUSTRY / CONSTRUCTION
//
// GET /public/pricing/diagnosis-reports → is_active=true만
//   각 레코드: { facility_type_code, basic_fee, process_fee, equipment_fee, total_report_fee }
//   facility_type_code: BUILDING_V2 / INDUSTRY_V2 / CONSTRUCTION_V2
```

fallback(API 실패 시) 하드코딩 가격:
- 건물 BASIC 59000, STANDARD 99000
- 산업 STARTER 79000, BUSINESS 149000, PRO 249000
- 건설 STANDARD 199000, PREMIUM 399000
- 법령진단 건물 299000, 산업 99000/199000/249000, 건설 299000

## 주의사항

- 법령진단 = 리포트만 제공. "점검항목 자동 생성" "일정 자동 생성" 등은 SaaS 기능이므로 법령진단 카드에 넣지 말 것
- 법령진단 카드 기능 목록: "PDF 법령진단 리포트", "적용 법령·의무 도출", "과태료·벌칙 정보", "감사 대응 서류 활용" 정도
- 과금 기준을 반드시 명시: "시설당 월정액" 또는 "현장당 월정액"
- 모든 가격에 "VAT 별도" 표시
- CUSTOM 플랜은 가격 대신 "별도 협의" + [도입 문의하기] 버튼
- pricing.js 파일이 있다면 API 연동 로직은 그쪽에 작성
