## ★ 내일 풀어야 할 핵심 (멈춘 지점)

**"조문에서 OK 주어 빌리기" 전략이 표본 검증에서 깨졌다.** 표본 18개 중 절반이 틀림:
- 건축법시행령51조 "배연설비를 해야 한다" → 빌린주어 "소방관" ✗ (진짜=건축주/소유자)
- 응급의료법48조 "응급의료기관의 장은…" → 빌린주어 "보건복지부장관" ✗
- 피난방화규칙10조 "출구로 쓰이는 문은…" → "출구"(사물) ✗
원인: 긴 조문은 항마다 주어가 다름. 조문 전체에서 하나 빌리는 건 너무 거침.

**발견된 더 정확한 단서:** 갈래1 절의 진짜 주어는 대개 그 의미절의
`source_part_text`(원문 전체) **맨 앞**에 있다 (17조 "사업주는…", 재난법41조
"관계 중앙행정기관의 장은…"). 분해기가 절을 쪼개며 뒤토막 주어를 잘못 집은 것.

**수정 후보 전략 (미검증):**
```
1. 갈래1 의미절의 source_part_text 맨 앞을 Kiwi 분석
2. 맨 앞 명사 주어(NNG/NNP + 은/는/이/가) 추출
3. OK 명사면 executor_fixed에 채움
4. 맨 앞이 사물(출구/구조부재)이거나 못 찾으면 → needs_review (자동보정 안 함)
```
→ 이 전략도 **표본 검증 필요**(대표: "루프 들어갈 확률 100%"라 신중히).
   Kiwi 필요 → Cursor 작업. 표본 통과해야 자동보정.
