## 2. 돌아갈 자리 = 의무추출 고도화 (17차 본체)

### ★ 섹터 구분 방식 (2026-06-30 현재 DB 직독 — 5월 근거 폐기)
**경고: 5월(5/8·5/9) 문서의 master_rule_v2 구조 설명은 현재 DB와 불일치. 17차 이전 문서이므로 폐기.** 아래는 서울 DB 실제 COUNT 직독값:

- **`master_rule_v2` = 0행. `master_rule_scope` = 0행. `master_rule_scope_threshold`/`_mapping`/`master_rule_v2_relation` = 모두 0행.** → 5월 문서가 말한 "58,495행 마스터 + sectors ARRAY 거처"는 **현재 DB에 존재하지 않음.** master_rule_v2를 섹터 근거로 쓰면 안 됨(비어있음).
- **현재 살아있는 섹터 구분 = `law_sector_mapping` (393행, sectors ARRAY).** 법령↔섹터 매핑. (← 이번 직독으로 확정, 대표 확인 "393 맞음")
- `semantic_clause` = 58,495행 존재하나 sector(구 단일, COMMON 포함)=폐기데이터, sectors(ARRAY)=빈채움. **섹터 판정 근거 아님.**
- 폐기 테이블은 이름으로 격리됨: `master_building_legal_rules_legacy_contaminated`, `master_legal_rules_*_legacy_contaminated`, `master_legal_rules_archive`. **재사용 금지.**
- 도메인 분류 `law_master.domain_code`(11종, LABOR 등)는 5월 직독값이라 **현재 재확인 필요**(이번 창 미확인).

→ **C급 검증의 올바른 1차 대상 = `law_sector_mapping`(393). master_rule_v2/scope는 비어 있어 현재 근거 불가.**
→ 다음 직독: law_sector_mapping 구조·내용 → 섹터 구분 방식 확정 → C급(노무 혼입) 필터 레버 식별.
