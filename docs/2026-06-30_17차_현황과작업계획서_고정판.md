## 3. 작업 방식 (헌법 TASK-007 Boundary Check 내장 — 폭주 방지)
**모든 신규 작업 첫머리에 Boundary Check:**
```
Applicability 내부 작업인가?   YES/NO
Boundary 변경 필요한가?         YES/NO
Data Contract 변경 필요한가?    YES/NO
Breaking Change인가?            YES/NO
→ "① 내부 YES, 나머지 전부 NO" = 바로 진행
→ 하나라도 YES = 중단, Architecture Review 먼저(구조 재개는 여기 해당)
```
- 한 번에 **1 영역 × 1 의무유형 × 1 사업장**. 조문 원문(law_article_part) 글읽기 대조. **건수/목업 수량 판단 금지**(오픈 전이라 프로그램 결과·업체는 목업일 수 있음. 진짜 자산=법령원문+의미절).
- 정교화 항목만 기록. 새 매핑/구조/레이어 = 헌법 위반(승인·Review 필요).
- ③ Check Engine / 판정로직 / engine = GPT 영역. 읽기 분석·호출만.
- STOP 즉시 존중. 구조 재추적 충동 = 이 문서 0장으로 복귀.
