## 2. 돌아갈 자리 = 의무추출 고도화 (17차 본체)
정의: **Applicability → Obligation 의 법령 정확도를 높인다.** (코드 구조가 아니라 의무 데이터의 법적 정확성)

### 검증 기준점 (확정)
- 단일 진실 원천 = `law_article_part` (143,549행, 조문 원문).
- 의무 텍스트층 = `semantic_clause` (58,495행 / OBLIGATION 29,665 / 사업주 1,294). source_article_id → law_article_part 연결.
- 적용조건 데이터 = `applicability_conditions` (law_name·appendix_no·actor_raw·metric·operator·threshold·action_text).
- 원칙: **건수 아닌 문장 직독**. **순환검증 금지**(파생 candidate로 검증 불가, 원문으로만). LLM은 검증 보조만, 핵심 판정 불가.

### 식별된 부정확 (VERIFY-002, factory 1427367d 기준 직독)
A(정확) 44% / B(관련) 34% / C(무관) 22% / 필수누락 8건. 원인 3종:
1. **C급 22% — BUSINESS:REGISTERED 과잉**: law_type/sector 필터 부재로 노무법령 혼입(장애인차별·예술인출산휴가·직기 등).
2. **키워드 의미 충돌**: 크레인→타워크레인, 고압가스→잠함 조문 오매칭.
3. **필수의무 8건 누락**: 산소농도 측정·발파 통제구역·발파 경고·발파계획·크레인 점검/자격·굴착기 작업계획서·전도방지. action_text 키워드 패턴 협소.

### 이 창에서 추가로 직독된 applicability_condition 정교화 항목 (참고)
인원 임계(EMPLOYEE_COUNT)로 환원되며 원문의 비(非)인원 조건이 누락되는 경향:
- 제129조 건강진단: 주기(사무직 2년/그 외 1년) 조건 누락, 인원 1명 임계로만.
- 제16조 관리감독자: "지휘·감독 직위" 조건이 인원 임계로 환원(과생성 위험).
- 제29조 교육: 3종 분리는 정확하나 주기 구분 없음.
- 제19조 경보용 설비: EMPLOYEE_COUNT>=50 임계가 원문 근거와 맞는지 원문 대조 필요.

※ 위 항목들은 **원문 대조로 확정 전**이며 정교화 후보일 뿐. 확정은 law_article_part 직독으로만.

## 3. 작업 방식 (벗어나지 않기 위한 규칙)
- 한 번에 **원인 1종 × 사업장 1건**만. 의무를 조문 단위로 글로 읽어 A/B/C/누락 분류(VERIFY-002 방식).
- 코드(서비스/라우터/adapter/enum) 분석 금지. 데이터(applicability_conditions·obligation·semantic_clause)와 조문 원문만 읽는다.
- 정교화 항목만 기록, 구현·새 매핑·새 분류 제안 금지(별도 대표 승인 시에만).
- 매 STEP STOP 존중. 범위 밖으로 새면 즉시 중단.
- diagnosis_service / engine / applicability 판정계층 = GPT 영역. 읽기 분석만 허용, 수정 핸드오프 금지(키매칭 표면 복구 제외).
