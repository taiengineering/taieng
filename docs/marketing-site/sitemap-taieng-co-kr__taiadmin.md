# taieng.co.kr 사이트맵 (2026-04-12 기획 확정)

> 대표 + Claude(Opus) 기획 토의 기반. 웹사이트 리디자인 시 이 문서를 참고할 것.

---

## 설계 원칙

1. **역할 기반 접근** — 안전관리자 vs 사업주/현장소장, 같은 제품이지만 다른 언어로 말한다
2. **메인 페이지는 1가지만 전달** — "이 서비스가 나한테 필요한가?" 3초 안에 판단
3. **히어로 슬라이더 6개 → 고정 1개** — 핵심 메시지 + CTA 1개 + 제품 스크린샷
4. **톤 통일** — 위협/친근/도발/비전 혼재 금지, 일관된 전문성 있는 톤
5. **서비스별 별도 페이지** — 메인에서 모든 것을 설명하지 않음
6. **디자이너에게 지시하듯** — 레퍼런스 + 특징 + 구조 설명 + 섹션 단위 검수

## 대표 스토리 (about.html 핵심 콘텐츠)

> 전기기사를 준비하면서 안전관리자 선임을 생각했을 때, 혼자 감당할 수 없다는 것을 깨달았습니다.
> 법을 모르고, 뭘 해야 하는지 모르고, 혼자 다 해야 하는 구조.
> 현실은 요식행위 — 안 걸리면 그만, 퇴사하면 그만.
> 하지만 작업자가 대충이라도 체크하는 것이 아예 안 하는 것보다 낫습니다.
> 그래서 TAI Safe를 만들었습니다.
