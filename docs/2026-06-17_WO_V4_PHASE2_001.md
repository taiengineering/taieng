## C1 파일럿 평가 규칙

```
입력:
  FacilityProfile.workforce.regular_workers (TriValue)
  ApplicabilityCondition.quantifiers[0] (metric, operator, value)

규칙:
  regular_workers.state = PRESENT
    → value operator threshold 비교
    → True  = MATCH
    → False = NOT_MATCH

  regular_workers.state = UNKNOWN
    → UNKNOWN (비교 불가)

  regular_workers.state = ABSENT
    → NOT_APPLICABLE

  actor ≠ ACTOR:OWNER
    → NOT_APPLICABLE (즉시)
```

## 성공 기준 SC-01 ~ SC-06

```
SC-01: ApplicabilityCondition 생성
  appendix_condition 7건 → ApplicabilityCondition 7건 (100%)

SC-02: C1 평가 정확도
  화성 제2공장 (280명) × "≥50명" 조건 → MATCH

SC-03: 판정 결과
  화성 제2공장 → REQUIRED 1명 판정

SC-04: Golden Reference 일치
  pilot_safety_manager_api 결과 == 새 엔진 결과 (100% 동일)

SC-05: UNKNOWN 처리
  근로자수 미입력 → UNKNOWN (REQUIRED/NOT_REQUIRED 아님)

SC-06: 빈 사업장 전체 UNKNOWN
  CASE-02 (모든 값 null)
  regular_workers = UNKNOWN
  → MATCH 0건 / NOT_MATCH 0건 / UNKNOWN 7건
  (null → 0 → 자동매칭 재발 방지 검증)
```
