## OUTPUT_ABSENT 집계 (입력엔 존재, 결과엔 0회 등장)

```
다음 건설 입력 항목들은 10건 전체에서 INPUT에 존재했으나
OUTPUT(결과 의무)에는 단 한 번도 등장하지 않음:

  건설유형 (조경/토목/전문공사/건축/산업환경설비)
  하도급업체수
  타워크레인        (샘플 2,3,4,7,8,9에 입력 존재)
  밀폐공간          (샘플 1,8,9에 입력 존재)
  석면              (샘플 1,5,6,7,9,10에 입력 존재)
  발파              (샘플 2,4,8,9,10에 입력 존재)
  잠수              (샘플 2,3,4,6,7,10에 입력 존재)
  건설공정 (CP-100~500: 토공사/골조/마감/철거/설비)
  건설작업 (CW-210~420: 굴착/흙막이/철근/콘크리트/도장/방수)
  건설작업인원
  굴착작업 / 고소작업 / 양중작업 / 해체작업
  비계작업 / 거푸집작업 / 용접작업 / 전기작업 / 화기작업

→ OUTPUT_ABSENT = 건설 관련 입력 항목 전부.
```

## OUTPUT_PRESENT 집계 (결과에 등장한 의무 = 전부 비건설)

```
10건 결과에 등장한 의무 (전부 일반 산업 의무):
  경보용 설비 설치
  기타사업 1000명+ 안전관리자 2명 (1000명 이상 샘플)
  기타사업 50-999 안전관리자 1명
  관리감독자 지정
  위험성평가 실시
  일반건강진단
  정기 안전보건교육 / 채용시 교육 / 작업변경 교육

→ OUTPUT_PRESENT = 건설 고유 의무 0개. 전부 비건설 일반 의무.
```

## 대응 요약 (3열)

```
INPUT_PRESENT   = 건설 항목 12~17개 (10건 전부 풍부)
OUTPUT_PRESENT  = 일반 의무 8~9개 (10건 전부 비건설)
OUTPUT_ABSENT   = 건설 항목 전부 (10건 전부 건설 고유 의무 0)

10건 모두 동일 구조:
  건설 입력은 풍부하게 들어갔다.
  결과 의무는 전부 비건설이다.
  입력의 건설 항목 중 결과에 등장한 것은 0개.
```
