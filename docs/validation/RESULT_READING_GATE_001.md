# RESULT READING GATE — 현재 결과 읽기 기반 판정
# WO-RESULT-READING-GATE-001

**목적**: 숫자가 아니라 "무슨 의무가 나왔는가"로 판정. 변경 없음.
**평가축**: 개수 → 내용. PRESENT/WRONG 숫자는 참고일 뿐.

---

## STEP-1: 현재 유지 상태 결과 (6건, 실제 문장)

```
1. 작업환경측정 고시 — "시료채취 근로자수"        (MEASURE, 점검)
2. 방사선 안전관리 규칙 — "화재방호시설"           (INSTALL, 서류)
3. 친환경주택 건설기준 — "설계조건"               (ACTION, 서류)
4. 건설기술 진흥법 시행령 — "소규모 건설공사 안전관리계획의 수립 등" (REPORT, 신고)
5. 건설기술 진흥법 시행령 — "안전점검의 시기ㆍ방법 등"  (REPORT, 신고)
6. 건설기술 진흥법 시행령 — "안전관리계획의 수립"      (REPORT, 신고)
```

---

## STEP-2~3: 5분류 (문장 읽기 기반)

```
A. 사업장 안전의무
   - 안전관리계획의 수립 (건설기술진흥법) ★ 건설 MUST
   - 소규모 건설공사 안전관리계획의 수립 등 ★ 건설 MUST
   - 안전점검의 시기·방법 등 ★ 건설 MUST
   = 3건. 전부 건설 정답지 핵심 의무.

B. 위험요소 안전의무
   - 없음 (타워크레인/석면/발파/밀폐/잠수 미출현)

C. 기술기준
   - 방사선 안전관리 "화재방호시설" (설비 설치 기준 성격)
   - (친환경주택 "설계조건"도 기술기준에 가까움)
   = 1~2건.

D. 행정절차
   - 없음 (소방 자체점검/등록 등 정화로 제거됨)

E. 기관 의무
   - 없음

[분류 애매]
   - 작업환경측정 "시료채취 근로자수": 산업 의무이나 건설현장엔 부분 해당.
     화학물질 취급 시 적용 → 건설 기본의무는 아님. (경계: A/C 사이)
```

---

## STEP-4: GOOD/BAD 판정 (내용 기반)

```
판정: GOOD

근거 (숫자 아닌 내용):
  - 결과의 핵심(건설기술진흥법 3건)이 전부 A(사업장 안전의무).
  - 건설 MUST 정답지(안전관리계획/안전점검)가 실제 문장으로 출현.
  - C(기술기준)는 1~2건으로 소수, D(행정)·E(기관)은 0건.
  - 직전(소방 98% 오염)과 비교하면 질적으로 전혀 다른 결과.

단 한계 (내용 기반):
  - B(위험요소 안전의무) = 0. 타워크레인/석면 등 아직 결과에 없음.
  - 잔존 비A 3건(작업환경측정/방사선/친환경주택)은 건설 핵심의무 아님
    (오염은 아니나 건설 사업장 안전의무도 아닌 주변 의무).
  - A 3건이 전부 rule_type=REPORT(신고)·category=신고:
    "계획 수립"이 "신고" 의무로 표현됨 → 의무 성격 표현은 다음 단계 점검 대상.

= "오염 없고 건설 핵심의무가 나오는 GOOD 상태. 단 B(위험요소) 비어있음."
```

## STEP-5~7: 다음 변경 후보 (A/B 증가만, C/D/E 금지)

```
후보              예상 A/B 증가     예상 C/D/E 증가   우선순위
[후보1]           B +5~10           낮음             ★ 1순위
위험요소 5종
(타워크레인/석면/
발파/밀폐/잠수)
사업장 의무 draft
선별 binding
  - B축을 0→다수로. 현재 완전 비어있는 축.
  - 단 위험요소 draft는 IF_CONDITION(Boolean)이 많아
    employee_count binding이 안 먹을 수 있음(다음 루프서 실측).

[후보2]           A +3~5            낮음~중간         2순위
건설 안전점검 세부
(자체/정기/정밀
안전점검) draft
선별 binding
  - A축 보강. 단 "안전점검" 일부는 이미 출현(중복 가능).

[후보3]           A +2              중간(시설물법      3순위
시설물안전법         행정 혼입 위험)
안전점검 의무
  - A 늘지만 시설물법은 행정·기관 조문 많아 D/E 혼입 위험.
    SCALE에서 WRONG 유발한 계열 → 신중.
```

---

## STEP-7: 선택

```
선택: 후보1 (위험요소 5종 사업장 의무 draft 선별 binding)

이유 (내용 기반):
  - 현재 B축이 완전히 0 → 가장 큰 결손.
  - 위험요소 의무는 건설 정답지의 절반(MUST 6 + 위험요소 5).
  - A는 이미 출현 중이라 한계효용 낮고, B는 0→다수로 질적 변화.
  - C/D/E 증가 위험 낮음(위험요소 사업장 의무는 A/B 성격).
주의: 위험요소 draft는 IF_CONDITION(Boolean) 비중 큼 →
  employee_count(IF_NUMERIC) binding이 안 먹을 수 있음.
  다음 루프에서 "위험요소 draft에 IF_NUMERIC slot 있는지" 선별 후 적용.
```

---

## STEP-8: 변경 안 함 (후보만 결정)

```
이 WO는 읽기·판정·후보 선정만. 변경 0.
다음 루프(변경)에서 후보1 적용.
```

---

## 산출 요약

```
1. 현재 결과 실제 내용: 6건 (건설기술진흥법 3 + 주변 3)
2. 분류: A 3 / B 0 / C 1~2 / D 0 / E 0
3. 판정: GOOD (A 중심, 오염 없음. 단 B 비어있음)
4. 다음 후보 TOP3: 위험요소(1순위) / 건설점검세부(2순위) / 시설물법(3순위)
   선택 = 후보1 위험요소
```

---

## 완료 문장

```
현재 유지 상태(PRESENT 3/WRONG 0)의 결과를 숫자가 아닌 문장으로 읽어,
A(사업장 안전의무) 3건이 건설 정답지 핵심(안전관리계획·안전점검)이고
C/D/E 오염이 거의 없는 GOOD 상태임을 확정하였다.
다만 B(위험요소 안전의무)가 0인 결손을 확인하여,
다음 변경 후보로 위험요소 5종 사업장 의무 draft 선별 binding을 선택하였다.
이 WO에서는 변경하지 않았다.
```
