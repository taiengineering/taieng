## ★ 핵심 발견: 시설목록에 법령 입력 필드가 대량 존재

```
직전 WO들에서 "엔진은 근로자수+KSIC만 본다"고 했는데,
시설 등록 화면(factory-list.html)을 실측하니
사용자는 그보다 훨씬 많은 법령 입력을 하고 있다:

  근로자수, 전기용량, 가스용량, 보일러, 승강기, 에너지,
  연면적, 층수, 변압기, + 위험물/화학물질/고압가스/안전관리자
  체크박스 다수.

→ 사용자 입력 현실(User Reality)은 2차원이 아니라 다차원이다.
```

## 5축 입력 위치 확인 (IF/THEN 판정용)

```
근로자수 → ✅ 시설목록 "상시 근무인원" (worker_count→employee_count)
KSIC    → ⚠️ 회사정보 "업태/업종명"(텍스트) + 시설유형(select)
          → KSIC "코드" 직접 입력란은 이 화면들에 명시적으로 없음.
          (무료진단 step / 시설유형 매핑으로 KSIC 연결 추정)
시설    → ✅ 시설목록 (시설명/유형/상세)
공정    → ✅ 공정관리 (메뉴 존재, 필드 미실측)
설비    → ✅ 설비관리 (설비명/수량/연도/위치)
```

---

## 판정 규칙 적용 (IF/THEN)

```
규칙:
  IF 근로자수/KSIC/시설/공정/설비 입력위치가 모두 확인
  THEN WO-UI-INPUT-CONTRACT-FREEZE-001 (입력계약 확정)
  ELSE WO-UI-MISSING-INPUT-MAP-001 (누락 입력 위치 확인)

판정:
  근로자수 ✅ 확인
  시설     ✅ 확인
  공정     ✅ 확인 (메뉴, 필드는 다음 단계)
  설비     ✅ 확인
  KSIC    ⚠️ 부분 — 업태/업종명 텍스트는 있으나
          "KSIC 코드" 명시 입력란은 이 4화면에서 미확인.

→ KSIC "코드" 입력 위치가 명확히 확인 안 됨.
  = IF 조건 완전 충족 아님 (5축 중 KSIC가 불완전).

  ∴ 다음 WO = WO-UI-MISSING-INPUT-MAP-001
    (KSIC 입력 위치 — 무료진단 step / 시설유형 매핑 확인)
```

## 성공 기준 점검

```
UFI-01 회사정보 필드 목록 → ✅
UFI-02 시설목록 필드 목록 → ✅ (가장 풍부)
UFI-03 공정관리 필드 목록 → ⚠️ 메뉴확인, 필드 미실측
UFI-04 설비관리 필드 목록 → ✅
UFI-05 근로자수 입력 위치 → ✅ 시설목록 "상시 근무인원"
UFI-06 KSIC 입력 위치    → ⚠️ 업태/업종명 텍스트만, 코드 입력 미확인
UFI-07 IF/THEN 판정      → ✅ (ELSE 분기 → MISSING-INPUT-MAP)
```

## 완료 문장

```
실제 사용자 입력계약은:
  회사(회사명/사업자/업태업종/연락처/주소) +
  시설(시설명/유형/근로자수/외주인원/주소 + 전기·가스·보일러·승강기·
       에너지·연면적·층수·변압기·위험물·화학물질·고압가스·안전관리자 등 다수) +
  공정(공정 선택) +
  설비(설비명/수량/연도/위치/법정점검/운영상태)
  로 구성된 다차원 입력이다.

  단 KSIC "코드" 명시 입력 위치는 이 4화면에서 확인되지 않음
  (업태/업종명 텍스트 + 시설유형으로 간접 연결 추정).

따라서 다음 WO는 WO-UI-MISSING-INPUT-MAP-001 이다.
  (KSIC 입력 위치 — 무료진단 step / 시설유형 매핑 확인)
```

## 이 WO의 의미 (사장님 지적대로)

```
이제 처음으로 두 가지를 같은 기준으로 비교할 수 있다:

  [사용자가 실제 입력하는 데이터] = 다차원
    근로자수 + 전기/가스/보일러/승강기/에너지/연면적/층수/변압기
    + 위험물/화학물질/고압가스/안전관리자 + 공정 + 설비(수량/연도)

  [VR이 현재 흔드는 데이터] = 2차원 (KSIC + 근로자수)

→ 격차가 화면 기준으로 처음 드러났다:
  사용자는 다차원을 입력하는데, VR은 2차원만 흔든다.
  (단 "엔진이 그 다차원을 쓰는가"는 엔진 분석 영역 = 별개,
   이 WO는 엔진 분석 금지이므로 입력 현실까지만 확정)
```
