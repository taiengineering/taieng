# REGRESSION MATRIX V1 — 3 sector 목업 회귀 매트릭스
# WO-MASS-REGRESSION-MATRIX-001

**방식**: 신규 목업 회사+factory 3개(sector별, 위험요소 전부 ON) 등록 → 엔진 투입 → 결과 읽기.
**기존 데이터**: 오염 소지로 전량 폐기, 신규 생성.
**수정·원인분석 없음. 결과 분포 + 실제 문장만.**

---

## STEP-1 대상군 (신규 목업)

```
회사: [목업] 회귀테스트 종합 (company 6f2b9ab6)
factory 3개 (위험요소 전부 ON: has_tower_crane/asbestos/blasting/confined/diving
            + chemical/gas/boiler 전부 true):
  [건설] 04eb9598 (CONSTRUCTION, 공사 50억/50명/타워크레인·석면·발파·밀폐·잠수)
  [산업] 65527d36 (INDUSTRIAL, 80명/화학·가스·보일러)
  [건물] 4c4e4eb9 (BUILDING, 1만㎡/15층/500명/엘리베이터4)
```

## STEP-2~4 그룹별 결과 + 매트릭스

```
sector       total   소방(WRONG)   위험요소 출현        주요 출현
[건설]        7       0            잠수만               건설기술진흥법(안전관리계획/안전점검) 3
                                                       + 잠수 + 작업환경측정 + 방사선/친환경
[산업]        3       0            잠수만               잠수 + 작업환경측정 + 안전보건교육
[건물]        113     105 (93%)    잠수만               소방안전관리/소방기술자/NFPC 화재안전기준 다량
```

### 위험요소 출현 매트릭스 (입력=전부 ON)
```
              타워크레인  석면   발파   밀폐   잠수
[건설]         ✗         ✗      ✗      ✗      ✓
[산업]         ✗         ✗      ✗      ✗      ✓
[건물]         ✗         ✗      ✗      ✗      ✓
= 위험요소 전부 ON 입력해도 잠수(binding 걸린 것)만 출현.
```

## ★ STEP-5~6 핵심 패턴 (실제 문장 읽기)

### 패턴 1: 위험요소 입력 ↔ 의무 연결 없음 (전 sector 공통)
```
위험요소를 명시적으로 has_*=true 입력해도:
  타워크레인/석면/발파/밀폐 = 전 sector 미출현.
  잠수만 출현 (= 우리가 잠수 IF_NUMERIC에 binding을 걸어놓은 것).
= 입력 빈약이 아니라 binding 부재가 원인임이 깨끗한 신규 목업으로 확정.
  (기존 데이터 오염 가능성 제거 후에도 동일 → binding 부재 단독 증명)
```

### 패턴 2: 소방은 sector별로 정확히 분리됨 (우리 정화의 결과)
```
[건설] 소방 0  / [산업] 소방 0  / [건물] 소방 105(93%)
= 소방을 BUILDING으로 매핑한 결과, 건물엔 정상 출현, 건설·산업엔 0.
= WRONG 정화가 sector별로 정확히 작동. 건물 소방은 WRONG 아니라 정상 의무.
```

### 패턴 3: A(사업장 의무)는 건설만 보유
```
[건설] 건설기술진흥법 안전관리계획·안전점검 3건 (binding 걸린 것)
[산업] A 거의 없음 (작업환경측정/교육만)
[건물] A 없음, 소방 행정·기술기준이 점유
= A축도 binding 건 것만 나옴. 산업·건물은 A binding 미적용 상태.
```

## STEP-6 반복 출현 / 반복 오염 패턴

```
[건설군]
  반복 출현: 안전관리계획 / 안전점검 (binding 적용분) + 잠수
  반복 오염: 없음 (WRONG 0)
[산업군]
  반복 출현: 작업환경측정 / 안전보건교육 + 잠수
  반복 오염: 없음 (WRONG 0)
[건물군]
  반복 출현: 소방안전관리 / 소방기술자 배치 / NFPC 화재안전기준 (정상)
  반복 오염: 없음 (건물에선 소방이 정상)
```

---

## STEP-6 우선순위 TOP 5 (집단 패턴 기준)

```
P1 위험요소 입력↔의무 binding 부재 (전 sector 공통, 최대 결손)
   타워크레인/석면/발파/밀폐 4종이 어느 sector에서도 안 나옴.
   = Boolean trigger binding (GPT) 필요. 이미 인계됨.
P2 산업 A축 binding 미적용
   산업 사업장 의무(작업환경측정 외)가 binding 안 됨. 건설처럼 선별 binding 가능.
P3 건물 A축 부재
   건물 사업장 의무(시설관리/유지관리)가 소방에 묻힘. binding 필요.
P4 건설 A축 확대
   현재 안전관리계획·안전점검 3건. 자체/정기/정밀점검·교육 추가 binding 가능.
P5 잠수 외 위험요소 = P1과 동일 뿌리 (Boolean binding)
```

## 성공 기준 충족

```
- 그룹별 샘플: 건설/산업/건물 각 1 목업(위험요소 전부 ON)  → ✅
- A/B/C/D/E 분포 + 위험요소 매트릭스                       → ✅
- 그룹별 실제 문장                                         → ✅
- 반복 출현 / 반복 오염 패턴                               → ✅
- 우선순위 TOP5                                            → ✅
- 수정·원인분석 없음                                        → ✅
```

## ★ 가장 큰 문제 하나 (집단 전체)

```
위험요소 입력↔의무 binding 부재 (P1).
  신규 깨끗한 목업에 위험요소 전부 ON으로 넣어도
  타워크레인/석면/발파/밀폐가 전 sector에서 0.
  = TAI 핵심 가치("입력한 사업장 특징대로 의무 제시")의 정면 실패 지점.
  = Boolean trigger binding(GPT/엔진)이 이 하나를 풀면 3 sector 동시 개선.
```

## 완료 문장

```
기존 오염 데이터를 폐기하고 건설·산업·건물 신규 목업(위험요소 전부 ON)을 등록해
엔진에 투입한 결과, 위험요소 4종(타워크레인/석면/발파/밀폐)이 전 sector에서
미출현(잠수만 binding으로 출현)함을 확인하였다. 이는 입력 빈약이 아니라
binding 부재가 원인임을 깨끗한 목업으로 단독 증명한다.
소방은 건물에만 정상 출현(건설·산업 0)하여 WRONG 정화가 sector별로 정확히
작동함을 확인하였다. 집단 전체의 가장 큰 문제는 위험요소 입력↔의무 binding
부재이며, Boolean trigger binding(GPT)이 이를 3 sector 동시에 해결한다.
본 WO에서는 수정·원인분석 없이 결과 분포와 실제 문장만 읽었다.
```
