## 근거: 의미절 전수 확인 결과

건설업 + 공사금액 관련 의미절을 전부 읽은 결과:

| 의미절 | 공사금액 기준 | 실제 의무 | 안전관리자 선임과 관계 |
|---|---|---|---|
| 제73조 | 1억~120억 | 기술지도계약 | ❌ 무관 |
| 제75조 | 120억 이상 | 노사협의체 | ❌ 무관 |
| 제17조제3항 | 120억 이상 | **전담** 안전관리자 | ⚠️ 선임의무가 아닌 "전담" 조건 |
| 제16조제2항 | 120억 이내 | 공동선임 한도 | ⚠️ 선임의무가 아닌 "공동선임" 조건 |
| 제62조 | 20억 이상 | 안전보건총괄책임자 | ❌ 다른 선임 |
| 제16조제1항 | — | "별표3과 같다" 참조만 | ⚠️ 참조만, 본문 없음 |

## 핵심 발견

```
건설업 안전관리자 "선임 의무 발생" 기준은
별표3 본문에 있다.

그러나 의미절은 모두
제16조제1항 "별표3과 같다"로 참조만 할 뿐,
별표3 본문 자체(건설업 공사금액별 선임 인원)는
의미절로 분해되지 않았다.

즉 DB에 있는 120억은:
  "선임해야 하는가"가 아니라
  "전담으로 두어야 하는가" 경계일 뿐.
```

## INDUSTRIAL과의 결정적 차이

```
INDUSTRIAL (이미 구현됨):
  별표3 본문이 appendix_condition 7건으로 구조화됨
  (WO-APPENDIX-COLLECT-001에서 수행)
  예: "제1호~제27호 외 사업 50명 이상 → 1명"

CONSTRUCTION (미구현):
  별표3 건설업란이 appendix_condition으로
  구조화되지 않음
  → INDUSTRIAL은 했고 CONSTRUCTION은 안 한 작업이 남아있음
```

## Phase 5 성격 최종 판정

```
Phase 5는 "순수 변환 단계"가 아니다.
Phase 5는 "별표3 건설업란 구조화 + 변환" 단계다.

이유:
  의미절은 "별표3 참조"만 하고 있으므로
  INDUSTRIAL처럼 별표3 건설업란을
  appendix_condition으로 구조화하는 작업이 선행되어야 함.

단, 이것은 "새 법령 수집"이 아니다.
  별표3 원문은 이미 국가법령정보센터에서 수집된 법령의 일부.
  WO-APPENDIX-COLLECT-001과 동일한 방식으로
  이미 수집된 별표 원문에서 건설업란을 추출하면 됨.
```

## 사장님 확인 요청

```
건설업 안전관리자 별표3 본문(공사금액별 선임 인원)은
현재 구조화되지 않은 상태입니다.

INDUSTRIAL은 WO-APPENDIX-COLLECT-001에서
별표3 본문을 appendix_condition으로 한 번 추출했습니다.

건설업도 동일한 방식(기존 수집된 별표 원문에서 추출)으로
구조화 가능합니다. 단 별표3 본문의 건설업란
원문이 어디에 있는지 확인이 필요합니다:

  A. WO-APPENDIX-COLLECT-001이 INDUSTRIAL만 추출했고
     원본 별표3 원문은 여전히 있다 → 건설업란만 추가 추출
  B. 별표3 원문 자체가 부분만 수집됨 → 원본 재확인 필요
```
