## 완료 조건 답변

```
Q: 건설업 안전관리자 기준이 이미 DB에 존재하는가?
A: 부분 YES — 공사금액 120억 기준은 원문·의미절에 존재
   그러나 구조화된 판정 조건(constraint/rule)에는 미도달
```

## 레이어별 도달 상태

| 레이어 | 건설업 안전관리자 공사금액 | 상태 |
|---|---|---|
| **law_article_part** (원문) | 120억/150억 기준 명시 | ✅ 존재 |
| **semantic_clause** (의미절) | 건설업+안전관리자 의미절 3건 | ✅ 존재 |
| **constraint_node** (제약 노드) | 공사금액 = DEFINITION만 | ⚠️ THRESHOLD 미도달 |
| **numeric_constraint** (수치 제약) | 금액 추출되나 subject 파싱 noise | ⚠️ 안전관리자 미연결 |
| **rule_candidate** (규칙) | 건설업 선임 인원 규칙 | ❌ 미도달 |
| **appendix_condition** (최종) | INDUSTRIAL 7건만 | ❌ 건설업 없음 |

## 세부 추적 결과

### 1. law_article_part — 원문 존재 ✅

```
제16조제3항:
  "상시근로자 300명 이상[건설업은 공사금액 120억원
   (토목 150억원) 이상]" → 전담 안전관리자 경계

제16조제2항:
  공동선임 경계 (공사금액 합계 120억 이내)
```

### 2. semantic_clause — 의미절 3건 ✅

```
건설업 + 안전관리자 의미절 3건 존재
```

### 3. constraint_node — DEFINITION만 ⚠️

```
공사금액 관련 노드:
  node_type = DEFINITION ("공사금액을 말한다")
  → 개념 정의일 뿐, 선임 판정 THRESHOLD가 아니었음
```

### 4. numeric_constraint — 연결 안 됨 ⚠️

```
제16조 건설업 120억 part의 numeric_constraint:
  검출된 것은 "합계는 <= 300명" (EMPLOYEE_THRESHOLD)
  → 공사금액 120억 수치는 이 part에서 추출 안 됨
  → 공사금액이 numeric_constraint로 온전히 구조화 안 됨
```

## 핵심 발견

```
건설업 안전관리자 기준은:

상위 레이어 (원문/의미절):
  ✅ 존재 — 120억 기준 명확

하위 레이어 (제약/규칙):
  ❌ 미도달 — 공사금액이 판정 가능한 THRESHOLD로
     구조화되지 않음

즉, 의미는 있으나 실행 가능한 조건으로는 아직 변환 안 됨.
```

## 별표3 본문 선임 인원 구간 (50억/800억 등)

```
현재 DB 추출 텍스트에서 미확인:
  law_attachment에 안전관리자 별표 추출텍스트 없음
  constraint_node에 선임 인원 구간 없음

확인된 유일한 공사금액 기준:
  120억 (전담/공동선임 경계) — 제16조 원문

주의: 50억/800억은 프로젝트가 가정했던 구간이지
     DB에서 확인된 값이 아님 → 추정 금지
```

## ApplicabilityCondition 변환 가능성

```
현재 확인된 것으로 만들 수 있는 조건:

안전관리자 "선임 의무 발생" 기준:
  scope_type = SECTOR, scope_values = ['CONSTRUCTION']
  metric = METRIC:CONSTRUCTION_AMOUNT
  operator = >=, threshold = ???
  → threshold 값이 문제

제16조 120억은 "전담 안전관리자" 경계이지
"선임 자체" 경계가 아님

즉 건설업은:
  공사금액 X 이상 → 선임 의무 발생 (X = ?)
  공사금액 120억 이상 → 전담 안전관리자

→ "선임 의무 발생" 최소 기준은 별표3 본문에 있으나
   현재 글읽은 레이어에서는 미확인
```
