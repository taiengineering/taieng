**목적**: VR 결과를 사람이 읽는 진단서 형태로 변환 → 독해 기반 검증 가능성 확인.

**원칙 정합**: "검증은 글을 읽는 방식. 카운트만 세기는 가장 위험" (메모리 핵심).

## 결론 먼저

```
RR-01 가상 사업장 생성 가능       → ✅

RR-04 읽어서 이상사례 발견 가능     → ✅ (즉시 3건 발견)

핵심: 진단서로 읽자마자, 카운트(AGREE 1400/MATCH 473)로는
  전혀 안 보였던 이상사례 3건이 즉시 드러났다.
  = "글을 읽는 검증"이 작동함을 증명.
```

## 읽어서 발견한 이상사례 (RR-04 핵심)

### 이상사례 1: 안전관리자 구간 중복 출력 (C28, 1200명)
```
출력:
  · 1000명 이상 안전관리자 2명
  · 50명 이상 999명 미만 안전관리자 1명   ← 둘 다 나옴

문제:
  1200명 사업장인데 두 규모 구간이 동시에 출력됨.
  규모 구간은 배타적이어야 함 (1200명 = "1000명 이상" 구간만).
  "50~999명" 구간의 상한(999명) 검사가 빠진 것으로 읽힘.

영향:
  대규모 사업장에서 안전관리자 의무가 중복 표기.
  사용자가 "1명? 2명? 둘 다?"로 혼란.

★ 카운트로는 안 보임: MATCH 수만 세면 "둘 다 MATCH"로
  정상처럼 집계됨. 읽어야 "구간 겹침"이 보인다.
```

### 이상사례 2: 소규모 의무 과다 (C28, 5명)
```
출력: 5명 사업장에 6건
  관리감독자 지정 / 위험성평가 / 일반건강진단 / 교육 3종

문제(읽어서 드는 의문):
  근로자 5명 영세 사업장에 6건 전부 부과.
  일부 의무는 소규모 적용제외/완화가 있을 수 있는데
  threshold가 1로 잡혀 전부 부과된 것으로 읽힘.

→ 확정 오류라 단정 안 함 (법령 확인 필요).
  단 "5명한테 이게 다 맞나?"는 읽어야 나오는 질문.
```

### 이상사례 3: 50인 경계 직전 0건 (C10, 49명)
```
출력: C10 49명 → 진단서 없음 (의무 0건)

관찰:
  49명은 대부분 의무의 50인 threshold 직전이라 전부 미달.
  → 진단서 자체가 안 나옴.

읽어서 드는 의문:
  "49명 사업장은 정말 아무 의무도 없는가?"
  (위험성평가/교육 등 규모 무관 의무가 있어야 하는 것 아닌가?)
  → 50인 미만 의무 커버리지 점검 지점. (단정 아님, 읽기가 던진 질문)
```

## 이 WO가 증명한 것

```
1. VR 결과는 진단서로 변환 가능하다 (RR-01~03).
   숫자가 아니라 "이 사업장은 이런 의무가 있다"로 읽힌다.

2. 진단서를 읽으면 이상사례가 보인다 (RR-04).
   카운트 검증(AGREE 100%)에서는 완전히 안 보였던
   "구간 중복 / 소규모 과다 / 경계 0건" 3건이 즉시 드러났다.

3. 이것이 메모리 원칙의 실증:
   "카운트만 세기가 가장 위험" — AGREE 1400은 다 맞아 보였지만,
   읽어보니 구간 겹침(이상사례 1) 같은 의미 오류가 숨어 있었다.
```
