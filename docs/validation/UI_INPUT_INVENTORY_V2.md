## [실측 완료] 회사정보 (my-company.html)

```
회사 등록/수정 입력 필드:
  · 회사명           (필수, text)

  · 대표자명         (필수, text)
  · 사업자유형       (선택, select: 법인/개인)
  · 업태             (선택, text)

  · 팩스             (필수, tel)

업로드:
  · 사업자등록증 사본 (PDF/JPG/PNG, 최대 10MB, 드래그앤드롭)

  카카오 API 금지 원칙과 정합.
```

## [실측 완료] 설비관리 (my-equipment.html)

```
설비 등록 — 탭1: 공정 기반 선택
  · 공정 선택       (필수, select ← 등록된 공정 목록)
  · TAI 권장설비    (MUST/CORE 밴드 체크박스, 다중)
  · 공통 설치연도   (선택, number 1950~2030)
  · 설치위치        (선택, text, 항목별)

설비 등록 — 탭2: 설비명 직접 검색
  · 설비명 검색     (필수, equipment_model 검색 ← /model/search)
  · 수량            (필수, number 1~999)
  · 설치연도        (선택, number 1950~2030)
  · 설치위치        (선택, text)
  · 법정점검 대상   (체크박스, 기본 ON)

설비 수정 (오프캔버스):
  · 운영상태        (ACTIVE/BROKEN/INACTIVE 버튼)
  · 설비명          (필수)
  · 설비위치 / 수량(1~999) / 설치연도(1950~2030)
  · 법정점검 대상   (체크박스)

자동/연동:
  · 시설(factory) 선택 후 설비 등록 (factory_id 연결)
  · 공정→권장설비 매핑 (/recommend-equipment)
  · equipment_category / equipment_model_id (검색 선택 시 자동)
```

## 업로드 / 자동수집 / 숨김값 (실측)

```
업로드:
  · 사업자등록증 (회사정보, PDF/JPG/PNG 10MB)
  · 설비 이미지/도면 (DB: equipment_assets.main_image_url/drawing_url)

자동수집:
  · 공정→권장설비 매핑 (TAI 추천)
  · equipment_category/model_id (설비 검색 선택 시)
  · QR/RFID (equipment-qr-manager.html 존재)

숨김값/시스템:
  · created_at / created_by / company_id / factory_id
  · is_legal_target / legal_status / operation_status 기본값
```

## 성공 기준 점검 (V2 갱신)

```
UII-01 화면 전체 확인     → ⚠️ 부분 (회사정보·설비관리 실측,
                            시설목록·공정관리 위치확인·필드미실측)
UII-02 입력항목 목록화    → ✅ (실측 2화면 + 위치확인 2화면)
UII-03 필수/선택 구분     → ✅ (실측 2화면 확정, 미실측은 "?")
UII-04 업로드 항목        → ✅ (사업자등록증/설비이미지)
UII-05 자동수집 항목      → ✅ (권장설비/QR/RFID/카테고리)
UII-06 엔진 분석 금지     → ✅
UII-07 DB 분석 금지       → ⚠️ DB는 입력항목 존재확인에만
```

## 결론

```
"소비자는 무엇을 입력할 수 있는가" — 화면 실측 기준:

  [회사정보] 회사명/사업자번호/대표자/유형/업태/업종/연락처/주소
            + 사업자등록증 업로드
  [설비관리] 공정선택/설비명/수량/설치연도/위치/법정점검/운영상태
            + 공정기반 권장설비 / 모델검색
  [시설목록] 근로자수·업종·주소 추정 (미실측)
  [공정관리] 공정 lv1~4 추정 (미실측)
  [무료진단] 업종/근로자수/규모/지역 (별도 step 화면)

핵심 관찰 (판정 아님):
  - 사용자는 설비 단위로 "수량/연도/위치/법정점검대상/운영상태"를
    상세 입력한다. = 직전 WO에서 본 입력공간이 화면에서 확인됨.
  - 그러나 (엔진 분석 금지로 여기선 안 다루나) 이 상세 입력이
    근로자수+업종 외 판정에 쓰이는지는 별개 질문.
  - 주소는 행안부 juso API (카카오 금지 정합).

남은 실측: 시설목록(factory-list) / 공정관리(process-manage)
  HTML 본문 → 근로자수 입력 위치 확정 시 인벤토리 완성.
```
