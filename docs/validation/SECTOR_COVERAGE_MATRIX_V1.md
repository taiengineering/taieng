# WO-SECTOR-FULL-COVERAGE-MATRIX-001

**방식**: 기존 목업 3개(위험요소 전부 ON) 엔진 투입 → 결과 문장 읽기 → A/B/C/D/E 분류.
**수정·binding·mapping·원인분석 없음. 읽기만.**

## STEP-1~3 Sector별 결과표 (실제 문장)

```

  - 안전점검의 시기·방법 등        (동)
B 위험요소 의무 (1):
  - 표면공급식 잠수작업 시 조치    (산안기준규칙)
C 시설/기술 기준 (2):
  - 방사선 화재방호시설 / 친환경주택 설계조건
D 행정/신고 (0)
E 기관 업무 (0)
+ 작업환경측정 시료채취 (A/C 경계, 1)
```

### BUILDING (4c4e4eb9) — 113건

## STEP-4 Sector별 한 문장 평가

```
CONSTRUCTION: GOOD
  사업장 의무(안전관리계획·안전점검) 중심 + 잠수. 오염 0. 가장 건강한 결과.

INDUSTRIAL: EMPTY
  핵심 의무 부족(3건뿐). 작업환경측정·교육·잠수만. 화학/가스/보일러 입력 미반영.

BUILDING: BAD
  기술기준 중심(소방·NFPC 105/113=93%). 사업장 의무 0. 소방 설비기준이 결과 점유.
  (단 건물엔 소방이 정상 적용 대상이므로 "오염"은 아님. 그러나 사업장 관리의무 부재)
```

## STEP-5 Sector별 가장 큰 결손 1개

```
CONSTRUCTION
  결손: 위험요소 의무 부족 (타워크레인/석면/발파/밀폐 0, 잠수만)
        → Boolean binding(GPT) 필요.

INDUSTRIAL
  결손: 사업장 의무 + 화학/설비 의무 전반 부족
        (화학물질·고압가스·보일러 입력했으나 관련 의무 미출현, A binding 미적용)

BUILDING
  결손: 사업장 관리 의무 부재 (소방 설비기준만 있고
        건물 안전관리자 선임·점검·교육 등 사업장 운영 의무 안 나옴)
```

## ★ 한 장 요약 (운영 관점)

```
              A사업장   B위험요소   C기술기준   D행정   E기관   평가
CONSTRUCTION  3        1(잠수)     2          0       0      GOOD
INDUSTRIAL    2        1(잠수)     0          0       0      EMPTY
BUILDING      0        1(잠수)     105        혼재    혼재    BAD

공통: 위험요소는 전 sector 잠수만(binding 건 것). 4종 미반영.
건설 = 사업장 의무 출현(우리가 binding). 가장 건강.
산업 = 거의 비어있음(의무 binding 미적용).
건물 = 소방 기술기준이 결과를 채움(소방은 정상이나 사업장 의무 부재).
```

## STEP-6 다음 우선순위 (읽기 기반)

```
1. INDUSTRIAL 사업장 의무 binding (EMPTY 해소가 가장 시급)
   - 산업 사업장 의무(안전보건관리/위험성평가/작업환경측정 등)가 거의 안 나옴.
2. BUILDING 사업장 관리 의무 binding (소방에 묻힌 A축 살리기)
3. 위험요소 4종 Boolean binding (전 sector 공통, GPT)
4. CONSTRUCTION A축 확대 (이미 GOOD, 우선순위 낮음)
```

## 완료 문장

```
3개 sector 목업(위험요소 전부 ON)의 실제 결과를 읽어 A/B/C/D/E로 분류한 결과,
CONSTRUCTION은 사업장 의무 중심의 GOOD, INDUSTRIAL은 핵심 의무가 거의 없는
EMPTY, BUILDING은 소방 기술기준이 93%를 점유하는 BAD로 평가되었다.
위험요소는 전 sector에서 잠수(binding 건 것)만 출현하였다.
각 sector 최대 결손은 건설=위험요소 의무, 산업=사업장+설비 의무 전반,
건물=사업장 관리 의무 부재이다. 수정 없이 읽기만 수행하였다.
```
