## 읽으면서 떠오른 큰 그림 관찰 (메모, 판정 아님)

```
[관찰 A] 업종이 두 그룹으로 갈린다
  - "풀세트 그룹"(C25/C28/C29/C30): 5명부터 교육/평가/건강진단/감독자 6건
  - "안전관리자만 그룹"(B071/C10/C20/C24): 50명부터 안전관리자 1건만
  → 왜 어떤 업종은 교육/위험성평가가 있고 어떤 업종은 없나?
    (규모무관 의무가 업종 따라 있다가 없다가?)

[관찰 B] "1명+2명 동시" 패턴이 전 업종 상위규모에서 반복
  - 한 사업장 우연이 아니라 500명/1000명 넘는 곳마다 나옴
  → 구조적 패턴으로 보인다.

[관찰 C] 업종코드 vs 설명텍스트 불일치 의심
  - C10/C20/C24 모두 "식료품 제조업..." 텍스트
  → 코드는 다른데 설명이 같다.

[관찰 D] 광업(B071) 상위규모 구간 부재 의심
  - 1200명도 "50~499명 1명"으로 나옴
  → 광업은 500명+ 구간이 아예 없는 듯.
```
