# 2부. 반복 관찰 패턴 (패턴 5종 이상)

```
PATTERN-A (중복처럼 보이는 표현)
  - 안전관리자 "1명 + 2명" 동시 출력 (상위규모 전반, 직전 배치서도)
  - 선임 의무 텍스트에 다른 업종명 박힘 ("식료품 제조업"이 타 업종에)
  → 같은 종류 의무가 둘로 보이거나, 텍스트가 안 맞아 중복처럼 읽힘

PATTERN-B (갑작스러운 경계값 변화)
  - 49명→50명: 0건 또는 6건 → 8건 (선임+설비 점프)
  - 999명→1000명: 8건 → 9건 (선임 2명째)
  - 19명→20명, 499→500: 일부 업종서 점프
  → 경계에서 의무가 계단식으로 점프. 경계 직전/직후 큰 차이.

PATTERN-C (업종 차이가 과도해 보임)
  - 같은 51명: C24 1건 vs C22 8건 (8배)
  - 같은 1000명: H49 2건 vs C28 9건
  - 같은 소규모: 6건 그룹 vs 0건 그룹
  → 규모 같아도 업종 따라 의무 수가 극단적으로 갈림

PATTERN-D (설명이 부족해 보임)
  - "제1호부터 제27호까지 외의 사업" 법조문 그대로
  - "토사석 광업(071)" 같은 코드 박힌 텍스트
  → 사용자가 읽고 무슨 뜻인지 모를 표현

PATTERN-E (직관과 다름)
  - 대규모인데 의무 적음 (H49 1000명 2건)
  - 1명 농가에 "관리감독자 지정"
  - 50~999명 내내 8건 평지 (20배 규모차에도 동일)
  → "클수록 많겠지" 직관과 어긋나는 사례

PATTERN-F (0건 진단서)
  - 49명 이하 특정 업종이 "의무 0건"
  → "진단했는데 0건"을 사용자가 어떻게 받아들일지 불명
```
