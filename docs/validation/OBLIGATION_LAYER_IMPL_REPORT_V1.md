## 1. 구현 결과

Obligation View = V4 Evaluation Result(MATCH) + 조건 레코드 조인.
**새 테이블/새 데이터/새 판단 없음. SQL 조립 표현만.**

```
Obligation View 필드 (전부 기존 데이터):
  title           ← action_text
  legal_basis     ← law_name + ' ' + appendix_no
  reason          ← factory 입력(업종+인원) [런타임 조립]
  required_action ← action_text
  required_count  ← required_count
  verdict         ← V4 eval_result

출력 정책:
  MATCH          → 사용자 표시
  NOT_MATCH      → 표시 안 함
  NOT_APPLICABLE → 표시 안 함
  UNKNOWN        → 표시 안 함
```

  title  = "안전관리자 선임"

  상세    = "(제1호~제27호 외 사업, 50~999명 구간)"

→ 단, 이건 데이터/판단 문제 아닌 "표현 조립 방식".
  action_type(APPOINTMENT)을 title 매핑에 쓰면 해결.
  다음 표현 정제 WO에서 다룰 후보. 이번 WO 범위 아님.
