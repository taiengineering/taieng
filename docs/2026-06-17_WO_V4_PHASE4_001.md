## 한 줄 요약

> Phase 4는 구현 단계가 아니다.
> 소비자 입력이 현재 엔진에서 어디까지 흐르는지 30개 케이스로 관찰한다.

---

## 해석 원칙

```
INDUSTRIAL 10개 = 안전관리자 파일럿 정답 검증
CONSTRUCTION 10개 = 입력 활용도 관찰 (NO_RELEVANT_CONDITION 가능성 높음)
BUILDING 10개 = 입력 활용도 관찰 (NO_RELEVANT_CONDITION 가능성 높음)

"안 맞는다" ≠ 오류
"아직 조건이 없다" = 정상 관찰
```

---

## 결과 분류 기준

| 분류 | 정의 |
|---|---|
| OK | 기대 결과 == 실제 결과 |
| FALSE_POSITIVE | 나오면 안 되는 것이 나옴 |
| FALSE_NEGATIVE | 나와야 하는 것이 안 나옴 |
| UNKNOWN_MISSING | 사용자 미입력으로 UNKNOWN |
| UNKNOWN_UNSUPPORTED | 입력했지만 엔진이 미지원 |
| NO_RELEVANT_CONDITION | 현재 파일럿에 해당 조건 없음 |
| TRACE_GAP | 결과는 나왔으나 추적 불가 |

Track A 수정 금지
