## 핵심 발견

### 1. INDUSTRIAL 10/10 OK — 엔진 정상

```
ksic_major + worker_count 두 필드만으로
안전관리자 선임 판정이 10개 케이스 모두 정확함.
경계값(50명) 정상, 확장 구조(C-01 → C11 구분) 정상
```

### 2. CONSTRUCTION/BUILDING UNKNOWN — 오류 아님

```
건설/건물에는 현재 INDUSTRY Scope 기반 조건 7건만 존재.
ksic_code=null → 전체 UNKNOWN
이것은 파일럿 범위 밖 (Phase 5+ 대상)
"안 맞는다" ≠ 오류, "아직 조건이 없다" = 정상 관찰
```

### 3. I-09: ksic=null → UNKNOWN — 정상 설계

```
업종 미입력시 안전관리자 판정 불가 정상 반환
“업종을 입력해야 안전관리자 선임 여부를 알 수 있습니다”
→ 소비자 UI에서는 ksic_major를 필수로 요청하는 것이 맞음
```
