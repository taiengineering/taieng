## 시장 비교 데이터

### TAI의 대체재 비용 (구매자가 비교하는 것)

| 대체재 | 월 비용 | 비고 |
|--------|---------|------|
| 안전관리자 직접 고용 | 300~400만원 | 인건비만, 4대보험 별도 |
| 안전관리 대행기관 | 15~30만원/월 | 방문 월 1~2회, 서류 대행 |
| 전기안전관리 대행 (50kW) | 13.5만원/월 | 전기 분야만 |
| 전기안전관리 대행 (500kW) | 33.2만원/월 | 전기 분야만 |
| 전기안전관리 대행 (1000kW) | 120.6만원/월 | 전기 분야만 |
| 안전보건관리체계 컨설팅 (민간) | 300~2,000만원/회 | 1회성, 사후관리 없음 |
| KOSHA 무료 컨설팅 | 0원 | 정부지원, 5~50인 한정, 2~5회 방문 |
| 과태료 1건 | 최소 300만원 | 반복 위반 시 가중 |
| 중대재해 벌금 | 최대 10억원 | 사업주 형사처벌 포함 |

### 건설 특수: 안전관리비 법정 계상
- 100억 공사 기준 약 200만원 안전관리비 확보
- TAI 비용은 이 예산에서 지출 가능 → 가격 저항 낮음

### 핵심 포지셔닝
```
TAI Safe는:
  대행기관보다 저렴하면서 (15~30만원 vs TAI)
  대행보다 훨씬 많은 것을 해주고 (24시간 자동 vs 월 1~2회 방문)
  컨설팅보다 지속적이다 (매월 자동 관리 vs 1회성 보고서)
```

### 가격 제안

#### 건물 (3단계)
| 단계 | 내용 | 제안가 | 근거 |
|------|------|--------|------|
| 무료 | 적용법령 수 + 선임의무 O/X | 0원 | 전환 트리거 |
| 표준 | 법령명·조문·과태료 전체 | **79,000원** | 대행 1개월분의 절반. 건물주에게 부담 없는 선 |
| 종합 | 표준 + 설비별 점검주기·담당자 | **179,000원** | 전기대행 1개월분(13.5만)보다 약간 높지만 전 분야 포함 |

**건물 근거:** 건물 관리소장·건물주가 의사결정. 10만원 이하가 심리적 허들 없음. 종합도 20만원 미만이면 "한번 해보자" 가능.

#### 산업 (4단계)
| 단계 | 내용 | 제안가 | 근거 |
|------|------|--------|------|
| 무료 | 적용법령 수 + 선임의무 O/X | 0원 | 전환 트리거 |
| 표준 | 법령명·조문·과태료 전체 (401건) | **99,000원** | 10만원 미만 = 총무·안전담당자 결재선에서 처리 가능 |
| 설비 | 설비별 점검항목·주기·담당자 | **199,000원** | 컨설팅(300만~) 대비 1/15 수준 |
| 종합 | 전체 + 일정생성 + 신고서식 | **249,000원** | 컨설팅 1회 대비 1/10. "이 가격에 이것까지?" 효과 |

**산업 근거:** 안전관리자나 총무가 결재 올림. 30만원 미만이면 팀장급 결재. 과태료 1건(300만원) 대비 1/12.

#### 건설 (2단계 — 즉시 사용)
| 단계 | 내용 | 제안가 | 근거 |
|------|------|--------|------|
| 무료 | 선임의무 O/X + 안전관리비 기준 | 0원 | 전환 트리거 |
| 종합 | 전체 의무 + 공정별 일정 + TBM + 신고서식 | **399,000원** | 안전관리비에서 지출. 컨설팅(500만~) 대비 1/12 |

**건설 근거:**
- 건설은 공정→작업이 자동 연결되는 구조이므로 중간 단계 불필요
- "즉시 사용 가능"이 목표 → 한번에 다 줌
- 안전관리비 법정 계상으로 가격 저항 거의 없음
- 데이터 복잡도(161공정×243작업) + 시간축(착공~준공) + TBM 자동발령 → 산업보다 비싸야 정당

## 2. SaaS 구독 — 핵심 수익 (시설당 과금)

### 과금 기준 변경: 인원 → 시설

```
기존 (과금구조 v1.0): 기본료 + 초과 인원당
  문제: "직원이 몇 명이냐"로 분쟁 가능
  문제: 파견·일용직 포함 여부 논란
  문제: 건설현장 인원 수시 변동

변경 (현재 확정): 시설당 월정액
  장점: 단순명료 — 시설 1개당 얼마
  장점: 인원 변동과 무관
  장점: 추가 시설 = 추가 구독 (자연스러운 업셀)
```

### 건물 SaaS (시설당)

| 플랜 | 제안가 | 포함 내용 | 대상 |
|------|--------|----------|------|
| BASIC | **59,000원/월/시설** | 법령엔진 자동작동, 점검일정, D-3 알림(SMS 50건/카카오 50건), 완료기록 6개월 | 소규모 건물 (아파트, 상가) |
| STANDARD | **99,000원/월/시설** | BASIC 전체 + 신고서식 자동화, 법령변경 알림, SMS 150건/카카오 150건, 서류 15건, 기록 무제한 | 중규모 건물 (오피스, 복합시설) |
| CUSTOM | **협의** | STANDARD + 다수시설 통합, 전담매니저, API연동 | 대형 관리업체 |

**건물 가격 근거:**
- 전기안전관리 대행만 13.5만원/월인데, TAI는 소방+전기+승강기+가스 전부 포함
- BASIC 5.9만원 = 대행의 1/2 이하 → "이 가격에 이것까지?" 
- STANDARD 9.9만원 = 대행 1개 분야 비용으로 전 분야 관리
- 건물주·관리소장의 월 예산 감각: 10만원 이하가 결정 쉬움

### 산업 SaaS (시설당)

| 플랜 | 제안가 | 포함 내용 | 대상 |
|------|--------|----------|------|
| STARTER | **79,000원/월/시설** | 법령엔진, 점검일정, 작업자배정, D-3 알림(SMS 100건/카카오 100건), 완료기록 6개월 | 5~30인 (겸직 타깃) |
| BUSINESS | **149,000원/월/시설** | STARTER + 신고서식, 법령변경알림, QR점검, 대시보드, SMS 300건/카카오 300건, 서류 30건, 기록 무제한 | 30~100인 |
| PRO | **249,000원/월/시설** | BUSINESS + TBM전자서명, 경영진리포트, 비상알림, 전자계약, API연동, 우선지원 | 100인+ 전담 |
| CUSTOM | **협의 (350,000~)** | PRO + 다수시설 통합, 전담매니저, 커스텀리포트 | 대기업·다사업장 |

**산업 가격 근거:**
- STARTER 7.9만원 = 안전관리 대행(15~30만)의 1/2~1/4
- 겸직 안전관리자의 시간 가치: 월 3~5시간 절감 × 시급 1.5~2만원 = 4.5~10만원 → 7.9만원은 딱 이 범위
- BUSINESS 14.9만원 = 대행 1개월분과 동일하지만 24시간 자동
- PRO 24.9만원 = 대행보다 약간 비싸지만 전 기능 포함
- "본업 방해 안 받으려면 7.9만원은 납득 가능" (겸직 타깃 메시지)

### 건설 SaaS (현장당)

| 플랜 | 제안가 | 포함 내용 | 대상 |

| PREMIUM | **399,000원/월/현장** | STANDARD + 위험성평가 자동, 기상청 작업중지 연동, 경영진리포트, 하도급관리, API연동, 우선지원 | 50억+ 현장 |

**건설 가격 근거:**
- 안전관리비 법정 계상 → 100억 공사 기준 약 200만원/월 확보

- 건설은 공정→작업 자동연결 구조이므로 기본부터 TBM 포함
- 중간 플랜 없이 2개만 → "즉시 사용" 철학과 일치

## 4. 연결 수수료 — 미확정

### 현재 상태
- 선임 연결: 방향 확정 (거래 성사 시 공급자 부담), 금액 미정
- 수선 연결: 방향 확정 (거래 성사 시 공급자 부담), 금액 미정
- 교육 단가: 기관 협의 후 확정

### 대표님 결정 필요 사항
- 오픈 시점: 처음부터 vs 모수 확보 후
- 수수료율: 초기 운영 데이터 수집 후 결정

### 확정된 원칙
1. 거래 성사 시에만 수수료 (견적·매칭 자체는 무료)
2. 아쉬운 쪽(공급자)이 부담 / 수요자(사업장) 무료
3. 플랫폼 기록이 Lock-in (선임계·수리기록 자동 저장)
4. SaaS 비구독자도 이용 가능 (초기 활성화)
5. 그레이드 구조 (큰 거래 = 낮은 % / 작은 거래 = 높은 %)

## 6. 구매의사결정자 관점 정리

### 누가 결제 버튼을 누르는가?

| 유형 | 의사결정자 | 결재선 | 심리적 허들 |
|------|-----------|--------|----------|
| 건물 | 관리소장/건물주 | 본인 결정 | 10만원 이하 = 즉시 |
| 산업 (겸직) | 총무/생산팀장 | 팀장→부서장 | 10만원 미만 = 팀장선, 30만원 미만 = 부서장선 |
| 산업 (전담) | 안전관리자 | 안전팀장→경영진 | 30만원 미만 = 팀장, 그 이상 = 임원 |
| 건설 | 현장소장 | 본부장/대표 | 안전관리비에서 지출 → 별도 결재 불필요 |

  "안전관리비의 10%로 TBM부터 신고까지 자동화"

건설 PREMIUM 39.9만원:
  "컨설팅 1회(500만원) 가격으로 공사 기간 내내 자동 관리"
