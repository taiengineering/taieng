## TAI의 역할 정의

```
TAI는 대행이 아닙니다.

SaaS = 안전관리를 직접 하게 해주는 도구
법령진단 = 미리 알고 대비하게 하는 1회성 서비스
선임/수선/진단 = 연결하고 수수료를 받는 역할

대행기관은 경쟁자가 아니라 연결 서비스의 공급자(파트너)
가격 비교 대상 = 엑셀/종이(무료) + 과태료 리스크
```

## 시장 비교 데이터

### 고객이 현재 쓰는 방식과 비용

| 현재 방식 | 비용 | 문제 |
|---------|------|------|
| 엑셀/종이로 직접 관리 | 0원 | 누락 발생, 시간 소모, 과태료 리스크 |
| 안전관리자 직접 고용 | 300~400만원/월 | 중소기업에 과도한 부담 |
| 안전관리 대행기관 위탁 | 15~30만원/월 | 월 1~2회 방문, 실시간 관리 불가 |
| 전기안전관리 대행 (50kW) | 13.5만원/월 | 전기 분야만 |
| 전기안전관리 대행 (1000kW) | 120.6만원/월 | 전기 분야만 |
| 안전보건관리체계 컨설팅 (민간) | 300~2,000만원/회 | 1회성, 사후관리 없음 |
| KOSHA 무료 컨설팅 | 0원 | 5~50인 한정, 2~5회 방문 후 종료 |
| 과태료 1건 | 최소 300만원 | 반복 위반 시 가중 |
| 중대재해 벌금 | 최대 10억원 | 사업주 형사처벌 포함 |

### 건설 특수: 안전관리비 법정 계상
- 100억 공사 기준 약 200만원 안전관리비 확보
- TAI 비용은 이 예산에서 지출 가능 → 가격 저항 낮음

### 핵심 포지셔닝
```
TAI SaaS의 비교 대상은 대행기관이 아닙니다.

비교 1: 엑셀/종이(무료)로 관리하다 과태료 맞는 것 vs TAI로 체계적 관리
비교 2: 직접 법령 찾기(하루 소요) vs 법령진단으로 즉시 확인
비교 3: 직접 수소문해서 전문가 찾기 vs TAI 연결로 간편하게

대행기관은 TAI의 경쟁자가 아니라 연결 서비스의 공급자(파트너)
```

## 1. 법령진단 (1회성) — 온보딩 도구

### 구조

| 유형 | 무료 | 유료1 | 유료2 | 유료3 |
|------|------|-------|-------|-------|
| 건물 | ✅ | ✅ | ✅ | - |
| 산업 | ✅ | ✅ | ✅ | ✅ |
| 건설 | ✅ | ✅ | - | - |

### 가격 (확정)

#### 건물 (3단계)
| 단계 | 내용 | 가격 |
|------|------|------|
| 무료 | 적용법령 수 + 선임의무 O/X | **0원** |
| 표준 | 법령명·조문·과태료 전체 | **79,000원** ✅ |
| 종합 | 표준 + 설비별 점검주기·담당자 | **179,000원** |

#### 산업 (4단계)
| 단계 | 내용 | 가격 |
|------|------|------|
| 무료 | 적용법령 수 + 선임의무 O/X | **0원** |
| 표준 | 법령명·조문·과태료 전체 (401건) | **99,000원** |
| 설비 | 설비별 점검항목·주기·담당자 | **199,000원** |
| 종합 | 전체 + 일정생성 + 신고서식 | **249,000원** |

#### 건설 (2단계 — 즉시 사용)
| 단계 | 내용 | 가격 |
|------|------|------|
| 무료 | 선임의무 O/X + 안전관리비 기준 | **0원** |
| 종합 | 전체 의무 + 공정별 일정 + TBM + 신고서식 | **299,000원** ✅ 확정 |

**건설 가격 근거:**
- 건설은 공정→작업이 자동 연결되는 구조이므로 중간 단계 불필요
- "즉시 사용 가능"이 목표 → 한번에 다 줌
- 30만원 미만 = 결재선 낮음
- 산업 종합(249K)과의 차이 5만원 = 건설 복잡도 반영하면서 자연스러운 차이
- SaaS 전환 퍼널 역할 → 진입장벽 낮추는 것이 중요

## 4. 연결 수수료 — 미확정

### 확정된 원칙
1. 거래 성사 시에만 수수료 (견적·매칭 자체는 무료)
2. 아쉬운 쪽(공급자)이 부담 / 수요자(사업장) 무료
3. 플랫폼 기록이 Lock-in (선임계·수리기록 자동 저장)
4. SaaS 비구독자도 이용 가능 (초기 활성화)
5. 그레이드 구조 (큰 거래 = 낮은 % / 작은 거래 = 높은 %)

### 미확정 사항
- 오픈 시점: 처음부터 vs 모수 확보 후
- 수수료율: 초기 운영 데이터 수집 후 결정
