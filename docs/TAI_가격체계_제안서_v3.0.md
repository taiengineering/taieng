## TAI의 역할 정의

```
TAI는 대행이 아닙니다.

SaaS = 안전관리를 직접 하게 해주는 도구
법령진단 = 미리 알고 대비하게 하는 1회성 서비스
선임/수선/진단 = 연결하고 수수료를 받는 역할

대행기관은 경쟁자가 아니라 연결 서비스의 공급자(파트너)
가격 비교 대상 = 엑셀/종이(무료) + 과태료 리스크
```

## 시장 비교

| 현재 방식 | 비용 | 문제 |
|---------|------|------|
| 엑셀/종이로 직접 관리 | 0원 | 누락, 시간 소모, 과태료 리스크 |
| 안전관리자 직접 고용 | 300~400만원/월 | 중소기업에 과도 |
| 안전관리 대행기관 위탁 | 15~30만원/월 | 월 1~2회 방문, 실시간 불가 |
| 전기안전관리 대행 (50kW~1000kW) | 13.5~120.6만원/월 | 전기 분야만 |
| 안전보건관리체계 컨설팅 (민간) | 300~2,000만원/회 | 1회성 |
| 과태료 1건 | 최소 300만원 | 반복 시 가중 |
| 중대재해 벌금 | 최대 10억원 | 형사처벌 포함 |

## 4. 연결 수수료 — 전략적 판단 필요

### 확정된 원칙
1. 거래 성사 시에만 수수료 (견적·매칭은 무료)
2. 공급자(아쉬운 쪽)가 부담 / 수요자(사업장) 무료
3. 플랫폼 기록이 Lock-in
4. SaaS 비구독자도 이용 가능
5. 그레이드 구조 (큰 거래 = 낮은 % / 작은 거래 = 높은 %)

### 오픈 시점 트레이드오프

| | 지금 오픈 | 추후 오픈 |
|---|---------|---------|
| 장점 | 초기 고객 이탈 방지, Lock-in 시작 | 수요 데이터 먼저 확보, 공급자 유치 시 어필 |
| 단점 | 공급자 0명 = "아무도 없다" 리스크 | 고객이 다른 경로로 해결 → 돌아올 이유 없음 |

### 제안: "사전 등록" 방식 (절충안)
```
메뉴는 지금 넣되, 실제 매칭은 하지 않음
→ 수요(기업): "선임 필요합니다" 사전 등록
→ 공급(전문가/업체): "선임 가능합니다" 사전 등록
→ 양쪽 모수가 일정 수 이상 모이면 정식 오픈

효과:
  초기 고객: "여기서 선임도 해결할 수 있구나" → 이탈 안 함
  공급자: "이미 수요 N건 대기 중" → 등록 동기 부여
  리스크: "연결했는데 아무도 없다" 경험 제로
```

## 6. 구매의사결정자 심리선

| 유형 | 의사결정자 | 심리적 허들 |
|------|-----------|----------|
| 건물 | 관리소장/건물주 | 30만 미만 = 본인 결정 가능 |
| 산업 (겸직) | 총무/팀장 | 10만 미만 = 팀장선, 30만 미만 = 부서장선 |
| 산업 (전담) | 안전팀장 | 30만 미만 = 팀장, 그 이상 = 임원 |
| 건설 | 현장소장 | 안전관리비에서 지출 → 별도 결재 불필요 |

### 가치 메시지
```
건물 BASIC 5.9만원:
  "엑셀 대신 쓰는 도구. 소방+전기+승강기+가스 자동. 과태료 1건이면 4년치."

산업 STARTER 7.9만원:
  "안전이 본업이 아닌 분들을 위해. 과태료 1건의 1/38."

건설 STANDARD 19.9만원:
  "안전관리비의 10%로 TBM부터 신고까지. 엑셀에서 벗어나세요."
```
