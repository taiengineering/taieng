## 3. Engine change — punctuation tier (P9)

Fixed a real gap: the Hangul araea `ㅍ` (U+318D) used as a list separator in
many law names (소음ㅍ진동관리법, 지진ㅍ화산재해대책법 …) is categorised as a
letter, so it survived punctuation stripping and a user query without it missed.
Added: (a) `normalize.no_punctuation` now strips `ㅍ`/`・`; (b) the projection
carries `term_no_punctuation`; (c) the engine has a punctuation-insensitive tier
(match_type `PUNCTUATION`, score 88, below NORMALIZED_EXACT). Query
`소음진동관리법` → `소음ㅍ진동관리법` (PUNCTUATION).
