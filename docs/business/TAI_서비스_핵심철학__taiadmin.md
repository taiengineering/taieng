# TAI Safe 서비스 핵심 철학
> 대표 심태왕 관점 — 모든 창이 공유해야 할 서비스 본질
> 최초 작성: 2026-03-29

---

## 핵심 한 줄

**"안전관리자 1인 체계를 → 현장 전원 참여 체계로 전환하는 플랫폼"**

---

## 법령진단의 위치

```
법령진단 = SaaS 온보딩(세팅) 도구

"우리 회사에 어떤 안전관리 의무가 있는지" 파악하는 과정
→ 서비스 시작점이지, 핵심 서비스가 아님
```

---

## 현재 현장의 구조적 문제

```
현장작업자
  → 실제로 가장 위험에 노출
  → 현장 안전 상태를 가장 잘 앎
  → 그러나 안전관리에 참여하지 않음

안전관리자 1명
  → 모든 안전관리 업무를 혼자 처리
  → 기억에 의존 → 누락 필연적
  → 퇴사·휴가 시 완전 공백
  → 책임만 집중, 실행은 형식적
  → 중대재해 발생 시 책임 소재 불명확

결과:
  서류는 있지만 실행 안 됨
  안전은 관리자 혼자 하는 것이라는 인식
  현장작업자 안전 인식 제로
  중대재해처벌법 리스크 상시 노출
```

---

## TAI Safe가 바꾸는 것

```
[기존]
  모든 안전업무 → 안전관리자 1인 처리

[TAI Safe]
  안전업무 → 작업자·그룹에 할당·분산
            → 실행 여부 시스템이 추적
            → 누락 시 자동 알림
            → 실행 이력 누적
```

### 역할 전환

| 역할 | 기존 | TAI Safe 적용 후 |
|------|------|------------------|
| 현장작업자 | 안전관리 비참여 | 할당받은 업무 직접 실행·보고 |
| 반장·팀장 | 중간 전달만 | 그룹 단위 업무 관리·취합 |
| 안전관리자 | 모든 것을 혼자 | 할당·모니터링·이상 대응 |
| 경영진·대표 | 결과만 보고받음 | 실시간 실행 현황·누락 파악 |

---

## TAI Safe 5가지 핵심 가치

```
1. 안전관리 업무 할당·분산
   안전관리자 혼자 → 작업자·그룹 전원 참여

2. 실행 누락 방지
   기억에 의존 → 시스템이 추적·알림

3. 평상시 안전 인식 고취
   사고 후 교육 → 일상적 참여로 인식 변화

4. 프로세스 변화 대응
   법령·현장 변화 시 즉시 반영

5. 중대재해·과태료 리스크 감소
   "했다"는 실행 이력 = 법적 방어 근거
```

---

## 경쟁사와의 진짜 차이

```
세이프로·스마플:  안전 "문서" 관리
슈퍼세이프:      현장 "실행" 관리 (근접 경쟁)

TAI Safe:
  법령 세팅 (온보딩)
  + 업무 할당·분산 (핵심)
  + 실행 추적·누락 방지
  + 평상시 안전인식 고취
  + 프로세스 변화 대응
  = 안전관리 구조 자체를 바꾸는 플랫폼
```

  "실행 이력이 쌓이는 구조"
  "평상시에 안전이 습관이 되는 구조"
