# TAI 안전정보 게시판 기획서

> 작성일: 2026-03-28  
> 배경: 공공API 10종 승인 완료 → 자동 수집 콘텐츠 활용

---

## 1. 핵심 목적

| 목적 | 설명 |
|------|------|
| **SEO** | 매일 자동 업데이트 콘텐츠 → 검색 유입 |
| **신뢰도** | 국가 공인 데이터 기반 → "TAI는 공신력 있는 정보를 제공" |
| **전환** | 업종별 맞춤 재해사례 → 경각심 → TAI Safe 가입 CTA |
| **재방문** | 매일 새 콘텐츠 → 북마크 유도 |

---

## 2. 콘텐츠 소스 및 갱신 계획

| 탭 | 소스 | 갱신 | 예상 콘텐츠 |
|---|------|------|------------|
| 중대재해현황 | 건설업 일별 중대재해 현황 (KOSHA) | **매일** | 연 365건+ |
| 사고사례 | 국내재해사례 게시판 (KOSHA) | 주 1회 | 수천 건 DB |
| 기술지침 | KOSHA GUIDE (코샤가이드) | 분기 1회 | ~500건 |
| 법령안내 | 안전보건법령 스마트검색 (KOSHA) | 월 1회 | 개정 감지 자동화 |
| 안전팁 | TAI 자체 작성 + KOSHA 안전보건자료 | 수시 | 누적 |

## 5. 백엔드 연동 계획

### DB 테이블: posts
```sql
category 값:
  'disaster_daily'   -- 건설업 일별 중대재해
  'accident_case'    -- KOSHA 재해사례
  'kosha_guide'      -- KOSHA GUIDE
  'law_update'       -- 법령 개정
  'safety_tip'       -- 안전팁

source 값:
  'KOSHA_DAILY'      -- 매일 자동 수집
  'KOSHA_API'        -- KOSHA API 주기 수집
  'LAW_API'          -- 법제처 API
  'TAI_MANUAL'       -- TAI 자체 작성
```

### API 엔드포인트
```
GET /posts?category={}&page={}&size=9     -- 목록
GET /posts/{id}                           -- 상세
GET /posts/latest?limit=3                 -- 메인 노출용 최신 3건
GET /posts/stats/today                    -- 오늘의 통계 위젯
```

### 배치 스케줄
```
매일 06:00  -- 건설업 중대재해 현황 수집
매주 월요일  -- KOSHA 재해사례 동기화
매월 1일    -- 법령 개정 감지 + KOSHA GUIDE 신규 확인
```
