## 3. 선임연결 서비스

### 3-1. 서비스 개요

**방향 전환 이유:**
- 안전관리전문기관 직접 운영 → 인력 3명 + 장비 + 법인 요건으로 1인 창업 구조 불가
- 직업소개업 신고(관할 구청) → 즉시 운영 가능한 중개 구조로 전환

**핵심 차별화:**
```
일반 헤드헌터: 구인/구직 DB → 연결
TAI: SaaS 법적진단 → 선임 의무 자동 파악
     → 필요 자격 DB 조회 → 검증된 인력 매칭
     → 선임 신고서식 자동 작성 → 원스톱
```

### 3-2. 공급자 구조

공급자는 두 종류로 완전 분리 관리합니다.

#### A. 개인 기술자
- 산업안전기사/산업기사, 전기기사, 소방안전관리사 등 자격 보유 개인
- 상주(풀타임) / 비상주(월 방문) 형태

#### B. 안전관리전문기관 (대행업체)
- 고용노동부 지정 안전관리전문기관
- 여러 사업장 동시 위탁 관리

### 3-3. 운영 원칙

**공급자 비공개 원칙:**
- 공급자 프로필/연락처는 고객에게 절대 노출 금지
- 고객 요청 접수 → TAI 내부 매칭 → 조건 맞는 5곳만 요약 추천서 발송
- 모든 연락은 TAI 경유
- 추천 후 3개월 내 TAI 경유 없이 직접 계약 시 수수료 청구

### 3-4. 수수료 구조 — 최종 확정

#### 상주 (풀타임 고용)

| 항목 | 내용 |
|------|------|
| 수수료 기준 | 연봉 × 15% (상한) |
| 수수료 부담 | 기업 (구인자) |
| 납부 시점 | 근로계약 체결 후 30일 내 |
| 보증 기간 | 3개월 |
| 재매칭 | TAI 귀책 시 1회 무료 / 2회부터 수수료 50% 추가 |
| 법적 근거 | 직업안정법 제18조 (고급·전문인력 — 당사자 합의) |

**수익 예시:**
| 연봉 | 수수료 |
|------|-------|
| 3,000만원 | 450만원 |
| 4,000만원 | 600만원 |
| 5,000만원 | 750만원 |

#### 비상주 (월 방문 서비스)

| 항목 | 내용 |
|------|------|
| 수수료 기준 | 월 방문비 × 12개월 × 10% (1회) |
| 수수료 부담 | 기업 (구인자) |
| 납부 시점 | 서비스 계약 체결 후 30일 내 |
| 보증 기간 | 3개월 (상주와 동일) |
| 재매칭 | 동일 조건 적용 |

**수익 예시:**
| 월 방문비 | 연간 합산 | 수수료 |
|---------|---------|-------|
| 50만원 | 600만원 | 60만원 |
| 100만원 | 1,200만원 | 120만원 |
| 200만원 | 2,400만원 | 240만원 |

#### 보증 조건 (상주/비상주 공통)

| 항목 | 내용 |
|------|------|
| 보증 기간 | 계약일로부터 3개월 |
| TAI 책임 | 공급자 귀책 사유 (개인 사정 퇴사/서비스 중단) |
| TAI 면책 | 기업 귀책 (폐업/부당처우/조건 임의변경) |
| 재매칭 | 1회 무료 / 2회부터 수수료 50% 추가 |
| 구직자 수수료 | 연봉 × 1% 이하 (초기: 무료 운영) |

### 3-5. 자격검증 체계

#### 개인 기술자 검증 (3단계)

```
1단계: 서류 제출
  - 자격증 사본
  - 신분증 사본
  - 경력증명서
  - 현재 담당 사업장 목록

2단계: 공공 API 실시간 검증
  - 한국산업인력공단 큐넷 API → 자격증 진위 확인
  - 자격증 번호/취득일/종목 자동 조회

3단계: TAI 담당자 최종 승인
  - 영업일 2일 내 완료
  - 승인 시 DB 활성화
```

**연 1회 갱신:**
- 자격 유효 여부 재확인
- 담당 사업장 수 업데이트
- 행정처분 이력 확인
- 갱신 미완료 시 자동 비활성화

#### 수선업체 검증

**설비 종류별 필수 면허:**
| 설비 종류 | 필수 면허 | 확인 API |
|---------|---------|--------|
| 전기설비 | 전기공사업 등록증 | 한국전기공사협회 |
| 소방시설 | 소방시설공사업 등록증 | 소방청 소방산업정보시스템 |
| 승강기 | 승강기유지관리업 등록증 | 한국승강기안전공단 |
| 가스설비 | 가스시설시공업 등록증 | 한국가스안전공사 |
| 일반건설 | 전문/종합건설업 등록 | 국토부 KISCON |

### 3-6. 등급 체계

공식 자격등급과 TAI 자체 등급 두 축으로 관리합니다.

#### 공식 자격 등급 (협회 기준)

| 등급 | 안전관리 | 경력 기준 |
|------|---------|----------|
| 초급 | 산업안전산업기사 | 3년 미만 |
| 중급 | 산업안전기사 | 3~7년 |
| 고급 | 산업안전기사 + 경력 | 7~15년 |
| 특급 | 산업안전지도사/기술사 | 15년 이상 |

#### TAI 자체 등급 (T1~T5)

| 등급 | 기준 | 담당 가능 규모 |
|------|------|-------------|
| T1 | 자격 취득 3년 미만 | 소규모 사업장 |
| T2 | 3~7년 | 중소규모 |
| T3 | 7~15년 | 대규모 |
| T4 | 15년 이상 or 상위 자격 | 복합시설/위험물 |
| T5 | 지도사/기술사/협회 인증 | 중대재해/컨설팅 |

#### 등급별 매칭 로직

고객 요청 조건:
- 업종 / 상시인원 / 주요 설비 / 선임 형태 / 희망 예산

매칭 필터 순서:
1. 필수 자격 충족 여부
2. TAI 등급 기준 충족
3. 담당 업종 경험
4. 활동 지역 (반경 50km)
5. 현재 담당 수 여유
6. 예산 범위 매칭
7. 후기 점수 높은 순 상위 5곳 추천

### 3-7. 모니터링 서비스

계약 후 1/2/3개월 시점에 TAI가 양측에 확인 연락:
- 문제 조기 발견 → 재매칭 전 조율
- 이탈률 감소 → 보증 리스크 절감
- SaaS 관계 유지로 자연스럽게 가능

## 4. 수선중개 서비스

### 4-1. 서비스 개요

**트리거 3가지:**
1. SaaS 설비 점검 결과 → 이상 발견 → 수선 필요 알림
2. 법령진단 → 설비 교체/보수 의무 발견
3. 고객 직접 요청

**운영 원칙:**
- 업체 프로필/연락처 비공개
- 조건 맞는 3~5곳만 요약 추천서 발송
- 모든 연락 TAI 경유
- 추천 후 3개월 내 직접 계약 시 수수료 청구

### 4-2. 수수료 구조 — 최종 확정

| 공사 규모 | 수수료 | 부담 주체 |
|---------|-------|----------|
| 500만원 미만 | **고정 5만원** | 업체 |
| 500만원 ~ 5,000만원 | **공사금액 × 3%** | 업체 |
| 5,000만원 이상 | **공사금액 × 5%** | 업체 |

> ⚠️ 대규모가 중규모보다 높은 이유: 대형 공사일수록 TAI의 매칭 난이도가 높기 때문

**수익 예시:**
| 공사금액 | 수수료 |
|---------|-------|
| 300만원 | 5만원 |
| 1,000만원 | 30만원 |
| 3,000만원 | 90만원 |
| 8,000만원 | 400만원 |
| 1억 5,000만원 | 750만원 |

- 기업(고객)은 완전 무료 → 진입장벽 없음
- 납부 시점: 공사 완료 후 14일 내
- 하자 책임: TAI 면책 (업체-기업 직접 하자보증)

### 4-3. 설비별 전문업체 분류

TAI equipment_type 코드(001~040)와 매핑:

| 설비 코드 | 설비 종류 | 전문 업체 |
|---------|---------|----------|
| 001~010 | 전기설비 | 전기공사업체 |
| 011~020 | 기계설비 | 기계설비업체 |
| 021~026 | 중장비 | 중장비전문업체 |
| 027~030 | 저장탱크 | 위험물/탱크업체 |
| 031~034 | 소방설비 | 소방시설업체 |
| 035~040 | 환경/기타 | 환경설비업체 |

### 4-4. 업체 자격검증

- 설비 종류별 필수 면허 확인 (선임연결과 동일 3단계)
- 시공 실적 확인 (계약서/완공사진)
- 업체 규모별 등급:
  - 소규모: 전문건설업 + 자본금 2억 미만
  - 중규모: 전문건설업 + 자본금 2~10억
  - 대규모: 종합건설업 + 자본금 10억 이상

## 5. 전체 수익 구조 요약

```
TAI 수익원

① SaaS 구독
   월정액 (시설 수 기반)
   → 안정적 기반 수익 (고정)

② 선임연결 — 상주
   연봉 × 15%
   → 건당 450~750만원 (고수익, 비정기)

③ 선임연결 — 비상주
   월방문비 × 12개월 × 10% 1회
   → 건당 60~240만원 (중간, 비정기)

④ 수선중개
   공사금액 구간별 3~5%
   → 건당 5만~750만원 (반복 발생)

⑤ 공급자 월 구독료 (예정)
   업체/기술자 DB 등록료
   → 소액 고정 수익 (미확정)
```

## 6. 법적 근거

| 서비스 | 법적 근거 | 인허가 |

### 직업소개업 신고 요건
- 신고 기관: 관할 구청
- 신고 요건: 사무실(자택 가능) + 결격사유 없음 + 수수료 표 게시
- 비용: 신규 등록 3만원
- 수수료 규정: 고급·전문인력은 당사자 합의 (법적 상한 없음)
- 구직자 수수료: 연봉 × 1% 이하 (초기 무료 운영)
- 미신고 영업 시: 과태료 500만원

## 8. DB 설계 방향 (개발 창 참조)

### 신규 필요 테이블

```
safety_personnel      — 개인 기술자 DB
safety_agencies       — 대행업체 DB
repair_companies      — 수선업체 DB
matching_requests     — 매칭 요청 (선임/수선 공통)
matching_results      — 추천 결과 발송 이력
matching_contracts    — 계약 성사 및 수수료 정산
verification_logs     — 자격 검증 이력
```

### 공통 검증 상태 코드 (system_codes 추가 필요)

```
verified_status:
  PENDING    — 서류 제출, 검토 중
  API_PASS   — API 검증 완료, 담당자 검토 대기
  APPROVED   — 최종 승인, 활성
  REJECTED   — 반려
  EXPIRED    — 갱신 기한 초과, 비활성
  SUSPENDED  — 문제 발생, 임시 중단
```

### TAI 등급 코드 (system_codes 추가 필요)

```
tai_grade:
  T1 — 입문 (경력 3년 미만)
  T2 — 일반 (3~7년)
  T3 — 전문 (7~15년)
  T4 — 고급 (15년 이상)
  T5 — 특급 (지도사/기술사)
```

### 선임연결 핵심 필드 (safety_personnel)

```sql
safety_personnel (
  id, name, phone, email,
  employment_type,        -- FULLTIME(상주) / PARTTIME(비상주)
  qualification_type,     -- 자격증 종류
  qualification_grade,    -- 기사/산업기사/지도사
  qualification_no,       -- 자격증 번호
  qualification_verified, -- API 검증 여부
  career_years,           -- 총 경력년수
  association_grade,      -- 초급/중급/고급/특급
  tai_grade,              -- T1~T5
  region_sido,            -- 활동 시도
```
