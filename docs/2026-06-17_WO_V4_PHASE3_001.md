## condition_scopes 테이블 구조

```sql
CREATE TABLE condition_scopes (
  id             UUID PK,
  condition_id   UUID FK → applicability_conditions,
  scope_type     TEXT,      -- INDUSTRY | PROCESS | ACTIVITY | EQUIP
  scope_operator TEXT,      -- IN | NOT_IN | HAS
  scope_values   TEXT[],    -- ["B071"] | ["PROC:WELDING"]
  note           TEXT
);
```

**데이터 예시:**
```
토사석 광업:  INDUSTRY / IN     / ["B071"]
식료품 제조:  INDUSTRY / IN     / ["C10","C11","C19","C20","C21","C24"]
운수 창고:   INDUSTRY / IN     / ["H49","H50","H51","H52"]
일반 조항:   INDUSTRY / NOT_IN / ["B071","C10","C11","C19","C20","C21","C24","H49","H50","H51","H52"]

-- 나중에 (Phase 0B 이후)
용접 특별교육: PROCESS / IN  / ["PROC:WELDING"]
압력용기 검사: EQUIP   / HAS / ["EQUIP:PRESSURE_VESSEL"]
```

## C1 공통 평가 인터페이스

```python
def evaluate_scope(scope: dict, facility_profile: dict) -> str:
    """scope_type 무관하게 동일한 인터페이스."""
    scope_type = scope["scope_type"]
    operator   = scope["scope_operator"]
    values     = scope["scope_values"]

    # FacilityProfile에서 해당 scope_type의 값 추출
    facility_value = get_facility_scope_value(facility_profile, scope_type)

    if facility_value is None:
        return "UNKNOWN"

    if operator == "IN":
        matched = any(facility_value.startswith(v) for v in values)
        return "MATCH" if matched else "NOT_APPLICABLE"

    if operator == "NOT_IN":
        matched = any(facility_value.startswith(v) for v in values)
        return "MATCH" if not matched else "NOT_APPLICABLE"

    # HAS (나중에 EQUIP/PROC용)
    return "UNKNOWN"
```

## INDUSTRY Scope 파일럿 데이터

**산안법 시행령 별표3 안전관리자 선임기준 7건 매핑:**

```
토사석 광업(071)          → IN  / ["B071"]
식료품·음료 등 고위험      → IN  / ["C10","C11","C19","C20","C21","C24"]
운수 및 창고업(49~52)      → IN  / ["H49","H50","H51","H52"]
제1호~27호 외의 사업(일반) → NOT_IN / [배타집합 전체]
```

## 성공 기준 SC-01 ~ SC-05

```
SC-01: 화성 제2공장 (C28, 280명)
  MATCH = 1건 (일반 조항)
  NOT_APPLICABLE = 3건 (토사석/식료품/운수창고)
  verdict = REQUIRED 1명

SC-02: 토사석 광업 (B071, 60명)
  토사석 조건 → MATCH
  일반 조항  → NOT_APPLICABLE (B071은 배타집합 포함)
  verdict = REQUIRED 1명

SC-03: 식료품 제조업 (C10, 600명)
  식료품 조건 → MATCH (2명 조건)
  일반 조항  → NOT_APPLICABLE
  verdict = REQUIRED 2명

SC-04: 빈 사업장 (null명)
  전체 7건 UNKNOWN
  verdict = UNKNOWN

SC-05: Scope 확장성
  새 Scope Type (예: PROCESS) condition_scopes에 추가만으로
  C1 evaluator 코드 수정 0줄로 평가 가능
```

> ApplicabilityCondition이 "누구에게 적용되는가"를
> Scope 객체로 표현할 수 있게 되었다.

> 모르는 상태에서도 공통 인터페이스로 평가할 수 있다.
> 안전관리자 파일럿은 INDUSTRY Scope를 이용한 첫 번째 검증 사례다.
