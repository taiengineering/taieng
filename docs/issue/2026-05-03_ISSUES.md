## ISSUE-02 · 구조적 이슈
### Nexas 템플릿 breadcrumb-area — 서비스 페이지 전체 영향

**상태**: 🔴 잠재적 버그 (다른 페이지 미확인)  
**영향 범위**: `nexas/service/` 하위 모든 페이지

**문제**:
- Nexas 템플릿은 `.navbar-area` 아래에 `.breadcrumb-area` 를 기본으로 렌더링
- 히어로가 천장부터 시작해야 하는 페이지에서 흰 갭 발생
- `tai-hero-fix.css` 에는 이 숨김 처리가 없어 `tai-hero.css` 를 써야 해결됨

**영향 가능 페이지**:
- `service/` 하위 모든 서비스 페이지 (`safety-manager.html`, `expert.html` 등)
- `target/` 하위 페이지는 이미 `tai-hero.css` 사용 중으로 정상

**권장 조치**:
- `tai-hero-fix.css` 를 로드하는 모든 서비스 페이지를 `tai-hero.css` 로 교체
- 또는 `tai-hero-fix.css` 파일 자체에 `.breadcrumb-area { display: none !important; }` 추가

**조치 우선순위**: 낮음 (히어로 없는 페이지에는 영향 없음)

## ISSUE-03 · 작업 효율 이슈

**배경**: 이번 세션에서 `saas.html` 히어로 천장 고정 작업을 4회 이상 반복 수정

**근본 원인**:
1. `tai-hero-fix.css` vs `tai-hero.css` 차이를 모르고 반복 시도
2. Cloudflare Pages 캐시로 인해 수정 반영 여부를 즉시 확인 불가

- 새 서비스 페이지 제작 시 → `tai-hero.css` 기본 로드
- 수정 후 반영 확인은 `Ctrl+Shift+R` 강제 새로고침 후 판단
