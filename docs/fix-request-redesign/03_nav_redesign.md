# 상단 네비게이션 개편 작업지시서

## 개요

전체 사이트 공통 nav를 아래와 같이 변경합니다.

### 변경 전
```
[로고] 서비스+ | 대상별+ | 요금제 | 안전정보 | 로그인 | 마이페이지 | [무료 진단]
```

### 변경 후
```
[로고(원래 크기)] 서비스+ | 업종별+ | 역할별+ | 안전정보 | 로그인 | 마이페이지
```

## 변경 사항 4가지

### 1. 메뉴 구조 변경

| 메뉴 | 드롭다운 항목 |
|------|-------------|
| **서비스** | 법령진단, SaaS 구독, 교육사업, 전문가 매칭(fix-request), 요금제 |
| **업종별** | 건물·시설, 제조공장, 건설현장 |
| **역할별** | 안전관리자·겸직 담당자, 사업주·경영자, 안전 전문가·대행업체 |
| **안전정보** | 드롭다운 없음 (단일 링크) |

#### 서비스 드롭다운 상세
- 법령진단 → `/nexas/free-diagnosis.html`
- SaaS 구독 → `/service/saas`
- 교육사업 → 기존 링크 유지
- 전문가 매칭 → `/nexas/fix-request.html?from=nav&type=general`
- 요금제 → 기존 요금제 페이지 링크

**주의:** 기존 서비스 드롭다운에 있던 "수선 연결", "선임 연결", "컨설팅", "인앱 서비스", "연결서비스 사전등록"은 **삭제**합니다. 수선/선임/컨설팅은 "전문가 매칭"으로 통합되었습니다.

#### 업종별 드롭다운 (기존 "대상별" 항목을 그대로 이동)
- 건물·시설 → 기존 링크
- 제조공장 → 기존 링크
- 건설현장 → 기존 링크

#### 역할별 드롭다운 (신규)
- 안전관리자·겸직 담당자 → `/target/for-safety-manager` (또는 기존 해당 페이지)
- 사업주·경영자 → `/target/for-business-owner` (또는 기존 해당 페이지)
- 안전 전문가·대행업체 → `/target/for-expert` (또는 기존 해당 페이지)

페이지가 아직 없는 경우 href="#" + data-planned="true" 속성으로 placeholder 처리

### 2. 요금제 탑메뉴에서 삭제

- 독립 메뉴 항목 "요금제" 제거
- 서비스 드롭다운 하위로 이동 (위에 명시)

### 3. 무료 진단 버튼 삭제

- 우측 CTA 버튼 "무료 진단" 완전 삭제
- 해당 버튼의 HTML, CSS, JS 이벤트 모두 제거

### 4. 로고 크기 원복

- 현재 로고가 비정상적으로 작아진 상태
- 원인 파악: nav CSS 또는 로고 img 태그의 width/height 변경 이력 확인
- 다른 페이지들과 비교하여 정상 크기로 복원
- 정상 기준: 로고 높이 약 32~40px (nav 높이에 비례)

**확인 방법:**
```bash
# 로고 관련 CSS 검색
grep -rn 'logo\|nav-brand\|navbar-brand' nexas/ --include='*.html' --include='*.css' --include='*.js'
```

## 수정 대상 파일

nav는 공통 컴포넌트이므로 아래 파일들을 모두 확인:

1. **nav-auth.js** — nav 동적 생성 로직이 여기 있을 수 있음
2. **각 HTML 파일의 nav 섹션** — 정적 HTML로 nav가 포함된 경우
3. **공통 CSS** — nav 스타일

```bash
# nav 구조가 있는 파일 전체 검색
grep -rn '서비스\|대상별\|요금제\|무료 진단\|무료진단' nexas/ --include='*.html' --include='*.js'
grep -rn 'nav-menu\|nav-item\|navbar' nexas/ --include='*.html' --include='*.js' --include='*.css'
```

**중요:** nav가 nav-auth.js에서 동적 생성되는 경우, 그 JS 파일 하나만 수정하면 전 페이지에 적용됩니다. 정적 HTML인 경우 모든 페이지를 수정해야 합니다. 먼저 어떤 방식인지 확인 후 작업하세요.

## 모바일 대응

- 햄버거 메뉴 내부에도 동일한 구조 적용
- 서비스 / 업종별 / 역할별: 터치 시 서브메뉴 펼침
- 안전정보: 직접 이동
- 무료 진단 버튼: 모바일에서도 삭제

## 푸터 메뉴 동기화

푸터에도 메뉴 구조가 있으므로 동일하게 변경:
- "서비스" 섹션: 법령진단, SaaS 구독, 교육사업, 전문가 매칭, 요금제
- "대상별" → "업종별"로 라벨 변경
- "역할별" 섹션 추가 (안전관리자, 사업주, 전문가)
- 기존 "시작하기" 섹션의 "도입 문의" → fix-request 링크로 변경

## 금지 사항

- 카카오 API 사용 금지
- 기존 페이지 콘텐츠 변경 금지 (nav/footer만 수정)
- 새로운 외부 라이브러리 추가 금지

## 완료 기준

1. 전 페이지에서 nav가 `서비스 | 업종별 | 역할별 | 안전정보 | 로그인 | 마이페이지` 로 표시
2. 요금제 독립 메뉴 없음 (서비스 하위에 존재)
3. 무료 진단 버튼 없음
4. 로고 크기 정상 (높이 32~40px)
5. 드롭다운 모두 정상 동작
6. 모바일 햄버거 메뉴에서도 동일 구조
7. 푸터 메뉴도 동기화 완료
