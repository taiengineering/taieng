# fix-request 페이지 리디자인 작업지시서 (v2)

## 개요

`nexas/fix-request.html`을 free-diagnosis.html과 동일한 **좌우 분할 레이아웃**으로 리디자인합니다.

## 레이아웃

```
┌─────────────────────────────────────────────────────────┐
│  NAV (공통 nav-auth.js — 로고 크기 정상화 필수)         │
├──────────────────────┬──────────────────────────────────┤
│                      │                                  │
│   왼쪽 패널 (40%)    │   오른쪽 패널 (60%)              │
│                      │                                  │
│   ① 헤드카피         │   채팅 UI                        │
│   ② 흐름도 SVG       │   (height: calc(100vh-nav))      │
│   ③ 이용 안내        │   입력바 하단 고정               │
│   ④ 신뢰 요소        │                                  │
│                      │                                  │
└──────────────────────┴──────────────────────────────────┘
```

### 모바일 (768px 이하)

- 왼쪽 패널: 흐름도 SVG만 축소 배너로 표시
- 오른쪽 패널: 나머지 전체 화면 채팅 UI

## 왼쪽 패널 콘텐츠 (위→아래 순서)

### ① 헤드카피

```
"상황만 말하면
전문 업체를 연결합니다"

안전관리자 선임, 설비 수선, 점검 대행, 안전 진단
복잡한 견적 요청 없이 대화로 해결하세요.
```

### ② 흐름도 SVG (핵심 비주얼)

- 파일: `nexas/assets/img/matching-flow.svg`
- 5단계 원형 흐름도 (Napkin 제작)
- `<img>` 태그로 삽입, max-width: 100%, 좌우 중앙 정렬
- 왼쪽 패널의 중심 콘텐츠 — 가장 큰 비중 차지

### ③ 이용 안내 (흐름도 아래, 간결하게)

```
✓ 비회원도 3턴까지 무료 상담
✓ 회원가입 시 전문 업체 즉시 매칭
✓ 법령·과태료 정보 무료 제공
```

### ④ 신뢰 요소 (하단 고정)

```
특허 출원 중 (Patent Pending)
제10-2026-0056330 외 7건
법령 규칙 엔진 2,080+ 의무 항목 DB
```

## 오른쪽 패널 (채팅 UI)

### 기존 로직 100% 유지

- 기존 JS 코드 (startChat, sendMessage, showResult 등) 그대로 유지
- DOM 구조 ID 변경 없음 (chatBody, msgInput, btnSend, turnBadge, resultSection 등)
- 세션 관리, 턴 카운트, 결과 카드 로직 동일

### UI 변경 사항

1. 채팅 영역 높이: `calc(100vh - nav높이)` — 세로 풀 사용
2. 채팅 헤더: 기존 "TAI 전문가 / 산업안전 전문 업체 매칭" 유지
3. 입력 바: 하단 고정 (sticky)
4. 결과 섹션: 채팅 영역 내부에서 스크롤로 표시

### from/type 파라미터 처리 추가

## 스타일 가이드

- 배경: #f8fafc
- 왼쪽 패널 배경: 흰색 또는 아주 연한 블루 그라데이션
- 채팅 영역 배경: #1e293b (다크, 현재와 유사)
- 폰트: Pretendard
- 배경 이미지 사용 금지

## 기존 왼쪽 패널 콘텐츠에서 삭제할 것

- 기존 4개 섹션 구조 (히어로/매칭분야/이용안내/신뢰요소)를 위의 구조로 대체
- 매칭 분야 아이콘 4개 (🔧 수선·보수 등) → 삭제 (흐름도 SVG가 대체)
- 텍스트 나열 최소화, SVG 흐름도가 메인
