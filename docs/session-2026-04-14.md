## 작업 6: for-business-owner.html 리빌드 (workorder-website-rebuild-v5.md 기반)

**기반 템플릿:** nexas_sample/index-3.html (home-3 sc5, 중앙 히어로 구조)

### 섹션 구성
1. **히어로** — "사고 나면 **내가 책임집니다**" (중앙 정렬, 빨간 에이브로우)
2. **법적 현실 배너** — 10억 / 347% / 5인 확대 / 1년+ (빨간 배경 수치 배너)
3. **TAI가 리스크를 줄이는 방법 — 6개 카드** (기획서 표 그대로)
   - 위험도 대시보드: "상급자나 대표도 상세히 확인할 수 있습니다"
   - 법적 증거 자동 확보: "안전점검 시 문제가 전혀 없습니다"
   - 법령진단 리포트: "계획하고 관리하고 있다고 어필할 수 있는 문서"
   - 의무 누락 방지: **"중대재해처벌법은 어림없습니다"**
   - 비용 최적화: "자산을 잘 지킬 수 있습니다"
   - 전문가 연결: "TAI가 확실히 연결합니다"
4. **법적 증거 자동 확보 워크플로우** — 4단계 (index-3 work-area 구조)
5. **CTA** — [무료 법령진단 시작] [전문가 상담 요청] (index-3 cta-area 구조)
6. **크로스링크** — 안전관리자용 페이지 하단 링크

### 주요 특징
- `home-3 sc5` body class, Lato 폰트 (Nexas 원본 스타일 준수)
- 각 카드에 기획서 원문 인용구를 `highlight` 박스로 강조
- 이미지 플레이스홀더 명시 (실제 스크린샷 교체 예정)
