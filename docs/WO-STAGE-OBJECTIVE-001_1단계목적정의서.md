# WO-STAGE-OBJECTIVE-001
# 1단계 목적 정의서 (고정문서)

**작성일:** 2026-06-23 | **상태:** 확정
**우선순위:** 최상위
**목적:** 이후 모든 WO의 판단 기준이 되는 1단계 목표를 고정한다.
**이 문서는 수정하지 않는다. 이후 WO는 이 문서에 부합하는지 검증하며 진행한다.**

---

## 1. 문제 정의

현재 프로젝트는 다음 두 세계를 연결하려고 한다.

### 입력 세계

```
산업 / 건설 / 건물
```

입력값 예시:
```
KSIC          업종 분류코드
공정           작업·제조 공정명
설비           보유 설비 종류
시설           운영 시설 종류
위험물         취급 물질·유해인자
인원           근로자 수
면적           작업장·건물 면적
수량           저장량·취급량
전력           전기 용량
압력           기압·압력 조건
보유여부        has_* boolean
```

### 법령 세계

```
법 / 시행령 / 시행규칙 / 별표 / 조문 / 의미절
```

법령 구성요소 예시:
```
정의           용어 정의
조건           의무 발생 조건
의무           사업주가 해야 할 것
예외           적용 제외
참조           다른 조문 연결
처벌           위반 시 벌칙
적용범위       적용 대상 범위
위임           하위 법령으로 위임
```

---

## 2. 1단계 목적

### 목적

```
입력 세계와 법령 세계를
동일한 패턴 체계로 표현할 수 있는지 검증한다.
```

### 목적이 아닌 것

현재 단계는 다음을 목표로 하지 않는다.

```
❌ 의무 계산
❌ 체크엔진 완성
❌ 정확도 측정
❌ VCF 검증
❌ 법령 추천
❌ 커버리지 측정
```

---

## 3. 핵심 원칙

### 원칙 1: 패턴을 만들지 않는다 — 패턴을 발견한다

인위적으로 분류 체계를 설계하지 않는다.
입력 세계와 법령 세계에 이미 존재하는 패턴을 찾아낸다.

### 원칙 2: 원본을 수정하지 않는다

```
원본 보존
  ↓
스테이징 분석
  ↓
패턴 추출
```

이 순서로만 진행한다.
원본 테이블(semantic_clause, factories, equipment_assets 등)은 건드리지 않는다.

### 원칙 3: 매핑을 먼저 만들지 않는다

```
입력 분석
  ↓
법령 분석
  ↓
패턴 발견
  ↓
후보 매핑
  ↓
검증
  ↓
운영 매핑
```

이 순서를 건너뛰지 않는다.
"입력값 하나 → 법령 하나" 방식으로 바로 내려가지 않는다.

### 원칙 4: 산업·건설·건물을 처음부터 분리한다

```
INDUSTRIAL    산업
CONSTRUCTION  건설
BUILDING      건물
```

공통으로 합치지 않는다.
공용 법령도 COMMON이 아닌 다중 섹션 배열로 표현한다.

## 4. 1단계 산출물

### 산출물 A: Input Staging Catalog

**목적:** 입력 원본 전체 수집

포함 대상:
```
KSIC          한국표준산업분류 전체
PROCESS       공정명 전체
EQUIPMENT     설비 코드·종류 전체
FACILITY      시설 종류 전체
MATERIAL      물질·위험물 종류
HAZARD        유해인자 (has_* boolean)
BOOLEAN       보유여부 전체
NUMERIC       수치 조건 필드 전체
```

**이 단계에서 분류·판단하지 않는다. 수집만 한다.**

### 산출물 B: Law Staging Catalog

**목적:** 법령 원본 전체 수집

포함 대상:
```
조문           semantic_clause 전체
별표           appendix_condition 전체
시행령         law_article (시행령) 전체
시행규칙       law_article (시행규칙) 전체
의미절         content_type 분포 전체
```

**이 단계에서 분류·판단하지 않는다. 수집만 한다.**

### 산출물 C: Pattern Discovery Catalog

**목적:**
```
입력 패턴 발견
법령 패턴 발견
```

Input Staging + Law Staging 완료 후 시작한다.
패턴은 수집된 원본에서 귀납적으로 도출한다.

## 5. 성공 기준

다음 상태에 도달하면 1단계 성공이다.

```
✅ 산업 입력 전체 파악
✅ 건설 입력 전체 파악
✅ 건물 입력 전체 파악
✅ 법령 패턴 전체 파악
✅ 패턴 후보 도출 가능 상태 도달
```

---

## 6. 실패 기준

다음이 발생하면 1단계 실패로 본다.

### 실패 1: 개별 매핑으로 회귀
```
입력값 하나 → 법령 하나
```
방식으로 계속 내려가는 경우.

### 실패 2: 매핑 생성이 목적이 되는 경우
매핑 건수 늘리기, 커버리지 측정이 목표가 되는 경우.

### 실패 3: 정확도 측정이 목적이 되는 경우
VCF 재실행, 결과 수치 검증이 목표가 되는 경우.

### 실패 4: 엔진 구현이 목적이 되는 경우
체크엔진 완성, API 연결, 서비스 배포가 목표가 되는 경우.

## 7. 이 문서의 사용법

**모든 후속 WO는 실행 전에 다음 질문에 답해야 한다:**

```
Q1. 이 WO는 입력 원본 수집 또는 법령 원본 수집에 해당하는가?
Q2. 이 WO는 패턴 발견에 해당하는가?
Q3. 이 WO가 "매핑 생성"을 목적으로 하고 있지 않은가?
Q4. 이 WO가 원칙 1~4를 위반하지 않는가?
```

Q1 또는 Q2에 해당하고, Q3·Q4를 위반하지 않으면 진행한다.
하나라도 어긋나면 WO를 수정하거나 중단한다.
