## 주요 발견사항

### 이니시스 매뉴얼 기반 확인
1. **결제창 VAT 분리 표시 불가** — `tax`/`taxfree` 파라미터는 세무 정산용, 결제창 UI에는 goodname + price만 표시
2. **`tax`/`taxfree` 사용 조건** — "부가세 업체정함" 계약 MID만 설정 가능. TAI MID가 해당 계약인지 이니시스 가맹점관리자에서 확인 필요
3. **`payViewType=popup`** — 별도 팝업 창으로 열려 검은 배경 없음. 단, 결제 에러 발생하여 원복함 (추가 조사 필요)
4. **goodname 40byte 제한** — VAT 내역 포함 시 초과 가능, 상품명만 넣기로 확정

### billing_pay.html CORS 패턴
```
billing_pay.html이 Cloudflare 프록시 경유 시:
  origin = taieng.co.kr
  fetch → api.taieng.co.kr (cross-origin) → CORS 차단

수정 후:
  fetch → taieng.co.kr/_api/ (same-origin) → 정상
```
