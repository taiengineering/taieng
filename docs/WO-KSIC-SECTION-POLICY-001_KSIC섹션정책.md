## 산출물 B: SECTION 배정 원칙

### 판정 5문항

```
Q1. 산업안전 의무의 주 발생 영역인가?     → 그렇다면 서비스 IN-SCOPE
Q2. 생산설비·공정·유해물질 중심인가?      → INDUSTRIAL
Q3. 건설공사·현장 중심인가?               → CONSTRUCTION
Q4. 건물 운영·관리·시설 중심인가?         → BUILDING
Q5. 서비스 범위 밖인가?                   → UNUSED
```

### 배정 우선순위 규칙

```
규칙 1: 산업안전보건법 적용 핵심 업종 우선 배정
  - 제조·건설은 산안법 의무가 가장 집중 → 즉시 확정

규칙 2: "사업장의 물리적 위험 형태"로 판단
  - 어떤 법인지가 아니라, 어떤 위험이 발생하는 공간인지

규칙 3: 한 KSIC가 복수 SECTION 성격을 가질 수 있음
  - 예: 병원(Q) = 건물 운영(BUILDING) + 의료설비(일부 INDUSTRIAL)
  - 이 경우 "주된 위험 형태"로 1차 배정, 복합은 보류

규칙 4: 확신 부족 시 즉시 확정하지 않고 보류
  - 잘못된 확정보다 보류가 안전

규칙 5: UNUSED와 ORPHAN 엄격 구분
  - UNUSED = 의도적 제외 (정책 결정)
  - ORPHAN = 분류 미완 (작업 미완)
```

## 산출물 E: 보류 영역

**즉시 확정 금지 — 11개 대분류**

```
G 도소매업       물류창고 vs 매장 혼재
H 운수·창고업    창고 vs 운송 혼재
I 숙박·음식점     건물운영 vs 주방설비
J 정보통신       데이터센터 vs 사무
K 금융·보험       사무 건물
L 부동산          건물 관리
M 전문·과학·기술  연구소 vs 사무
N 사업시설관리    시설관리 주체 자체
P 교육            학교 vs 실습설비
Q 보건·사회복지   병원 건물 + 의료설비
R 예술·스포츠     공연장·체육시설
S 협회·수리·개인  수리업 vs 사무
```

### 보류 사유 핵심 패턴

```
패턴 1: BUILDING vs INDUSTRIAL 경계 모호
  → 건물을 운영하는가, 건물 안에서 생산하는가?
  예: G 물류창고(INDUSTRIAL 성격) vs G 백화점(BUILDING 성격)

패턴 2: 시설관리 주체 vs 사용 주체 구분 필요
  → N 사업시설관리업은 BUILDING의 "관리 주체"일 수 있음
  예: 시설관리회사가 곧 BUILDING 섹터 고객

패턴 3: 복합 위험 (BUILDING + 일부 INDUSTRIAL)
  → Q 병원 = 건물 운영 + 의료설비·비상발전기·보일러
  → 1차는 BUILDING, 설비는 EQUIPMENT 경로로 별도 처리 검토
```

### 보류 영역 처리 방침

```
1. 보류 영역은 "BUILDING 후보"로 잠정 표시하되 status = 보류
2. lv2(중분류) 단위로 다시 검토 필요
   예: H 운수창고 중 "창고업(52)"만 별도 검토
3. 실제 고객 유입 시점에 케이스별 확정
4. 절대 추측으로 INDUSTRIAL/CONSTRUCTION에 강제 배정하지 않음
```

## 산출물 F: UNUSED 정책

### UNUSED vs ORPHAN 엄격 구분

```
UNUSED (정책 결정)
  정의: 현재 서비스 범위에서 의도적으로 제외
  대상: A 농림어업, O 공공행정, T 가구내고용, U 국제기관
  특성: "안 하기로 결정함" — 향후에도 검토 대상 아님
  status = 'UNUSED'

ORPHAN (작업 미완)
  정의: 아직 분류하지 못함
  대상: lv1_code NULL 공정 265개, 설비 미분류 195종
  특성: "아직 못 함" — 분류 작업 대기
  status = 'ORPHAN'
  section = NULL

보류 (BACKLOG, 신규 상태)
  정의: 분류는 가능하나 확정 근거 부족
  대상: G,H,I,J,K,L,M,N,P,Q,R,S (11개 대분류)
  특성: "할 수 있으나 아직 확정 안 함"
  status = 'CANDIDATE' + section_hint = 'BUILDING'(잠정)
```

**3개 상태는 절대 혼동하지 않는다:**
- UNUSED = 안 함 (정책)
- 보류 = 나중에 함 (백로그)
- ORPHAN = 작업 미완 (오류·미연결)

## 정책 요약

```
21개 KSIC 대분류 →

확정 9개:
  INDUSTRIAL (4):  B C D E
  CONSTRUCTION (1): F
  UNUSED (4):      A O T U

보류 11개 (잠정 BUILDING 후보):
  G H I J K L M N P Q R S

BUILDING 확정 0개:
  ← BUILDING은 보류 영역에서 lv2 검토 후 확정 예정
  ← 현재 BUILDING으로 확정된 대분류 없음 (중요)
```

### 핵심 발견: BUILDING 확정 대분류가 없다

```
현재 BUILDING으로 즉시 확정 가능한 KSIC 대분류는 없다.
BUILDING 후보는 전부 보류 영역(G~S)에 있으며,
대부분 "건물 운영 vs 다른 성격"의 경계 판단이 필요하다.

→ BUILDING 섹터는 lv2(중분류) 단위 정밀 분류가 필수.
→ 다음 WO에서 보류 11개를 lv2로 쪼개 검토해야 함.
```

## 근거 자료 (현재 사업장 분포)

```
현재 factories의 sector 컬럼은 KSIC와 독립적으로 설정되어 있음:
  C 제조업 213개 → sector가 BUILDING/CONSTRUCTION/INDUSTRIAL 혼재
  F 건설업 5,063개 → sector 혼재
  
→ 현재 sector 컬럼은 신뢰할 수 없음 (KSIC와 불일치)
→ 이 정책표가 KSIC 기반 SECTION 재배정의 기준이 되어야 함
→ 단, factories.sector 수정은 이번 WO 범위 외 (INSERT/UPDATE 금지)
```

**중요 발견:** 현재 `factories.sector`가 KSIC와 정합하지 않음.
C 제조업인데 sector가 BUILDING으로 된 레코드 존재.
이 정책표가 향후 정합화의 기준 문서가 된다.
