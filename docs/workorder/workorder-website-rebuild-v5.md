## 대원칙

### 디자인 방향
1. **원본 Nexas 템플릿의 보라색 그라디언트 상단을 그대로 사용한다** (index-1.html의 sc5 클래스, 배너 영역)
2. **어둡고 강하고 경계를 강조하지 않는다** — 안전관리가 무겁게 느껴질 필요 없음. Nexas 원본의 밝고 깔끔한 색감이 TAI와 맞음
3. **Nexas 원본 폰트(Lato)와 컬러 팔레트를 그대로 사용한다**
4. **index-1 ~ index-6 템플릿 레이아웃을 서비스별로 다르게 활용한다** (아래 매핑 참고)
5. **이미지가 필요한 곳에는 placeholder + 설명 텍스트를 넣는다** ("[이미지: 안전관리자가 모바일로 점검하는 장면]" 형태)

### 콘텐츠 방향
1. **슬로건에 집중하지 말고, 실질적 가치를 전달한다**
2. **소비자가 "이게 뭔지", "나한테 왜 필요한지", "구체적으로 뭘 해주는지"를 알 수 있어야 한다**
3. **대표님의 20년 현장 경험에서 나온 구체적 장점들이 사이트에 묻어나야 한다**
4. **한 페이지에 너무 많이 담지 말고, 페이지별 역할을 명확히 한다**
5. **【절대 금지】소개비, 소개수수료, 인력소개, 소개료 — 대체 용어만 사용**

### 기술 방향
1. **Nexas 원본 CSS/JS를 그대로 사용** (assets/css/style.css, assets/js/main.js 등)
2. **header.js / footer.js로 네비게이션·푸터 통일**
3. **node_modules/ 는 .gitignore에 추가하고 git에서 제거**
4. **Nexas.zip, prepros.config는 nexas/ 폴더에서 제거 (nexas_sample에만 보관)**

#### 섹션: 현장의 진짜 고민 (Pain Points)
실제 대화체로:
- "점검 일정을 직접 엑셀로 관리하고, 작업자한테 일일이 연락합니다"

| D-3 사전 알림 | SMS·카카오톡 자동 발송. 누락으로 인한 과태료 위험이 사라집니다 |
| 신고서식 자동화 | 서류 작성에 쓰던 시간을 안전관리에 쓸 수 있습니다 |
| TBM 전자서명 | 종이 들고 다니며 서명 받을 필요 없습니다. 모바일에서 바로 |

### 4. service/saas.html — SaaS 구독
**기반 템플릿:** nexas_sample/index-4.html
**역할:** SaaS 제품 상세 설명

#### 핵심 메시지
"아직도 종이나 엑셀로 안전관리를 하고 계십니까? 마땅한 프로그램이 없어서 그랬을 겁니다. TAI Safe가 답입니다."

#### 섹션: 현실 (왜 필요한가)
- 아직도 종이나 엑셀을 사용하는 게 현실. 마땅한 프로그램이 없어서입니다.
- 안전관리자는 서류 작성 하느라 정작 안전관리를 하기 어렵습니다.
- 겸직까지 하면 더 요식행위를 하게 됩니다.

#### 섹션: 구체적 기능 (아코디언 또는 좌우 교차)
1. **법령 기반 자동 일정** — 한번만 세팅하면 놓치지 않음
2. **작업자 배정 + D-3 알림** — SMS/카카오톡 자동
3. **현장 앱** — 1분 이내 처리, QR/RFID 점검
4. **TBM 전자서명** — 종이 불필요
5. **비상 알림** — 골든타임 확보
6. **기록 자동 보관** — 안전점검 시 완벽 대응
7. **경영진 대시보드** — 상급자/대표도 확인 가능
8. **법 변경 자동 적용** — 바뀌는 법에 마음 놓을 수 있음
9. **전자계약** — 도장 찾지 않아도 됨, 항상 보관
10. **신고서식 자동화** — 서류 시간 → 안전관리 시간으로

#### 섹션: 가격 미리보기
- 기본 79,000원/월
- 프리미엄 149,000원/월
- "컨설팅 비용과는 상대도 안 될 만큼 저렴합니다"
- [요금제 상세 보기] → pricing.html

| | 무료 진단 | 유료 진단 |
|---|----------|----------|

### 15. about.html — 회사소개

#### 대표 스토리
> 전기기사를 준비하면서 안전관리자 선임을 생각했을 때,
> 혼자 감당할 수 없다는 것을 깨달았습니다.
> 법을 모르고, 뭘 해야 하는지 모르고, 혼자 다 해야 하는 구조.
> 현실은 요식행위 — 안 걸리면 그만.
> 하지만 작업자가 대충이라도 체크하는 것이 아예 안 하는 것보다 낫습니다.
> 그래서 TAI Safe를 만들었습니다.

#### TAI 철학
- "안전관리는 이렇게 해야 돼"가 아니라 "이렇게 하면 안전관리가 잘 된다"를 만들고자 합니다
- 안전관리자와 현장의 입장에서 설계하고 만들었습니다
- 지속적으로 연구하고 개발하고 있습니다
