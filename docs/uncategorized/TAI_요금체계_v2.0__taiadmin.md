## 2. 월정액 구독 플랜

### 과금 기준
- 시설 기본료 + 참여 사용자 수 혼합
- 법령진단 미포함 (별도 단건 유료)

| 구분 | STARTER | BUSINESS | ENTERPRISE |
|------|---------|----------|------------|
| 대상 | 5~30인 | 30~100인 | 100인+ |
| 기본료 | 월 49,000원 | 월 99,000원 | 협의 |
| 포함 인원 | 10명 | 30명 | 협의 |
| 초과 1인당 | 월 3,000원 | 월 2,500원 | 협의 |
| 시설 수 | 1개 | 3개 | 무제한 |
| 업무 할당·분산 | ✅ | ✅ | ✅ |
| 개르 관리 | ✅ | ✅ | ✅ |
| 누락 알림 | ✅ | ✅ | ✅ |
| 실행 이력 | 6개월 | 무제한 | 무제한 |
| API 연동 | ❌ | ✅ | ✅ |
| 법령진단 | ❌ (별도 유료) | ❌ (별도 유료) | 협의 |
| 연간 할인 | 2개월 무료 | 2개월 무료 | 협의 |

### 요금 계산 예시

| 사업장 | 인원 | 플랜 | 월 요금 |
|------|------|------|--------|
| 소규모 제조공장 | 15인 | STARTER | 49,000 + 5인×3,000 = **64,000원** |
| 중소 제조공장 | 30인 | BUSINESS | 99,000 (30명 포함) = **99,000원** |
| 건설 현장 | 50인 | BUSINESS | 99,000 + 20인×2,500 = **149,000원** |
| 복지시설 | 20인 | STARTER | 49,000 + 10인×3,000 = **79,000원** |
| 대형 공장 | 80인 | BUSINESS | 99,000 + 50인×2,500 = **224,000원** |

| 일반건물 | 무료 | 29,000원 | 59,000원 | 99,000원 |
| 제조·공장 | 무료 | 49,000원 | 99,000원 | 249,000원 |

## 4. 공공기관(B2G) 전략 — 별도 추후 적용

| 단계 | 방법 | 시점 |
|------|------|------|
| 1단계 | 공공기관 직접 수의계약 (2천만원 이하) | 지금 즉시 |
| 2단계 | 혁신장터(ppi.go.kr) 등록 | 사업자등록 후 3개월 |
| 3단계 | GS인증 → 나라장터 등록 | 법인 전환 후 6~12개월 |
| 4다계 | CSAP → 디지털서비스몰 | 1~2년 후 |
