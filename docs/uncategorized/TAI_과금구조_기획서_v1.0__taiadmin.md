## 2. SaaS 구독 가격 — 겸직 현실 반영

### 2.1 주요 고객 특성

```
산업안전보건법상 안전관리자 선임 형태:
  전담 / 겸직 / 안전관리 대행 3가지

중소기업 현실 (TAI Safe 주 타깃):
  50인 미만: 생산팀장·총무가 안전 겸직
  50~300인: 전담 있지만 보건·환경·총무 겸직 다수
  300인 이상: 전담 (TAI Safe 필요성 낮음)

겸직 안전관리자 실태:
  월 안전 실투입 시간: 3~5시간
  "안전은 내 본업이 아니다"
  "뭘 해야 하는지도 잘 모른다"
  → TAI Safe가 가장 필요한 사람
```

### 2.2 가격 책정 근거

```
대체 비용 비교:
  안전관리 대행기관: 월 150,000~300,000원
  안전관리자 직접 고용: 월 300~400만원
  중대재해 과태료 최소: 300만원
  → TAI Safe 79,000원 = 대행비용의 1/2

겸직자 시간 가치:
  월 3~5시간 절감 × 시급 15,000~20,000원
  = 월 45,000~100,000원 가치
  → 79,000원 = 정확히 이 범위

"본업 방해 안 받으려면 79,000원은 납득 가능"
```

### 2.3 플랜별 요금

| 플랜 | 대상 | 월 기본료 | 포함 인원 | 초과 1인당 |
|------|------|---------|---------|----------|
| STARTER | 5~30인 (겸직 타깃) | **79,000원** | 10명 | 4,000원 |
| BUSINESS | 30~100인 (겸직+전담) | **149,000원** | 30명 | 3,500원 |
| ENTERPRISE | 100인+ (전담) | **협의 (300,000~)** | 협의 | 협의 |

```
연간 결제: 2개월 무료 (~17% 할인)

계산 예시:
  20인 제조공장 STARTER:
    79,000 + 초과 10명 × 4,000 = 119,000원/월
  50인 건설현장 BUSINESS:
    149,000 + 초과 20명 × 3,500 = 219,000원/월
```

| 기능 | STARTER | BUSINESS | ENTERPRISE |
|------|---------|----------|------------|
| 업무 할당·분산 | ✅ | ✅ | ✅ |

```
  → "다 돈 받는다" 반발 없음
```

## 3. 부가기능 과금 — 포함 건수 초과 시

### 3.1 고객에게 보이는 방식

```
나쁜 표현 (반발 유발):
  "SMS 전송 추가 9,000원/월"
  "서류 자동제출 19,000원 별도"

좋은 표현 (자연스러운 업셀):
  "이번 달 SMS 100건 초과했습니다.
   추가 100건: 5,000원
   또는 BUSINESS로 업그레이드하시면
   월 300건 포함됩니다."

크레딧 단어는 고객에게 노출 안 함
→ 내부 정산 단위로만 사용
→ 고객에게는 "건수"로 표시
```

### 3.2 부가기능별 초과 단가

|------|---------|------|------|

| 카카오 알림 | 100건 | 3,000원 | 건당 30원 |
| 서류 자동작성 | 10건 | 5,000원 | 건당 500원 |
| 전자제출 연동 | 1건 | 1,000원 | 전산 가능 기관만 |

## 4. 신고서식 자동화 — "서류 자동제출" 재정의

### 4.1 명칭 변경

```
기존: "서류 자동제출"
변경: "신고서식 자동화"

이유:
  전산 불가 서류도 있음
  고객 기대와 현실 불일치 방지
  → 환불 분쟁 예방
```

### 4.2 접수 방법별 서비스 구성

| 접수 방법 | 서비스 내용 | 과금 |
|---------|---------|------|
| 전자제출 가능 | 고용노동부·소방청 자동 제출 | 건당 크레딧 |
| 팩스 가능 | 인터넷팩스 자동 발송 | 건당 크레딧 |
| 우편 필요 | 우편 대행 서비스 | 건당 유료 (규모 후) |
| 방문만 가능 | 출력 + 접수처 주소·시간 안내 | 무료 |

### 4.3 화면 표시 방식

```
각 서류마다 접수 방법 뱃지 표시:
  [전자제출 가능] → 크레딧 자동 차감
  [팩스 가능]    → 크레딧 자동 차감
  [우편 필요]    → 대행 신청 or 직접
  [방문 필요]    → 접수처 정보 안내

→ 투명한 안내 → 신뢰도 상승
→ 기대 불일치 없음
```

## 5. 초기세팅 지원 — 1회성 유료

```
구독과 분리된 별도 서비스

내용:
  시설 정보 등록 대행
  설비·공정 초기 입력 지원
  관리자 교육 (1시간)
  첫 달 점검 일정 셋업

가격:
  기본 세팅: 49,000원 (원격)
  심화 세팅: 99,000원 (방문)

포지셔닝:
  "세팅 도와드립니다" → 별도 고품질 서비스
  구독에 포함시키면 기대치 관리 어려움
  분리하면 → 오히려 프리미엄 서비스로 인식
```

## 6. 가격 인상 불가 원칙 — 처음부터 제대로

```
한 번 정한 가격은 올리기 어렵다:
  기존 고객 반발 → 해지 → 부정적 리뷰
  Netflix·Slack·Adobe 사례 모두 동일

처음 고객이 없을 때가 가장 쉬운 인상 타이밍:
  지금 → 아무 고객도 없음
  → 79,000원으로 시작하는 게 최적

얼리버드 전략 (선택적 활용):
  초기 고객 한정: 49,000원 평생 유지 약속
  → 초기 레퍼런스 확보
  → 이후 신규는 정가 79,000원
  → 기존 고객 반발 없음 (약속된 것)

가격 올릴 때 유일하게 쉬운 방법:
  새 기능 추가 + 가격 조정 동시 발표
  → "기능이 많아졌으니 가격 올랐다" 납득
```

```

  "안전관리 업무 효율화"
  → 전담자 수 적음, 예산 결재 어려움

올바른 메시지 (겸직 타깃):
  "안전이 본업이 아닌 분들을 위해"
  "매달 뭘 해야 할지 시스템이 알려줍니다"
  "담당자가 바뀌어도 이력이 남습니다"
  "과태료 걱정 없이 본업에 집중하세요"

핵심:
  겸직자의 페인포인트 정확히 겨냥
  79,000원 = "본업 방해 안 받으려면 충분"
```

## 9. 요약 — 핵심 원칙 5가지

```
1. 처음부터 제대로 된 가격 (79,000원~)
   한 번 정하면 올리기 어렵다

2. 기본 구독에 충분한 가치 포함
   SMS·카카오·서류 기본 건수 포함
   → "다 돈 받는다" 반발 없음

3. 크레딧은 내부 정산만
   고객에게는 "건수"로 표시
   → B2B 반발·결재 문제 없음

4. "서류 자동제출" → "신고서식 자동화"
   전산 불가 서류 현실 반영
   접수 방법 뱃지로 투명하게 안내

5. 겸직 안전관리자가 주 타깃
   "안전이 본업이 아닌 분들을 위해"
   시스템이 알아서 관리해주는 것
```
