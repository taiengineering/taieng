## 발견 3. 잘림 종조사 패턴 (가장 큰 신규 발견)

분해기 `split_or` 함수가 "또는"으로 분해한 후, executor 추출이 잘린 부분 텍스트를 사용해 주어가 잘림.

샘플:

```
executor_text: "교육업무수탁단체의 장 또"
source_text:   "교육업무수탁단체의 장 또는 전기 관련 기관의 장은 다음 각 호의 구분에 따라
                해당 호에서 정한 자료를 다음 해 1월 31일까지 기후에너지환경부장관에게 보고해야 한다."

executor_text: "관리주체는 건설사업자 또"
source_text:   "관리주체는 건설사업자 또는 그 시설물을 시공한 자[하자담보책임기간(...)
                내인 경우에 한정한다]로 하여금 시설물의 유지관리를 대행하게 할 수 있다."

executor_text: "장애인의 가족 또"
source_text:   "장애인의 가족 또는 장애인을 보호하고"
```

→ executor가 종조사로 끝나면 NULL 정정 후 paragraph/article inherit.
