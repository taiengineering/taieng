## 3. T1 (606 법령 추출) 작업 가이드

### 3.1 KEC vs 745 master 차이

| 항목 | KEC | 745 master (606 = 745-139 추정) |
|---|---|---|
| 본문 형식 | PDF 1개 (1,234p) | **article_text에 이미 구조화** |
| 추출 단계 | PDF → pdfplumber → Gemini → Sonnet | **Gemini → Sonnet만** |
| chunk 분할 | 5 chunks | **article 단위 자연 분할** |
| 점번호 형식 | `234.2.1` (hierarchical) | 법령마다 다름 (제N조, 별표 N 등) |

| 시간 | 30분 | 5~10시간 |

→ 745 트랙은 **단순함** (PDF 단계 불필요, article_text 그대로 사용).
→ v2.7~v2.10 보강 그대로 적용 가능.

### 3.2 T1 진행 절차 (Cursor 정식 코드 권장)

```
extract_745_master.py
├─ 1. master 선택 (active=true, draft 0건인 606)
├─ 2. master별 article 순회
│   ├─ article_text 직접 사용 (PDF 추출 skip)
│   ├─ Gemini chunk 추출 (article 단위)
│   └─ Sonnet 검증 (v2.7 4보강 + v2.8 ctx prefix + v2.9 멀티 위치 + v2.10 batch=1)
├─ 3. CSV 출력
└─ 4. drafts INSERT (insert_kec_to_drafts.py 응용)
    ├─ master_id / version_id / article_id 채워서 INSERT
    └─ source_api = "gemini_pro_v2_10_745master"
```
