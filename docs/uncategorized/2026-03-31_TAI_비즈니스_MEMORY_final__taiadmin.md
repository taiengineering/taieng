## 4. 법령진단 요금체계 v3.0

### 핵심 원칙
```
무료에서 주는 것:
  법령 수 (숫자만)
  선임의무 여부 (O/X만)

무료에서 주지 않는 것:
  법령명 / 조문 / 과태료 금액 (← 핵심 전환 트리거) / 점검 항목
```

| 단계 | 가격 | 데이터 |
|------|------|--------|
| 기초 | 무료 | diagnosis_stage=1 / APPOINT 30건 |
| 표준 | 99,000원 | stage=1 전체 401건 |
| 설비 | 199,000원 | stage=2 설비점검 매핑 |
| 종합 | 249,000원 | stage=3 + work_schedules |

### 건설 (CONSTRUCTION)

| 단계 | 가격 | 특이사항 |

| 기초 | 무료 | 건축 150억/토목 120억 기준 |

```
건설이 산업보다 비싼 이유:
```

## 5. 회원가입 필수 전환 전략

```
원칙:
  회원가입을 해야만 무료 서비스 이용 가능

이유:
  무료 체험 후 "나중에 결제" 사람 → 거의 돌아오지 않음
  회원가입 = 이메일 확보 = CRM 자동화 기반
  입력 데이터 저장 = 이탈 후 복귀 시 이어서 진행

전체 흐름:
  홈페이지
  → 회원가입 (이메일+비번 or 카카오/구글 1클릭)
  → 무료 진단 (KSIC + 근로자수)
  → 결과 화면 (과태료·법령명 블러 처리)
  → 결제 유도
  → 추가 입력 → 전체 결과
  → SaaS 구독 전환

이탈 시 CRM 시퀀스:
  즉시: 결과 요약 이메일
  1일 후: "과태료 확인하셨나요?"
  3일 후: 유사업종 사례 (과태료 2,000만원)
  7일 후: 10% 할인 쿠폰

핵심 UI:
  무료 결과 화면에서 과태료·법령명 블러 처리
  → "저 숫자가 얼마지?" → 결제 충동 유발
```
