### 1. 물질안전보건자료(MSDS) 조회
**URL:** https://www.data.go.kr/data/15157612/openapi.do

**활용 서비스:** SaaS 법령진단 / 위험성평가 (추후)

**연동 흐름:**
```
시설 정보 입력 시 설비 항목에 "화학물질 취급" 선택
  → 취급 물질명 입력
  → MSDS API 자동 조회
  → 유해성·위험성 등급 반환
  → 법령진단 엔진에 화학물질 조건코드 입력
  → 화학물질관리법 / 산안법 해당 룰 판정
  → 선임 의무 (유해화학물질 취급담당자) 자동 산출
```

**DB 연동:**
- `factories.hazardous_chemical_yn` → MSDS 조회 트리거
- `equipment_assets` 화학물질 저장탱크 설비 연동
- 법령룰 `condition_code: chemical_material` 조건 판정

**표시 화면:**
- factory-list.html 탭2 시설상세옵션 → 취급 화학물질 섹션
- 법령진단 결과 → 화학물질 관련 룰 조문 원문 링크

### 2. 안전보건법령 스마트검색
**URL:** https://www.data.go.kr/data/15123696/openapi.do

**활용 서비스:** SaaS 법령진단 / 홈페이지

**연동 흐름:**
```
법령진단 결과 → 적용 룰 목록 출력
  → 각 룰의 law_refs 코드 기반
  → KOSHA 스마트검색 API 호출
  → 산업안전보건법 해당 조문 원문 반환
  → "법령 원문 보기" 버튼으로 표시

또한:
  고객이 법령명 직접 검색
  → AI 유사어 검색 ("스카이" → 고소작업대)
  → 관련 조항 즉시 조회
```

**표시 화면:**
- factory-list.html 탭5 법령진단 결과 → 각 룰 옆 "조문 보기" 버튼
- 홈페이지 tai-safe.html → "법령 검색" 데모 기능
- tadmin 법령진단 결과 페이지

**추가 활용:**
- 중대재해처벌법 관련 조문 직접 연결
- KOSHA GUIDE 연동으로 법령 → 기술지침 원스톱 제공

### 3. 건설업 일별 중대재해 현황
**URL:** https://www.data.go.kr/data/15133935/openapi.do

**활용 서비스:** SaaS 대시보드 / 홈페이지

**연동 흐름:**
```
매일 자동 조회 (배치 or 실시간)
  → 작업공종 / 기인물 / 재해종류 / 위험성감소대책
  → Admin 대시보드 "오늘의 건설 중대재해" 위젯
  → 홈페이지 안전정보 페이지 자동 업데이트

건설업 고객 시설 해당 시:
  → 고객 tadmin에 "업종 관련 최근 중대재해" 알림
  → 유사 작업공종 재해 발생 시 푸시 알림
```

**표시 화면:**
- Admin index.html 대시보드 → 중대재해 현황 카드
- 홈페이지 safety-news.html → 건설업 재해 자동 피드
- tadmin 대시보드 → 업종 맞춤 위험 알림

**마케팅 활용:**
- "오늘 발생한 중대재해" → 법령진단의 필요성 강조
- 홈페이지 CTA와 연결 ("우리 현장은 안전한가요?")

### 4. 안전보건자료 링크 서비스
**URL:** https://www.data.go.kr/data/15139398/openapi.do

**활용 서비스:** SaaS 교육관리 모듈 / tadmin

**연동 흐름:**
```
법정교육 마스터(education_master) 20개 과목
  → 각 교육 과목명으로 KOSHA 자료 API 조회
  → 업종별 / 재해유형별 교육자료 URL 반환
  → 교육 이수 화면에 "관련 자료 바로보기" 제공

안전관리자 tadmin:
  → 교육 배정 시 관련 KOSHA 영상/교안 자동 첨부
  → 교육이력 기록과 함께 자료 링크 보관
```

**표시 화면:**
- tadmin education-list.html → 각 교육항목 옆 자료 링크
- tadmin education-setting.html → 법정교육별 자료 연동 설정
- Admin education-setting.html → 교육 콘텐츠 관리

**향후 활용:**
- 온라인 안전보건교육기관 등록 시 → 콘텐츠 라이브러리 기반
- 외국인 근로자 교육자료 (다국어 자료 포함)

### 7. 국세청 사업자등록정보 진위확인 및 상태조회
**URL:** https://www.data.go.kr/data/15073219/openapi.do (자동승인)

**활용 서비스:** 선임연결 / 수선중개 공급자 검증

**연동 흐름:**
```
공급자 등록 신청 시 (안전관리전문기관 / 수선업체)
  → 사업자등록번호 입력
  → 국세청 API 실시간 조회
  → 정상 / 휴업 / 폐업 상태 반환
  → 정상 사업자만 다음 단계 진행
  → 결과를 verification_logs에 저장

고객사 등록 시:
  → 회사 등록 시 사업자번호 진위 확인
  → 계약 체결 전 상태 재확인
```

**표시 화면:**
- 홈페이지 apply-repair.html → 사업자번호 입력 + [국세청 검증] 버튼
- 홈페이지 apply-business.html → 기업 등록 시 검증
- Admin 공급자 관리 화면 → 검증 상태 배지 표시

**DB 연동:**
- `repair_companies.license_verified` 필드
- `safety_agencies.license_verified` 필드
- `verification_logs` 테이블 기록

## 백엔드 창 전달 — 신규 개발 필요 항목

### API 라우터 신규 생성 필요

```python
# routers/kosha_api.py (신규)

GET /kosha/law-search?keyword={검색어}
  → 안전보건법령 스마트검색 프록시
  → 응답: 법령명 / 조항 / 원문 URL

GET /kosha/guide?category={분야}&keyword={키워드}
  → KOSHA GUIDE 조회 프록시
  → 응답: 지침번호 / 명칭 / PDF URL

GET /kosha/disaster-cases?industry={업종코드}
  → 국내재해사례 업종별 조회
  → 응답: 재해사례 목록 (최근 10건)

GET /kosha/education-materials?industry={업종}&type={재해유형}
  → 안전보건자료 링크 조회
  → 응답: 교육자료 URL 목록

GET /kosha/daily-accidents
  → 건설업 일별 중대재해 조회
  → 응답: 오늘/최근 중대재해 현황

GET /kosha/msds?chemical_name={물질명}
  → 물질안전보건자료 조회
  → 응답: 유해성 / 위험성 정보

POST /verify/business
  → 국세청 사업자 진위확인 (기존 verify 라우터 추가)
  → 요청: {biz_no}
  → 응답: {valid, status, company_name}
```
