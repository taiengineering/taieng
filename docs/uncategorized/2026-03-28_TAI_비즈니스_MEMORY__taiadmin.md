### 3. 법인설립 전략 (파산면책 고려)

**개인 현황:**
- 장애인 6급
- 이전 법인 3개 파산
- 2025년 9월 개인파산 면책 확정

**법적 결론:**
- 면책 확정 → 자동 복권 → 법인설립 법적으로 가능
- 단, **홈택스 체납 조회 먼저 필수** (법인 연대보증 체납 시 사업자등록 불가)
- 파산 공공기록: 면책 후 5년간 유지 (2030년 9월까지)

**현실적 전략:**
```
1단계 (지금): 개인사업자로 시작
  → 법인보다 간단, 신용심사 없음
  → 크몽/숨고 수익 창출
  → 직업소개업 신고 가능 (면책 후 결격사유 없음)

2단계 (6개월~1년): 수익 발생 후 법인 전환
  → startbiz.go.kr 셀프 온라인 등기
  → 비과밀 지역, 비용 10~15만원
  → 1인법인 + 지분없는 임원 1명 필요 (공증비 100만원 절감)

3단계 (2030년 이후): 파산기록 삭제 후 정상 금융거래
```

**법인설립 체크리스트 (시작 전 필수):**
```
□ 홈택스 체납 조회 (법인 연대보증 포함)

□ 이전 법인 3개 청산/폐업 완료 여부
□ 신용정보원 연체기록 삭제 확인 (www.credit.co.kr)
```

## 백엔드 창 전달 — 신규 개발 필요

### routers/kosha_api.py (신규 생성)
```python
GET /kosha/law-search?keyword={검색어}
  → 안전보건법령 스마트검색 프록시

GET /kosha/guide?category={분야}&keyword={키워드}
  → KOSHA GUIDE 조회 프록시

GET /kosha/disaster-cases?industry={업종코드}
  → 국내재해사례 업종별 조회 프록시

GET /kosha/education-materials?industry={업종}&type={재해유형}
  → 안전보건자료 링크 조회 프록시

GET /kosha/daily-accidents
  → 건설업 일별 중대재해 조회 프록시

GET /kosha/msds?chemical_name={물질명}
  → MSDS 물질정보 조회 프록시

POST /verify/business {biz_no}
  → 국세청 사업자 진위확인 (기존 verify 라우터에 추가)
```
