  → 법 지키는 것만 해도 벅참
  → 시스템이 알아서 해주는 것 필요

## 3. 회원가입 필수 전환 전략

```
원칙: 회원가입 해야만 무료 서비스 이용 가능

흐름:
  홈페이지
  → 회원가입 (이메일+비번 or 카카오/구글)
  → 무료 진단 (KSIC + 근로자수)
  → 결과 화면 (과태료·법령명 블러)
  → 결제 유도
  → 추가 입력 → 전체 결과
  → SaaS 구독 전환

이탈 시 CRM 시퀀스:
  즉시: 결과 요약 이메일
  1일 후: "과태료 확인하셨나요?"
  3일 후: 유사업종 과태료 사례
  7일 후: 10% 할인 쿠폰

복귀 시: 저장된 데이터 그대로 유지
```

### 구독 플랜

| 플랜 | 대상 | 월 기본료 | 포함 인원 | 초과 1인당 |
|------|------|---------|---------|----------|

| 기능 | STARTER | BUSINESS |

| 카카오 알림 | 월 100건 | 월 300건 |
| 서류 자동작성 | 월 10건 | 월 30건 |

### 초과 단가

| 기능 | 초과 단가 |
|------|----------|
| SMS 100건 | 5,000원 |
| 카카오 100건 | 3,000원 |
| 서류 자동작성 10건 | 5,000원 |

```

```

### 신고서식 자동화 접수 방법 4단계

| 방법 | 서비스 | 과금 |
|------|------|------|

| 팩스 | 인터넷팩스 자동 발송 | 건당 |
| 우편 | 대행 서비스 (규모 후 도입) | 건당 |
| 방문만 가능 | 접수처 주소·시간 안내 | 무료 |
