## 2. 핵심 전략 — 3종 유저 멀티 엔트리

### 2-1. 유저 분류 및 속마음

| 유저 | 속마음 (실제 키워드) | 필요한 것 |
|------|---------------------|----------|
| 🏢 안전관리자 (SaaS 도입 기안자) | 아직도 수기로? / 이걸 혼자 다~~ / 사고날까 불안불안 | ROI 근거 + 기안 자료 + 법적 안정성 |
| 👷 선임기술자 (수익 추구) | 엄청 짠 거 아냐? / 수수료는 얼마? / 얼마나 연락이 올까? | 수익 구조 공개 + 물량 증명 + 단가 투명성 |
| 🔧 수선업체 (일감 확보) | 얼마나 일이 들어올까? / 나한테 그 일이 떨어질까? / 수수료는 얼마나 줘야지 | 물량 보장 + 공정한 매칭 + 투명한 수수료 |

### 2-2. 첫 접속 — 역할 선택 모달 (전체화면)

첫 접속 시 전체화면 팝업 모달로 역할을 선택합니다.

| 역할 카드 | 이동 페이지 | 핵심 메시지 |
|----------|-----------|------------|
| 🏢 기업 / 안전관리자 | index.html (홈) | "이걸 혼자 다 하고 계신가요?" |
| 👷 선임기술자 | for-manager.html | "수수료 걱정 없이, 일감 걱정 없이" |
| 🔧 수선업체 | for-repair.html | "검증된 의뢰만, 투명하게" |

> 모달 하단: "다시 보지 않기" 체크박스 + localStorage 저장

- 배경: #F8FAFC 그라데이션 / min-height: 85vh
- 배지: "산업안전 AI 플랫폼"
- **헤드라인: "이걸 혼자 다 하고 계신가요?"**
- 서브: "선임 관리, 점검 일정, 법령 확인까지 혼자 감당하다 하나라도 놓치면 책임은 고스란히 당신 몫입니다."
- 버튼: [지금 시작하기 →] [소개서 받기]
- 우측: 법령진단 결과 모의 카드 (적용법령 261건 / 점검세트 67개 / 선임요건 10건)

### 섹션2 — 신뢰 지표 바
- 배경: #1A5FD4 / 텍스트: 흰색 / 4열
- 396개 적용 법령 | 118만건 설비 매핑 | 67개 자동 점검 세트 | 24시간 법령진단 완료

### 섹션3 — 문제 제기
- 제목: "혹시 이런 고민 있으신가요?"
- 📋 "아직도 수기로 관리하세요?" — 엑셀, 수첩, 전화... 이 방식으로는 언젠가 반드시 빠뜨립니다.
- 😓 "이 많은 걸 혼자 다 하세요?" — 법령 확인, 점검 일정, 선임 관리 — 사람이 할 수 있는 범위를 넘었습니다.
- ⚠️ "사고 나면 누가 책임지나요?" — 몰랐다는 건 이유가 안 됩니다. 법은 담당자에게 묻습니다.

### 섹션4 — 서비스 카드 (2×2 + 준비중 2개)
- TAI Safe (파랑) / TAI Manager (초록) / TAI Fix (주황) / TAI Care (빨강)

- 고용 형태: 상주 / 비상주 / 겸직
- CTA: [기술자 등록하기] → apply-manager.html

  - 🎯 "나한테도 매칭이 될까요?" → 인허가 인증 업체 우선 매칭
  - 💰 "수수료가 너무 많이 나가는 건 아냐?" → 수수료 상담 후 확정 / 숨겨진 비용 없음
- 검증: 사업자번호 → 국세청 검증 → 면허 확인 → 인증 배지 → 우선 매칭
- CTA: [업체 등록하기] → apply-repair.html
