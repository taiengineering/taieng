## 알려진 false alarm 패턴 (시작점 - 본 세션 학습)

### [본 세션] NFTC hierarchical 코드체계
- NFTC 102~609 같은 화재안전기술기준
- 같은 article_no=2 / type='항'에 100~175개 row가 있는 게 정상
- 식별 키: article_internal_key (예: nftc-sec-2.1.1.1)
- 추출 시 각 row를 독립 article로 처리

### [본 세션] art/misc 분리 컨벤션
- 방사선 안전관리 등의 기술기준에 관한 규칙
- 같은 article_no에 art-XXX (조문) + misc-XXX (장 헤더) 별도 row
- 추출 시 misc-XXX는 헤더라서 의무 없음 (skip)

### [본 세션] 안전기준 등록 9 master
- law_name 같지만 9개의 다른 차수 (2017-6, 2018-17, ..., 2023-589)
- 각 차수마다 다른 부처 소관 안전기준 신규 등록 (누적 문서)
- 의무 거의 없음 (메타 등록 문서)

### [본 세션] 한 고시로 여러 KC 안전기준 동시 제·개정
- 국가기술표준원 NOTICE
- (ministry_code, law_number) 조합이 같아도 다른 master 정상

### [본 세션] 타법개정

## 추출 시 회피 패턴 (PROMPT_v3.0.1 기반)

### [기본] 정의 조항
- "이 법에서 X란 ...을 말한다" → skipped

### [기본] 벌칙 조항
- "...한 자는 ...에 처한다" → skipped
- 단, 상위 의무는 다른 article에서 추출됨

### [기본] 부칙
- 시행일/경과조치/특례 → skipped

### [기본] 권한 위임
- "...은 대통령령/총리령/부령으로 정한다" → skipped
- 위임된 하위 법령에서 의무 추출

### [기본] 재검토
- "...에 대해 N년마다 그 타당성을 검토한다" → skipped

### [기본] 권한·재량
- "...할 수 있다" / "필요하다고 인정하면" → skipped (의무 아님)
