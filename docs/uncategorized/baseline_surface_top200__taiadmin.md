- → 정확한 빈도는 Kiwi 단일 NNP 분해 후 측정 필요

### 1. 부서명 단일 NNP 토큰화 검증
- 입력: "기후에너지환경부장관은 ... 한다"
- 기대: `기후에너지환경부(NNP) + 장관(NNG) + 은(JX) + ...`
- 미흡 시: 사용자 사전 등록 필요

### 2. 법령명 NNP 토큰화 검증
- 입력: "산업안전보건법 제38조"
- 기대: `산업안전보건법(NNP) + 제(XPN) + 38(SN) + 조(NNB)`
- Kiwi 기본 사전에 없으면 NF 또는 NNG 분해 → 사용자 사전 등록

### 3. 합성어 등록 정책 결정
- 환경부장관 → 단일 NNP vs 환경부 + 장관 분해?
- 환경부령 → 단일 NNP vs 환경부 + 령 분해?

### 4. "고시" 다의성 검증
- 명사 "고시" (고시 제2024-1호) vs 동사 "고시하다" (장관이 고시한다)
- Kiwi POS 태그 (NNG vs VV+EF) 분해 결과로 컴텍스트별 구분
