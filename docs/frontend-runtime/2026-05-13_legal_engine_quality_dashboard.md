# Legal Engine Quality Dashboard
## 2026-05-13

## 페이지
admin.taieng.co.kr/html/horizontal-menu-template/legal-engine-quality.html

## 구성
1. **Summary Cards** — 시나리오/PASS/FAIL/UNSUPPORTED/도메인/경계값
2. **Domain Coverage** — 6도메인 커버리지 바
3. **Scenario Grid** — 50건 필터/검색
4. **Boundary Values** — 5개 기준 3단계 시각화
5. **Unsupported** — 7건 명시
6. **Regression** — 실행 이력 + 수동 실행
7. **Publish Blocking** — 상단 alert
