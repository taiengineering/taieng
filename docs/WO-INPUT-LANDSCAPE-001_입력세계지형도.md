**관찰:**

- **설비 19개가 거의 고립** — 특정 공정에만 쓰이는 전용 설비.
- **KSIC는 고립 0** — 모든 업종이 최소 2개 이상 공정 보유. KSIC-공정 연결은 완전.

## 산출물 F: 발견사항

### 발견 1: 입력세계는 "설비 중심 조밀 네트워크"

```
설비 1개 = 평균 305개 공정에 연결
공정 1개 = 평균 48개 설비 보유

→ 설비가 공정보다 훨씬 범용적
→ 같은 설비(컨베이어 등)가 거의 모든 제조 공정에 출현
→ 설비 단독으로는 변별력이 낮을 가능성 (관찰만, 판단 보류)
```

### 발견 2: 전기 인프라 설비가 상위 HUB 다수 점유

```
배전반·분전반·수배전반·변압기·접지설비가 상위 15위 내 5개
→ 전기설비는 업종 무관 공통 인프라
→ 변별력 측면에서 주목 필요 (관찰만)
```

### 발견 3: 공정 17%가 설비 미연결 고립

```
3,378개 공정 중 571개(17%)가 설비 연결 0
→ 이 공정들은 process_equipment_map에 누락
→ ORPHAN 후보이나 이번 WO에서 확정 안 함 (관찰만)
```

### 발견 4: 공정명 중복 구조

```
process_id 3,378개 vs process_lv4 distinct 478개
→ 동일 공정명이 KSIC별로 7배 중복 존재
→ "용접" 공정이 여러 업종에 각각 별도 process_id로 존재
→ 패턴 발견 시 공정명 정규화 필요 가능성 (관찰만)
```

### 발견 5: KSIC-공정 연결은 완전, 공정-설비 연결은 불완전

```
KSIC 고립 0개   → KSIC ↔ 공정 연결 완전
공정 고립 571개 → 공정 ↔ 설비 연결 17% 누락

→ 입력세계의 약한 고리는 "공정-설비" 구간
```
