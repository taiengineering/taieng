## 금지 목록

| 금지 | 이유 |
|---|---|
| Audience 판단 | Notification Intelligence 영역 |
| Severity 판단 | Control Runtime 영역 |
| Suppression 판단 | Notification Intelligence 영역 (mute/disabled) |
| Digest 판단 | Notification Intelligence 영역 |
| Escalation 판단 | Control Runtime 영역 |
| Channel 선택 | Notification Intelligence 영역 |
| Event 의미 해석 | Notification Intelligence 영역 |

## 핵심

**Delivery는 전달만 수행한다.** "보내라"고 받은 것을 안전하게 전달하는 것이 전부.
