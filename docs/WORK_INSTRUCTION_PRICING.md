- 관리자/작업자 등록: **무제한**

## 페이지 디자인 구조

### 필수 구성
```
1. Hero 섹션
   - "요금제" 제목
   - 부제: "시설 1개 기준 과금 · 관리자/작업자 무제한 · 기능 동일"

2. 섹터 탭 (상단)
   - 산업 | 건물 | 건설
   - 탭 클릭 시 해당 섹터 가격표로 전환

3. 가격 카드 (3~4열)
   - 플랜명
   - 월 가격 (굵은 글씨)
   - 기준 설명 (예: "상시근로자 49인 이하")
   - 포함 기능 리스트 (모든 플랜 동일)
   - CTA 버튼: "시작하기" → free-diagnosis.html

4. 공통 기능 섹션
   - "가격 차이는 기능이 달라서가 아닙니다."
   - "사업장 규모에 따라 적용되는 법이 달라지기 때문입니다."
   - 전체 기능 리스트

5. FAQ 또는 문의 CTA
```
