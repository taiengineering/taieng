## 4. 별도 테이블이 필요한 SCOPE

### 4-1. 소방시설 / 소방대상물 (406건, SCOPE의 46.8%)

**특성:**
- executor가 사업주 **0%** — 전량이 관계인(인질개정자)/소방서장/시도지사/공사업자 의무
- 적용 법령: 소방시설법, 화재예방법
- TAI 타겟(사업주) 의무가 **존재하지 않음**

**결론:** Binding 계층에 포함하더라도 TAI 서비스 범위 밖. 별도 테이블을 만들어도 커버할 의무가 없음.

### 4-2. 작업환경측정 (66건, SCOPE의 7.6%)

**특성:**
- executor=사업주 48.8%(실질 81건 연결 조문)
- TAI 타겟 의무 존재함
- 트리거 조건: 유해인자 측정대상 작업장(=분진, 소음, 화학물질 해당 공정)
- 미등록 이유: 현재 process_equipment_map에 유해인자-공정 매핑 없음

**병도 테이블 필요 여부:** 필요 — 하지만 소방법령 처럼 TAI 외부 언어가 아님, 산안법 점유하는 데이터로 취급 가능.  
`process_equipment_map`에 유해인자(분진작업, 소음작업, 화학물질취급작업) 코드와 `factory_process` 연결 시 **매핑 가능한 옵로드 경로가 존재**.

### 4-3. 소화설비 / 피난설비 (256건, SCOPE의 29.5%)

**특성:**
- executor=사업주 25.5% — 사업주 의무 존재 (산안법 제구, 화학설비/위험물 장소)
- 조건: 화학설비, 위험물오, 화재 발생 우려 장소 어부
- 트리거 조건이 **설비/공정 입력값과 연결 가능**

**별도 테이블 필요 여부:** has_chemical_substance, 화학설비 업종+설비 등록 시 트리거 가능 — **현재 입력 항목으로 취급 가능하나 어휘 매핑 테이블 필요.**

## 6. 구조적 분석: Binding 계층의 실제 형태

### Binding 구조도 (지금 구축 가능한 경로)

```
[Layer 0] 소비자 입력
  ksic_code
  employee_count
  has_tower_crane / has_confined_space / has_blasting ... (8개)
  factory_process (process_id)
  equipment_assets (equipment_type_code)
       ↓
[Layer 1] KSIC 매핑 (테이블 존재)
  ksic_process_map → 업종별 대표공정 토출
  process_equipment_map → 공정별 대표설비 토출
       ↓
[Layer 2] Sieve (이미 있음)
  legal_sieve_rule 2,219건 → executor 필터링
       ↓
[Layer 3] SCOPE 매핑 (현재 미구축 ← 여기가 GAP)
  설비명 canonical_token ↔ SCOPE slot canonical_token 매핑 테이블 필요
       ↓
[Layer 4] 의무 트리거
  semantic_clause (OBLIGATION/PROHIBITION)
```

**Layer 3이 현재 비어 있음.** 테이블 생성 없이 어휘 매핑만 하면 방호장치/안전장치/경보설비 140건은 작동하는 구조.

## 7. 결론

### B. 일부 가능, 별도 입력/테이블 필요

### 7-1. 증거

| 항목 | 수치 | 판단 |
|---|---|---|
| Binding 즉시 가능한 SCOPE | 140건 (16.1%) | process_equipment_map 연결 존재 |
| 매핑 커버 사업주 의무 | 777건 (64.8%) | 현재 입력데이터 활용 시 |
| 커버 불가 사업주 의무 | 423건 (35.2%) | UNRESOLVED 조건 + 기타 |
| 소방계열 SCOPE (TAI 타겟 위) | 406건 | Binding 필요없음 (사업주 의무 0건) |
| 작업환경측정 (TAI 타겟 내) | 66건 | 유해인자-공정 어휘 매핑 필요 |

### 7-2. Binding 계층 구축에 필요한 것 (3가지)

**필요한 것 1 — SCOPE 어휘 매핑 테이블 (어휘 37헝):**  
설비명(방호장치, 안전장치, 경보설비...) ↔ SCOPE slot 코드 매핑 정의.  
지금 process_equipment_map.facility_name_std를 통해 미완성으로 로 존재.  
테이블 생성 없이 **혐약 어휘 매핑 데이터(연마)** 필요.

**필요한 것 2 — 유해인자-공정 매핑 (어휘 20헝 내외):**  
작업환경측정 66건 커버를 위해 분진·소음·화학물질 작업 종류 ↔ process_id 매핑.  
현재 process_equipment_map에 미등록. 어휘 정의만 필요.

**필요한 것 3 — 소화설비 커버 결정 (사업주 의무 12건):**  
has_chemical_substance 또는 화학설비 등록 시 트리거.  
어휘 매핑이 아니라 입력 항목 포함 여부 판단 필요.

### 7-3. Binding 가능하지만 해서는 안 되는 것 (UNRESOLVED 35.2%)

사업주 의무 중 E3/F 카테고리 461건은 "해당하는 경우", "필요한 경우"와 같이 참조 조문 해석 없이는 커버 불가하다.  
이 영역은 **엔진(Check Engine / SemanticClause 주체)**이 담당해야 하는 도메인.
