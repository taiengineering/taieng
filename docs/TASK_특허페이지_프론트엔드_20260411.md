## 배경

TAI는 2026년 3~4월 특허 5건 + 상표 1건을 출원 완료.
현재 **출원 상태(Patent Pending)**이며, 등록 전이므로
모든 표기는 "특허 출원 중" 또는 "Patent Pending"으로 통일.

## 작업 1. nexas/patents.html 신규 생성

### URL
`new.taieng.co.kr/nexas/patents.html`

### 페이지 구조

```
[GNB]

[Hero 섹션] — 네이비 배경
  상단 태그: "기술 혁신"
  타이틀: "TAI의 핵심 기술은 특허 출원 중입니다"
  부제: "산업안전 관리의 구조적 혁신을 이루는 TAI의 기술은
         현재 5건의 특허 출원을 통해 법적으로 보호받고 있습니다."
  뱃지: 🔒 Patent Pending — 출원번호 제10-2026-0056330 외 4건

[특허 카드 섹션] — 5개 카드
  각 카드 구성:
    ① 아이콘 (서비스별 다름)
    ② 출원번호 (소문자, 회색)
    ③ 출원일
    ④ 발명 명칭
    ⑤ 한 줄 설명
    ⑥ 연계 서비스 배지
    ⑦ "Patent Pending" 빨간 태그

[통합 흐름도 섹션]
  5개 특허가 하나의 시스템으로 연결되는 흐름 시각화
  시설/공정/설비 입력 → 법령 자동 판정 → 점검 항목 생성
  → 작업자 입력 → 데이터 누적 → 위험 예측 → 경고/통제
  (가로 화살표 형태, 모바일은 세로)

[법적 고지 섹션] — 연한 배경
  아이콘: ⚖️
  제목: "법적 보호 안내"
  내용:
    본 서비스에 적용된 핵심 기술은 특허 출원 중이며
    (출원번호: 제10-2026-0056330 외 4건),
    출원일로부터 제3자의 동일·유사 기술 실시에 대해
    법적 대응이 가능합니다.
    무단 복제·모방·역설계 시 특허법에 따른
    민·형사상 조치를 취할 수 있습니다.

[CTA 섹션]
  "TAI의 특허 기술이 적용된 서비스를 경험해보세요"
  [무료 법령진단 시작] [서비스 소개]

[Footer]
```

### 디자인 요구사항

```
- 기존 tai-main.css 사용
- 히어로: var(--navy) 배경, 흰 텍스트
- 카드: 흰 배경, 좌측 border 4px var(--red)
- "Patent Pending" 태그: 빨간 배경 흰 텍스트
- 출원번호: 회색 소문자, font-size .75rem
- 흐름도: 아이콘 + 화살표 가로 배치 (Flexbox)
- 법적 고지 섹션: #f8f9fa 배경, 좌측 border var(--red)
- 반응형: 카드 모바일 1열, 태블릿 2열, PC 3열
```
