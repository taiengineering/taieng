## 배경

TAI는 2026년 3~4월 특허 5건 + 상표 1건 출원 완료.
현재 **출원 상태(Patent Pending)**이며 등록 전이므로
모든 표기는 "특허 출원 중" 또는 "Patent Pending"으로 통일.

**비공개 항목 (카드에 표시 금지):**
- 출원인 → 개인 이름 노출 위험
- 출원일 → "이제 막 냈다" 인식 방지

### 특허 카드 — 특허증 스타일 디자인

실제 특허증에서 영감받은 TAI 브랜딩 카드.
특허청 로고·직인 사용 금지. TAI 브랜딩으로 재해석.

**카드 레이아웃:**

```
┌─────────────────────────────────┐
│  PATENT PENDING        [스탬프] │  ← 우상단 빨간 대각선 스탬프
│  ─────────────────────────────  │
│                                 │
│  [아이콘]  발  명  명  칭       │  ← 세리프 폰트, 중앙 정렬
│                                 │
│  조건코드 기반 산업안전         │
│  법령 자동 판정 시스템          │
│                                 │
│  ─────────────────────────────  │
│  출원번호                       │
│  제10-2026-0056330              │  ← 소문자 회색
│                                 │
│  핵심 기술:                     │
│  시설·공정·설비 데이터 입력 시  │
│  적용 법령·의무사항 자동 산출   │
│                                 │
│  ─────────────────────────────  │
│  TAI Safe — 법령진단 [배지]     │  ← 하단 연계 서비스
└─────────────────────────────────┘
```

**표시 항목 (출원인·출원일 비공개):**

| 항목 | 표시 여부 | 비고 |
|---|---|---|
| PATENT PENDING 스탬프 | ✅ | 빨간 대각선 스탬프 |
| 출원번호 | ✅ | 소문자 회색 |
| 발명 명칭 | ✅ | 세리프 폰트 강조 |
| 핵심 기술 설명 | ✅ | 2~3줄 |
| 연계 서비스 배지 | ✅ | 하단 |
| 출원인 | ❌ | 개인명 노출 방지 |
| 출원일 | ❌ | 출원 시점 노출 방지 |
